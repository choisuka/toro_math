## A. 검증된 서랍 — 기존 개념카드와 연결됨 (역참조 필수)

### A-1. 항등식 — 계수비교법
- **메커니즘**: 양변의 같은 차수 항의 계수가 서로 같음을 이용.
- **연결 카드**: 주제0
- **난이도 신호**: 체이닝 1단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 기본0-1

### A-2. 항등식 — 수치대입법
- **메커니즘**: 구하려는 값이 그대로 나오게 만드는 특별한 x를 골라 대입 (전개 생략).
- **연결 카드**: 주제0
- **난이도 신호**: 체이닝 1단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 기본0-2
- **참고**: 이 기법이 B11(계수의 합, P(1)/P(−1) 활용)의 원형 — "x=1을 넣으면 계수의 합이 그대로 나온다"는 아이디어가 여기서 이미 등장함.

### A0. 다항식의 나눗셈 (몫과 나머지)
- **메커니즘**: 세로 나눗셈으로 P(x)=D(x)Q(x)+R(x) 직접 구함.
- **연결 카드**: 주제1
- **난이도 신호**: 체이닝 1단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 기본1, 기본1-2(이차식으로 나누는 변형)

### A1. 일차식으로 나눈 나머지 — 바로 대입
- **메커니즘**: x=a 대입해서 P(a) 계산.
- **연결 카드**: 주제2
- **난이도 신호**: 체이닝 1단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 기본2, 연습1·2, 실전훈련 유형2

### A2. 미정계수 1개 (조건 1개)
- **메커니즘**: P(a)=조건값을 방정식으로 풀어 미지수 하나 구함.
- **연결 카드**: 주제2
- **난이도 신호**: 체이닝 1단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 기본2-2, 기본2-3(분수 근 변형)

### A3. 나머지정리 → 인수정리 → 인수분해
- **메커니즘**: P(a)=0 확인 → (x−a)로 나눈 몫 구함 → 남은 식 인수분해.
- **연결 카드**: 주제3
- **난이도 신호**: 체이닝 2~3단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 기본3, 기본3-2(미정계수+인수분해 결합), 실전훈련 유형8
- **기출 대조**: examprep_reference_다항식_2026.txt에 "다항식이 (x−a)를 인수로 갖고 (x−b)로 나누면 나머지가 ~, 인수분해하시오" 서술형이 2개교(안양고/광휘고)에서 확인됨. **다만 실제 기출은 종종 인수분해에서 안 끝나고 "방정식을 푸는 과정까지" 서술을 요구** — 확장 후보(2026-07-23, 사용자 확인 대기중).

### A4. 조립제법 계산
- **메커니즘**: 계수만 놓고 "곱하고(×a) 더하기" 반복.
- **연결 카드**: 주제4
- **난이도 신호**: 체이닝 1단계(반복) / 케이스분류 0개 / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 기본4, 기본4-2(음수 a 변형)

## B. 새 서랍 — 개념카드 없이 연습·실전훈련에 바로 사용 중

### B1. 미정계수 연립 (조건 2개 → 두 미지수)
- **메커니즘**: 서로 다른 두 x값 대입, 연립방정식으로 미지수 2개 확정.
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / **동시조건 2개**
- **현재 사용처**: 실전훈련 유형1·4

### B2. 이차식으로 나눈 나머지 (R(x)=ax+b, 조건 2개)
- **메커니즘**: 나누는 식이 이차식 → 나머지를 ax+b로 놓고, 두 근을 대입해서 a,b 연립.
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 2개
- **현재 사용처**: 연습7, 실전훈련 유형3·7·13
- **주의**: 유형7(x¹⁰⁰÷(x²−1))과 유형13(P(a)=b,P(b)=a 패턴)은 겉보기 다르지만 **메커니즘은 B2와 동일** — 서랍 라벨링할 때 "이거 새로운 유형인가?"에 낚이지 않도록 학생에게 강조 필요.

### B3. 합성식은 목표를 재정의 (P(x+a), P(ax+b))
- **메커니즘**: "무엇을 구하는 문제인지"부터 P(특정값) 형태로 재정의 → 0으로 만드는 x 역추적 대입.
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 연습3, 서랍4(개념파일), 실전훈련 유형5·6

### B4. 몫 Q(x)에 나머지정리 중첩
- **메커니즘**: 검산식 P(x)=(x−a)Q(x)+r 을 세운 뒤, Q(x) 자체에 대한 별도 조건이 있으면 Q(x)에도 나머지정리를 한 번 더 적용.
- **난이도 신호**: 체이닝 2~3단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 2개(P 조건 1 + Q 조건 1)
- **현재 사용처**: 연습4, 서랍3(개념파일)

### B5. 두 다항식의 합·곱의 나머지
- **메커니즘**: (P+Q)(a)=P(a)+Q(a), (PQ)(a)=P(a)Q(a) — 나머지정리를 각각 적용한 뒤 연산.
- **난이도 신호**: 체이닝 1단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 연습5, 실전훈련 유형18

### B6. 나머지가 서로 같다는 조건
- **메커니즘**: P(a)와 P(b)를 각각 식으로 세우고 "같다"를 등식으로 연결 → 미지수 소거.
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 연습6

### B7. 삼차식(이차식+일차식 조건)으로 나눈 나머지
- **메커니즘**: 나누는 식이 삼차식 → 나머지 R(x)=ax²+bx+c. 이차식 조건에서 R(x)=k(x−p)²+(주어진 저차 나머지) 형태로 먼저 좁히고, 나머지 일차식 조건으로 k를 확정.
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개 / 정수론 없음 / **동시조건 2개(차수 다른 두 조건)**
- **연결 카드**: 서랍3(개념파일, 다만 B4와는 다른 기법이므로 혼동 주의 — 2026-07-23 수정 시 이 둘을 분리했음)
- **현재 사용처**: 실전훈련 유형10

### B8. (x−a)² 완전제곱으로 나눈 나머지 / 연속조립제법
- **메커니즘**: 조립제법을 (x−a)로 두 번(또는 세 번) 반복. 매번 나온 나머지를 (x−a)의 거듭제곱 계수로 이어붙임.
- **난이도 신호**: 체이닝 2~3단계(반복) / 케이스분류 0개 / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 실전훈련 유형11(=14 통합)

### B9. 인수분해 안 되는 이차식 조건 (x²+x+1=0 등, 허수 연계)
- **메커니즘**: 조건식×(x−1) 형태로 인수분해해서 xⁿ=1 같은 저차 항등식을 얻고, 큰 지수를 그 항등식의 배수+나머지로 쪼갬.
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개 / **정수론적 요소 있음(지수를 배수+나머지로 분해)** / 동시조건 0개
- **현재 사용처**: 실전훈련 유형9

### B10. 나머지가 같은 다항식 → 규칙식 이항해서 재구성
- **메커니즘**: P(1)=P(2)=P(3)=k 같은 조건 → P(x)−k가 x=1,2,3에서 0이 되므로 (x−1)(x−2)(x−3)을 인수로 가짐 → P(x) 자체를 다시 씀. (B6과 겉보기 비슷하지만, B6은 "미지수 하나 구하기"이고 B10은 "다항식 전체를 재구성하기"라 메커니즘이 다름 — 서랍 분리 유지.)
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / **동시조건 3개(같은 값 3개)**
- **현재 사용처**: 실전훈련 유형12

### B11. 계수의 합 (P(1), P(−1) 활용)
- **메커니즘**: 모든 계수의 합=P(1). 짝수차항 합=(P(1)+P(−1))/2, 홀수차항 합=(P(1)−P(−1))/2.
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 실전훈련 유형15

### B12. 자연수 거듭제곱의 나머지 (정수론 응용)
- **메커니즘**: 2⁵⁰=32¹⁰처럼 밑을 (나누는 수+1) 꼴로 바꾼 뒤, P(x)=xⁿ을 (x−1)로 나눈 나머지(=1)를 이용.
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개 / **정수론적 요소 있음** / 동시조건 0개
- **현재 사용처**: 실전훈련 유형16

### B13. 다항식 결정 문제 (차수 추론)
- **메커니즘**: 조건을 만족하는 최소 차수를 찾기 위해 몫을 상수로 가정하고 검산 → 모순 없으면 그게 답.
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개(가정이 맞았을 때만) / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 실전훈련 유형17

### B14. 정수 조건 + 부등식 결합
- **메커니즘**: 나머지정리로 나온 식이 부등식(자연수·정수 등) 조건을 만족하도록 범위를 좁힘.
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음(정수 "조건"이지 정수론 기법은 아님) / 동시조건 1개
- **현재 사용처**: 실전훈련 유형19

## 범위 밖 — 아직 배우지 않은 개념이라 서랍으로 넣으면 안 되는 것

- **미분을 이용한 (x−a)ⁿ 나눈 나머지** — 공통수학1 단계에서는 미분 미학습. B8(연속조립제법)로 대체함.
- **복소수 사칙연산 자체** — B9(x²+x+1=0)는 조건식만 다항식적으로 다루고, 복소수 값 자체를 계산하지는 않음. 복소수 단원을 배운 뒤에는 더 깊게 다룰 수 있음.
- **행렬을 이용한 나머지정리 표현** — 2022 개정 교육과정 범위 밖.
