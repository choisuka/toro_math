# 시험대비 패턴 서랍 — 원의 방정식

`toro-examprep-generator`가 문제 세트를 설계할 때 참고하는 유형 목록입니다. 각 서랍은
①메커니즘 ②연결되는 기존 개념카드(있으면 — 역참조 필수 대상) ③난이도 신호(체이닝 단계 /
케이스분류 개수 / 정수론적 요소 / 동시조건 개수)로 정리했습니다.

**범위**: 2022 개정 공통수학2 "원의 방정식" 소단원. `examprep_reference_도형의방정식_2026.txt`
에서 원의방정식|반지름|중심|접선 관련 실제 기출 표현 370건을 그라운딩으로 사용.

---

## A. 검증된 서랍 — 기존 개념카드와 연결됨 (역참조 필수)

### A1. 세 점을 지나는 원 (외접원)
- **메커니즘**: 일반형 x²+y²+Dx+Ey+F=0에 세 점을 대입, 연립방정식으로 D,E,F를 구함.
- **연결 카드**: 주제0(일반형), 지도1
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개 / 정수론 없음 / **동시조건 3개(연립)**
- **현재 사용처**: 연습문제 6

### A2. 원과 직선의 위치 관계
- **메커니즘**: 중심에서 직선까지 거리 d와 반지름 r을 비교(d<r/d=r/d>r).
- **연결 카드**: 주제1
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 연습문제 3

### A3. 접선 — 원 위의 점에서
- **메커니즘**: 원 위의 점(x₁,y₁)에서의 접선 공식 x₁x+y₁y=r²을 바로 대입.
- **연결 카드**: 주제2
- **난이도 신호**: 체이닝 1단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 연습문제 4

### A4. 접선 — 기울기 주어짐 / 원 밖의 점
- **메커니즘**: 접선을 y=mx+n(또는 점 기울기 형)으로 놓고, 중심과의 거리=반지름 조건으로
  미지수를 구함. 원 밖의 점이 주어지면 두 접선이 나옴(지도6).
- **연결 카드**: 주제2(확장), 지도6
- **난이도 신호**: 체이닝 2~3단계 / 케이스분류 0개(±로 갈라짐) / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 연습문제 5

## B. 새 서랍 — 개념카드 없이 시험대비 문제에 바로 사용 가능

### B1. 지름의 양 끝점으로 원 구하기
- **메커니즘**: 두 점의 중점(내분점 공식)=중심, 두 점 사이 거리의 절반=반지름.
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 지도2

### B2. 좌표축에 접하는 원 — 세 종류
- **메커니즘**: x축만 접(중심 y좌표=±r), y축만 접(중심 x좌표=±r), 양축 모두 접(중심 (±r,±r),
  네 사분면 중 하나) — 문제에서 "축에 접한다"는 말만 나오면 세 종류 중 어느 것인지부터 확정.
- **난이도 신호**: 체이닝 2단계 / **케이스분류 3개(x축만/y축만/양축)** / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 지도3

### B3. 원의 중심이 어떤 직선 위에 있다
- **메커니즘**: 중심을 (t, f(t)) 형태로 매개변수화(직선 위의 점이므로), 다른 조건(반지름·접선 등)과
  연립해서 t를 구함.
- **난이도 신호**: 체이닝 2~3단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 지도4

### B4. 원과 직선 + 넓이(현) 결합
- **메커니즘**: 원과 직선이 두 점에서 만날 때 생기는 현의 길이나, 그 현이 만드는 삼각형의 넓이를
  거리공식+피타고라스로 구함(현의 절반과 중심에서의 수선이 직각삼각형을 만듦).
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 지도5

### B5. 원 위의 동점과 정점 사이 거리의 최댓값·최솟값
- **메커니즘**: 원 위를 움직이는 점과 원 밖(또는 안) 정점 사이의 거리는 (중심-정점 거리) ± 반지름
  일 때 최댓값·최솟값이 됨(삼각부등식).
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개(±로 최대·최소 동시 도출) / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 지도7(하브루타)

### B6. 원 위의 점과 직선 사이 거리의 최댓값·최솟값
- **메커니즘**: B5와 헷갈리기 쉬움 — 이번엔 대상이 정점이 아니라 직선. 중심에서 직선까지의 거리
  d를 먼저 구하고, 최댓값=d+r, 최솟값=d−r(직선이 원과 안 만날 때만 최솟값이 의미 있음, 만나면
  최솟값 0).
- **난이도 신호**: 체이닝 2~3단계 / 케이스분류 1개(직선이 원과 만나는지 여부) / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 아직 없음 — 연습문제 또는 서랍문제 후보

## C. 결합형 — "상"·"최고난도"는 서랍을 겹쳐서 만든다

### C1. B2(좌표축접함) + B3(중심이 직선위) 결합
두 서랍을 동시에 걸면 케이스가 좁혀진다 — 예: "중심이 직선 y=x 위에 있고 양축에 모두 접하는
원"은 B2의 네 사분면 케이스 중 y=x와 실제로 만나는 두 개(1·3사분면)만 남고 나머지는 자동 소거됨.
**서랍문제 1로 사용.**

### C2. A1(외접원) + B3(중심이 직선위) 결합
세 점 중 하나를 미지수로 두고, 외접원의 중심이 특정 직선 위에 있다는 조건까지 얹으면 연립방정식이
하나 더 늘어나 체이닝이 4~5단계로 길어짐.

### C3. A4(접선) + B5(거리 최댓값) 결합
원 밖의 점에서 그은 접선의 접점을 구한 뒤, 그 접점이 다른 정점과 이루는 거리의 최댓값을 묻는 구조
— 접선 서랍의 출력(접점 좌표)이 거리 서랍의 입력이 되는 순차 결합.

## 아직 "서랍문제"(심화 discovery형)로 안 쓰인 서랍

연습문제 1~6이 A1~A4를 사용했고, B1~B5는 지도 카드에서 안내만 됐을 뿐 개방형 발견 문제로는
아직 안 쓰였다. **서랍문제 1**은 C1(B2+B3 결합)을 개방형으로 만든 것 — "중심이 직선 위에 있고
축에 접하는 원을 모두 찾아라"처럼 학생이 케이스를 스스로 좁혀가야 하는 구조.

## 범위 밖 — 아직 배우지 않은 개념이라 서랍으로 넣으면 안 되는 것

외부에서 받은 "원의 방정식 핵심 유형 10가지" 참고자료 중 다음은 **현재 커리큘럼(표준형·일반형·
위치관계·접선·외접원)을 벗어나** 새 개념카드 없이 문제만 만들면 안 배운 걸 전제하게 됨:
- **아폴로니오스의 원** — "자취의 방정식" 개념카드가 아직 없음. 이 개념 자체를 먼저 가르쳐야 함.
- **두 원의 공통현 / 두 원의 교점을 지나는 원** — "두 원"을 다루는 개념카드가 없음(지금은 원 1개만).
- **원의 이동과 대칭 결합** — 도형의 이동 단원(평행이동·대칭이동)과의 교차 결합이라, 그 단원까지
  다 배운 뒤에나 자연스러움. 지금 넣으면 순서가 꼬임.

이 세 가지는 나중에 해당 개념카드를 만들 때 서랍으로 재검토할 것.
