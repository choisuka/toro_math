# 시험대비 패턴 서랍 — 직선의 방정식

`toro-examprep-generator`가 문제 세트를 설계할 때 참고하는 유형 목록입니다. 각 서랍은
①메커니즘 ②연결되는 기존 개념카드(있으면 — 역참조 필수 대상) ③난이도 신호(체이닝 단계 /
케이스분류 개수 / 정수론적 요소 / 동시조건 개수)로 정리했습니다.

**범위**: 2022 개정 공통수학2 "직선의 방정식" 소단원. `examprep_reference_도형의방정식_2026.txt`
에서 기울기·평행·수직·절편 관련 실제 기출 표현 317건을 그라운딩으로 사용.

**서랍과 카드의 관계**: "지도" 카드(지도1~7)는 패턴을 안내하는 스토리 카드이지 서랍 그 자체가
아닙니다. 서랍은 그 안내가 가리키는 구체적인 풀이 기법입니다 — 지도 카드 하나가 서랍 여러 개를
포괄하기도 하고, 서랍 하나가 여러 지도 카드에 걸쳐 있기도 합니다.

---

## A. 검증된 서랍 — 기존 개념카드와 연결됨 (역참조 필수)

### A1. 절편 + 도형 넓이
- **메커니즘**: x절편·y절편을 구해 삼각형 OAB(또는 다른 도형)의 넓이·무게중심 등을 구함.
- **연결 카드**: 주제1.5(x절편·y절편), 지도2
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 연습문제 4(기본), 연습문제 9(대변 중점 결합·상)

### A2. 평행·수직 동시조건
- **메커니즘**: 한 직선이 A와는 평행, B와는 수직 — 두 조건을 동시에 만족하는 미지수를 구함.
- **연결 카드**: 주제2(평행과 수직)
- **난이도 신호**: 체이닝 2~3단계 / 케이스분류 0개 / 정수론 없음 / **동시조건 2개**
- **현재 사용처**: 연습문제 5(단일 수직), 연습문제 8(평행+수직 동시, 미지수 2개)

### A3. 점과 직선 사이의 거리 응용
- **메커니즘**: 거리 공식을 "평행선 사이 거리"(같은 직선 위 아무 점이나 대입)나 "원점에서의
  최대/최소 거리"로 확장.
- **연결 카드**: 주제3(점과 직선 사이의 거리), 지도7(하브루타)
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 연습문제 6(기본), 연습문제 10(최댓값 원리·상)

### A4. 수직이등분선
- **메커니즘**: 두 점의 중점(내분점 공식) + 수직조건을 결합해 수직이등분선의 방정식을 구함.
- **연결 카드**: 평면좌표(내분점) + 주제2(수직조건)
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개 / 정수론 없음 / **동시조건 2개(중점+수직)**
- **현재 사용처**: 지도6, 연습문제 11(다른 직선과의 교점까지 결합·고난도)

## B. 새 서랍 — 개념카드 없이 시험대비 문제에 바로 사용 가능

### B1. 세 직선이 삼각형을 이루지 못하는 조건
- **메커니즘**: "삼각형이 안 된다" = 두 직선이 평행 **또는** 세 직선이 한 점에서 만남. 두 가지
  경우를 각각 확인하고, 한쪽이 성립 안 하면 그 케이스를 소거.
- **난이도 신호**: 체이닝 3~4단계 / **케이스분류 2개(평행/한점) — 일부는 "해 없음"으로 소거될 수 있음**
  / 정수론 없음 / 동시조건 0개
- **현재 사용처**: 지도5, 연습문제 12(케이스 소거·고난도)

### B2. 매개변수 직선의 고정점 (항등식)
- **메커니즘**: k(식1)+(식2)=0 꼴은 k값과 무관하게 식1=0, 식2=0을 동시에 만족하는 점을 항상
  지남 — 학생이 "이게 k에 대한 항등식이다"를 스스로 알아채야 함(문제에서 대놓고 알려주면 안 됨).
- **난이도 신호**: 체이닝 2단계(고정점 찾기) / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 연습문제 13(거리 최댓값과 결합·최고난도)

### B3. 매개변수 직선과 선분의 교차 범위
- **메커니즘**: 고정점에서 선분의 양 끝점을 바라보는 두 기울기를 구하고, 매개변수가 그 사이에
  있어야 선분과 만난다는 사실을 이용.
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개(경계 포함 여부 확인 1회) / 정수론 **조건부**(자연수
  제한 시) / 동시조건 1개
- **현재 사용처**: 연습문제 14(자연수 조건 결합·최고난도)

### B4. 삼각형 넓이 이등분
- **메커니즘**: 꼭짓점을 지나며 넓이를 이등분하는 직선은 반드시 대변의 중점을 지난다는 성질.
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 연습문제 9(상)

### B5. 세 점이 한 직선 위에 있다 (공선점 — 기울기 비교)
- **메커니즘**: "세 점이 삼각형을 이루지 않는다" = 세 점이 한 직선 위에 있다는 뜻. **직선의 방정식이 아니라 점
  좌표만 주어졌을 때** 쓰는 서랍 — 두 점 사이의 기울기 공식(주제1)으로 slope(AB)=slope(AC) 식을 세운다. B1과
  표면 문구("삼각형을 이루지 않는다")가 같아 헷갈리기 쉬운 대비쌍 관계지만, B1은 직선 3개가 주어진 경우이고
  B5는 점 3개가 주어진 경우로 완전히 다른 기법을 쓴다.
- **연결 카드**: 주제1(기울기의 정의, 두 점 사이의 기울기)
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개(단, 기울기 등식이 통상 이차식이 되어 두 해를 모두 확인해야 함)
  / 정수론 없음 / 동시조건 1개
- **현재 사용처**: 연습문제 17(고난도, 파일2 신규 추가) — examprep_reference_도형의방정식_2026.txt의 "세
  점이 삼각형을 이루지 않도록 하는 실수 k의 값의 합/곱을 구하시오" 유형(6012, 7204, 7770행 등에서 3회 이상
  반복 확인)을 그라운딩으로 삼음.

## C. 결합형 — "상"·"최고난도"는 서랍을 겹쳐서 만든다

평면좌표 때와 같은 원칙: 단일 서랍은 "중" 수준에 그친다. 실제로 겹쳐서 쓴 사례:

### C1. A1(절편+넓이) + A4(중점) 결합 → B4
연습문제 9는 A1의 "절편으로 도형 만들기"와 A4에서 쓰는 "중점" 개념을 합쳐 B4(넓이 이등분)를
완성한 경우 — 서랍 하나가 다른 두 서랍의 재료를 가져다 쓴 사례.

### C2. B2(고정점) + A3(거리 응용) 결합
연습문제 13 — 먼저 B2로 고정점을 찾아야 A3(거리 최댓값)를 적용할 수 있음. 두 서랍이 순차적으로
이어지는 구조라 체이닝 단계가 가장 김(고정점 찾기 2단계 + 거리 최댓값 2단계 = 4단계).

### C3. A4(수직이등분선) + 교점 결합
연습문제 11 — A4로 수직이등분선을 구한 뒤, 그 결과를 또 다른 직선과 연립해서 교점까지 구함.
"한 서랍의 결과가 다음 계산의 입력이 되는" 순차 결합 구조.

## 아직 "서랍문제"(심화 discovery형)로 안 쓰인 서랍

연습문제(하~최고난도) 14개가 이미 A1~A4, B1~B4를 전부 최소 1회 이상 사용했다. 평면좌표의
"심화1·7·10"처럼 **개방형·발견형**(정답이 여러 개, 학생이 스스로 축/케이스를 설계하게 하는 구조)
으로는 아직 아무 서랍도 안 쓰였다는 뜻 — "서랍문제" 페이즈는 이 중 하나를 골라 문제/풀이가 아닌
**다단계 안내형**으로 다시 만드는 것이 목적이다 (기존 연습문제와 형식이 겹치면 안 됨).

**추천**: A2(평행·수직 동시조건)를 개방형으로 확장 — "직선 하나를 내가 직접 그어서 두 조건을
동시에 만족시키기"처럼 학생이 선택지를 만들어가는 구조로 설계 가능. 또는 B1을 확장한 현재
"서랍문제1"(원점을 지나는 직선 만들기)도 구조상 적합 — 다만 지도5를 서랍인 것처럼 표기한 오류만
바로잡아 "B1(세 직선이 삼각형을 이루지 못하는 조건)"으로 정정하면 그대로 재사용 가능하다.

## D. 단원 마무리 구조 — "이 단원 한눈에 보기" (2026-07-25 신규)

개념파일(`공수2_직선의방정식_1개념.html`) 맨 끝에 `원의방정식_3부` 파일의 마무리 패턴(🗂️ 전체
흐름 정리 → 📋 공식 총정리 → 🗺️ 이런 표현이 나오면 이 유형 → ✏️ 용어 빈칸 테스트)을 그대로
가져와 적용하고, 거기에 4가지 테스트를 추가로 확장했다. **이 구조는 앞으로 만드는 모든
개념파일의 표준 마무리 템플릿으로 재사용할 것.**

### D1. 🗂️ 전체 흐름 정리
단원의 각 주제를 ①②③... 순서로 한 문단씩 서술 — "이 주제가 왜 이 순서로 오는지"와 "다음 주제와
어떻게 연결되는지"를 명시. 원의방정식 3부의 형식 그대로.

### D2. 📋 공식 총정리
단원에서 쓴 모든 공식을 한 카드에 압축 — 학생이 시험 직전에 마지막으로 훑어보는 치트시트 용도.

### D3. 🗺️ 이런 표현이 나오면 이 유형
"트리거 표현 → 서랍/기법" 매핑을 한 카드에 압축한 것 — 이 파일 A/B 서랍 목록과 지도 카드들의
"신호가 되는 표현" 부분만 뽑아 압축한 버전. 서랍 목록(A1~A4, B1~B4)과 내용이 겹치므로, 서랍
목록을 먼저 갱신한 뒤 이 카드를 다시 압축하는 순서로 만드는 게 안전함.

### D4. ✏️ 용어 빈칸 테스트 (+정답 카드)
단원에서 배운 명칭(정점, 자취, 절편형, 일반형 등)을 정확히 기억하는지 확인 — 계산이 아니라
용어 자체를 묻는 문제.

### D5. 🧠 개념 이해 테스트 (신규 — 원의방정식엔 없던 유형)
- **메커니즘**: "공식이 왜 그런 모양인지" 서술형으로 묻거나, O/X로 개념 오해를 확인.
- **예시**: "y−y₁=m(x−x₁)에서 왜 (x−x₁)을 곱하는가", "기울기 판정과 일반형 판정이 다른 결론을
  줄 수 있는가(O/X, 정답 X)".
- **목적**: 암기가 아니라 이해를 확인 — project_toro_math 메모리의 "계산력보다 개념 인식이
  근본 문제"라는 진단과 직접 연결됨.

### D6. 🔍 영역 인식 테스트 (신규)
- **메커니즘**: 판별 드릴과 비슷하지만, 지도1~4가 아니라 **주제1~6 전체**를 대상으로 짧은 문제
  6개를 주고 "이건 주제 몇?"을 맞히게 함. 한 문제가 여러 주제에 걸치는 경우(예: 수직 조건은
  주제3이지만 방정식 자체는 주제2 공식)도 명시적으로 보여줌.
- **판별 드릴과의 차이**: 판별 드릴은 지도(트리거 표현) 중심, 이건 주제(단원 목차) 중심.

### D7. 🔗 결합능력 테스트 (신규)
- **메커니즘**: 기존 "결합형"(C1~C3)은 서랍 2개 결합이 최대였는데, 이건 **주제 4개 이상**
  (정점→기울기→수직→점기울기공식→거리)을 한 문제에 순차적으로 엮음.
- **현재 사용처**: 정점(2,3) → 수직 기울기(−1/2) → 직선 m(x+2y−8=0) → 원점 거리(8√5/5).
  직접 검산 완료.

### D8. 🔢 순서정하기 테스트 (신규)
- **메커니즘**: D7 결합 문제의 풀이 단계 5개를 섞어서 제시하고 올바른 순서를 맞히게 함.
- **목적**: 결합 문제에서 "무엇이 확정돼야 다음 단계로 갈 수 있는지" 순서 감각을 훈련 —
  단순히 각 기법을 아는 것과, 여러 기법을 순서대로 조립하는 것은 다른 능력이라는 전제.

**주의**: D3(유형매핑)과 D6(영역인식)을 만들 때 이 파일 상단의 서랍 목록(주제 번호, 지도 번호)이
2026-07-25 재구성 이전 값으로 낡아 있었다는 걸 그대로 옮기지 않도록 주의할 것 — D 섹션 자체는
새 주제1~6 번호로 작성했지만, A/B/C 섹션은 아직 갱신 안 됨(별도 작업 필요).
