 # 시험대비 패턴 서랍 — 평면좌표 (두 점 사이의 거리 · 내분점)

`toro-examprep-generator`가 문제 세트를 설계할 때 참고하는 유형 목록입니다. 각 서랍은
①메커니즘 ②연결되는 기존 개념카드(있으면 — 역참조 필수 대상) ③난이도 신호(체이닝 단계 /
케이스분류 개수 / 정수론적 요소 / 동시조건 개수)로 정리했습니다.

**범위 제한**: 2022 개정 공통수학2 "평면좌표" 소단원 — 두 점 사이의 거리, 내분점(외분점은
개정에서 삭제되어 다루지 않음)만 사용. 직선의 방정식·원의 방정식은 아직 안 배운 상태이므로,
그 개념이 필요한 서랍은 여기 포함하지 않았습니다(예: 직선 위의 점 조건은 "AB+BC=AC" 같은
거리 관계로 우회).

---

## A. 검증된 서랍 — 기존 개념카드와 연결됨 (역참조 필수)

문제 풀이 끝에 반드시 해당 카드 이름 + 구조적 신호를 함께 언급할 것 (에이전트 설계원칙 ④⑤).

### A1. 이등변삼각형 판별
- **메커니즘**: AB=BC, BC=CA, CA=AB 세 쌍 중 어느 것이 같은지 스스로 판단해야 함 — 문제에
  "어느 변인지" 알려주지 않는 게 핵심.
- **연결 카드**: 심화2
- **난이도 신호**: 체이닝 2~3단계 / 케이스분류 2~3개(어느 변이 같은가) / 정수론 없음 / 동시조건 1개

### A2. 직각삼각형 판별
- **메커니즘**: 피타고라스 정리의 역 — a²+b²=c² 성립 여부, 어느 변이 빗변인지 확정 안 됨.
- **연결 카드**: 심화3
- **난이도 신호**: 체이닝 2~3단계 / 케이스분류 2~3개(어느 각이 직각인가) / 정수론 없음 / 동시조건 1개

### A3. 정삼각형 조건
- **메커니즘**: AB=BC=CA를 동시에 만족 — 등식 두 개를 연립해야 함.
- **연결 카드**: 심화6
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개 / 정수론 없음 / **동시조건 2개(연립)**

### A4. 평행사변형 판별
- **메커니즘**: 대각선이 서로를 이등분한다 → 두 대각선의 중점(내분점 1:1)이 같음을 이용.
- **연결 카드**: 심화5
- **난이도 신호**: 체이닝 2단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개

### A5. 무게중심
- **메커니즘**: 대변의 중점(내분점 1회) → 그 중점과 꼭짓점을 2:1 내분(내분점 2회째, 중첩).
- **연결 카드**: 심화7
- **난이도 신호**: **체이닝 3단계** / 케이스분류 0개 / 정수론 없음 / 동시조건 1개(순차)

### A6. 외심
- **메커니즘**: 세 꼭짓점으로부터 등거리인 점 → PA²=PB², PB²=PC² 두 방정식을 연립.
  직각삼각형이면 빗변의 중점이 외심이라는 특수성질과 결합 가능(심화1 한 걸음 더 참고).
- **연결 카드**: 심화1(한 걸음 더) / 문항 도입부 외심 언급
- **난이도 신호**: **체이닝 3~4단계** / 케이스분류 0개 / 정수론 없음 / **동시조건 2개(연립)**

## B. 새 서랍 — 개념카드 없이 시험대비 문제에 바로 사용 가능 (교육과정 표준 지식)

기존 스토리카드가 없으므로 ④⑤ 역참조는 생략하거나, 대신 "이 문제가 사용하는 개념" 빈칸에서
순수하게 구조적 신호로만 안내.

### B1. 정수좌표 · 정수거리 (피타고라스 수)
- **메커니즘**: 좌표가 정수이고 두 점 사이 거리도 정수가 되는 조건 → 3-4-5, 6-8-10, 5-12-13
  같은 피타고라스 수를 스스로 찾아야 함.
- **난이도 신호**: 체이닝 3단계 / 케이스분류 **정수해 개수만큼 발생** / **정수론 핵심 요소** / 동시조건 1개

### B2. 일직선 위 조건 (직선의 방정식 없이)
- **메커니즘**: AB+BC=AC가 성립하면 세 점이 일직선 위에 있다는 성질 — 거리공식만으로 증명.
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개 / 정수론 없음 / 동시조건 1개

### B3. 좌표축 대칭 최단거리 (반사 원리)
- **메커니즘**: x축 또는 y축에 대한 대칭점 이용, "두 거리의 합이 최소"가 되는 점 찾기.
- **난이도 신호**: 체이닝 3~4단계 / 케이스분류 0개(부호 대칭 1회) / 정수론 없음 / 동시조건 1개

### B4. 내분점 비율 자체가 미지수
- **메커니즘**: m:n에서 m 또는 n이 미지수, 결과 좌표가 특정 조건을 만족하도록 역산.
  m,n이 자연수라는 조건과 결합하면 정수론 요소 추가 가능.
- **난이도 신호**: 체이닝 3단계 / 케이스분류 0개 / 정수론 **조건부**(자연수 제한 시) / 동시조건 1개

## C. 결합형 — "상" 난이도는 서랍 하나가 아니라 서랍을 겹쳐서 만든다 (2026-07-16 시범 확인)

A1(외심)만 단독으로 쓴 문항, B1(정수좌표·정수거리)만 단독으로 쓴 문항 둘 다 사용자 평가로는
"쉬운 중" 수준에 그쳤다. 참고자료의 최고난도 문항(문제2·문제7)을 다시 보면 둘 다 **단일 기법이
아니라 여러 조건이 겹쳐서** 어려운 것 — 케이스 분류 자체가 정수 조건과 얽혀 있고, 케이스 중
일부가 "답 없음"으로 소거되어야 나머지가 확정된다.

### C1. 이등변삼각형(A1) + 정수변(B1) 결합
- **메커니즘**: 이등변삼각형의 세 경우(AB=AC/AB=BC/AC=BC)를 전부 세우되, 세 변이 모두 자연수여야
  한다는 조건을 동시에 걸면 두 경우는 정수해가 없어서 소거되고 한 경우만 유일하게 남는다.
- **난이도 신호**: 체이닝 5~6단계 / **케이스분류 3개(그중 2개는 "해 없음"을 직접 증명해야 소거됨)**
  / 정수론 핵심(완전제곱수·인수분해) / 동시조건 2개(이등변 조건 + 정수 조건)
- **검증된 예시**: A(0,0), B(10,0), C(a,b) 자연수 → AC=BC 경우만 살아남아 C(5,12), 둘레 36.
  (`_dev/examprep_review_평면좌표_20260716.html` 문항3)
- **일반화**: 직각삼각형(A2)도 같은 방식으로 결합 가능 — "직각인 경우"를 case-1/2/3으로 나누고
  정수 조건으로 소거하는 구조는 동일.

### 이 발견이 서랍 목록에 주는 의미
A그룹·B그룹은 재료일 뿐이고, **실제 "상" 문제 설계는 재료 2개 이상을 겹쳐서 케이스를 소거하게
만드는 것**이 핵심 메커니즘이다. 세트를 구성할 때 A그룹 단독 문항과 B그룹 단독 문항은 "중" 난이도
슬롯에, C그룹(결합형)은 "상" 난이도 슬롯에 배정할 것.

## 사용 가이드 (에이전트용)

- A그룹·B그룹 단독 문항은 실측 결과 "중" 난이도에 해당한다(2026-07-16 시범 확인). "상" 난이도가
  필요하면 C그룹(결합형)을 쓸 것 — A그룹의 케이스분류 서랍(A1·A2)과 B그룹의 정수조건(B1)을
  겹쳐서 "케이스 소거"가 필요한 구조로 설계한다.
- 세트를 구성할 때 A그룹만으로도 참고자료 수준(체이닝 3단계+, 동시조건 연립)의 절반 이상을
  커버한다. A3(정삼각형)·A6(외심)이 동시조건 연립을, A1(이등변)·A2(직각삼각형)이 케이스분류를 맡는다.
  B1(정수좌표·정수거리)은 현재 유일하게 진짜 정수론적 사고를 채우는 서랍이므로, "상" 난이도
  세트에는 C1처럼 결합해서 최소 1문항 포함을 권장.
- 인터리빙(설계원칙②) 배치 시 A그룹(스토리 있음)과 B그룹(스토리 없음)을 섞으면 대비쌍(③)도
  자연스럽게 만들어진다 — 예: A1(이등변)과 A2(직각삼각형)는 겉모습이 비슷하고 조건도 비슷해서
  대비쌍 후보로 적합.
- 이 목록은 고정된 게 아니다. 실제 기출 자료가 새로 추가되면 서랍을 늘리고, 난이도 신호가
  실제 계산 결과와 다르면 이 파일을 수정할 것.
