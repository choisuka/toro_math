## 수정 내역

### 1. 허브 — inequality-guide 표시 수정
- **문제:** 버튼에 `(3장)` 표시 → 실제 4장 (review_stage2에서 카드 추가했으나 허브 미반영)
- **조치:** `(4장)` 으로 수정

### 2. ineq-gemini5 문제 4 — 문제 자체 수학 오류 수정
- **문제:** `(x−a)/2 ≤ (2x−1)/3` → 풀면 `x ≥ 2−3a` (하한)
  - 하한이면 자연수 해가 무조건 무한개 → "딱 3개" 조건 자체가 불가능
  - 카드 내 풀이("0 < 2−3a ≤ 1 → 자연수 1,2,3")도 논리 파탄
- **조치:** 문제식을 `(2x−1)/3 ≤ (x+a)/2` 로 수정
  - 풀면: `4x−2 ≤ 3x+3a` → `x ≤ 3a+2` (상한 ✓)
  - 3 ≤ 3a+2 < 4 → **1/3 ≤ a < 2/3** (동일 답)
  - 검증 박스 추가: a=1/3(✓), a=2/3(✗), a=0(✗)

### 3. ineq-lesson 교안 2/5 — 불일치 수정
- **문제:** 위 오류 문제를 그대로 참조 + "x < K" 서술로 `x ≥ 하한` 구조와 정반대
- **조치:**
  - 대표 문제 참조 → 수정된 `(2x−1)/3 ≤ (x+a)/2` 로 변경
  - K = 3a+2 (상한) 명시
  - K 예시 수치 교체: (K=3: 2개→) K=2: 2개 / K=3: 3개✓ / K=3.5: 3개✓ / K=4: 4개
  - 범위 `3 < K ≤ 4` → `3 ≤ K < 4` 로 수정 (등호 방향 수정)

### 4. ineq-hard10 3번 — 절댓값 개념 첫 등장 설명 박스 추가
- **문제:** guide 4장 어디에도 절댓값 부등식 개념 없이 3번 카드에 `|2x−3| < 5` 등장
- **조치:** 카드 상단에 "처음 배우는 거예요!" 박스 추가
  - `|A| < k` → −k < A < k (연속 구간)
  - `|A| > k` → A < −k 또는 A > k (두 조각)

## 구조적 문제 — 기본 문제 없음

방정식은 `eq-guide → eq-basic(10문항) → eq-hard` 구조.
부등식은 `inequality-guide → inequality-havruta → ineq-hard10(심화)` 로 기본 연습 단계 없음.

지수(어려워하는 학생) 입장에서 가이드 4장 후 하브루타 1편을 보고 나면
바로 "매개변수 포함 부등식, a의 값에 따라 분류"(심화 1번)를 마주하게 됨 → 진입 불가.

→ **ineq-basic 세트 신규 추가 필요 여부를 선생님이 판단하도록 플래그 남김.**
