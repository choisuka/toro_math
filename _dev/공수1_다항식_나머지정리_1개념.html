🦕 토로의 수학왕국 · 다항식 — 나머지정리 (1/2 개념·도구)

📍 주제 0 — 항등식: x자리에 뭘 넣어도 참인 식
항등식 — 개념 (방정식과 비교)
🤔 이 두 식, 뭐가 다를까?
❓ 던지는 질문

두 식을 비교해볼게요.

① x+2=5
② (x+1)²=x²+2x+1

①은 x=3을 넣어야만 참이 돼요. x=0이면 2=5로 거짓이죠. 그런데 ②는 x에 아무 숫자나 넣어봐도 항상 참이에요 (직접 x=0, x=2 등 대입해서 확인해보세요). 뭐가 다를까요?

방정식: 특정 x에서만 참 (①처럼, x=3일 때만)
항등식: x에 어떤 값을 넣어도 항상 참 (②처럼)
P(x)=(x−a)Q(x)+R 같은 나눗셈 검산식도 사실 항등식이에요 — Q(x), R이 무엇이든 상관없이, x자리에 어떤 수를 넣어도 등호가 깨지지 않아요. 그래서 대입할 x를 우리가 마음대로 고를 수 있는 자유가 생겨요. 이 성질을 이용하는 두 가지 방법을 배워볼게요.
항등식 — 계수비교법
🤔 양변의 같은 자리 숫자는 서로 같지 않을까?
❓ 던지는 질문

ax²+bx+c = 2x²−3x+5 가 x에 대한 항등식이라면, a, b, c는 각각 뭘까요?

잠깐 생각해보세요 — 양변이 모든 x에서 완전히 같은 식이라면, x² 자리 숫자끼리도 같아야 하고, x 자리·상수 자리도 각각 같아야 하지 않을까요?

계수비교법
두 다항식이 x에 대한 항등식이면, 양변에서 같은 차수 항의 계수는 서로 같다.
그대로 적용하면: x²자리 a=2, x자리 b=−3, 상수자리 c=5.
항등식 — 수치대입법
🤔 굳이 전개 안 해도, x에 숫자를 넣으면?
❓ 던지는 질문

(x−1)³ = ax³+bx²+cx+d 가 x에 대한 항등식일 때, a+b+c+d의 값은?

직접 좌변을 전개해서 a,b,c,d를 하나씩 구해도 되지만, 더 빠른 길이 있어요 — 구하려는 건 결국 a+b+c+d인데, 우변에 x=1을 넣으면 a·1+b·1+c·1+d = a+b+c+d 가 그대로 나오지 않나요? 그럼 좌변에도 x=1을 넣어보면?

좌변에 x=1 대입: (1−1)³ = 0
우변에 x=1 대입: a+b+c+d
항등식이니 둘은 같다 → a+b+c+d = 0
수치대입법
항등식은 x에 어떤 값을 넣어도 성립하므로, 구하려는 값이 그대로 나오게 만드는 특별한 x를 골라 대입하면 전개하지 않고도 빠르게 답을 얻을 수 있다.
🦕 토로: 계수비교법과 수치대입법은 경쟁 관계가 아니라 같은 목적(미지수 구하기)을 위한 두 가지 도구예요. 식이 복잡하면 수치대입법이, 각 계수를 전부 알아야 하면 계수비교법이 더 편할 때가 많아요.
항등식 — 기본문제 (계수비교법)
기본 0-1 — 계수비교법으로 미지수 구하기
등식 2x²+ax−3 = bx²−5x+c 가 x에 대한 항등식일 때, a+b+c의 값을 구하세요.
💡 풀이
계수비교: x²자리 2=b, x자리 a=−5, 상수자리 −3=c
b=2, a=−5, c=−3 → a+b+c = −6
항등식 — 기본문제 (수치대입법)
기본 0-2 — 수치대입법으로 미지수 구하기
등식 (2x−1)² = ax²+bx+c 가 x에 대한 항등식일 때, a+b+c의 값을 구하세요.
💡 풀이
구하는 값 a+b+c는 우변에 x=1을 대입한 값과 같다
좌변에 x=1 대입: (2−1)² = 1
a+b+c = 1
📍 주제 1 — 다항식도 나눗셈이 될까?
다항식의 나눗셈 — 기본설명 (초등 나눗셈과 연결)
📐 몫과 나머지, 다항식도 똑같아요
초등학교 때 배운 13 ÷ 4부터 떠올려볼게요. 13개를 4개씩 묶으면 3묶음이 되고 1개가 남아요.

13 = 4 × 3 + 1
(나누어지는 수) = (나누는 수) × (몫) + (나머지), 단 나머지 < 나누는 수
다항식도 완전히 같은 구조예요. 다만 "나머지 < 나누는 수"라는 조건이 다항식에서는 "나머지의 차수 < 나누는 식의 차수"로 바뀔 뿐이에요.
P(x) = D(x) × Q(x) + R(x)
P(x): 다항식, D(x): 나누는 식, Q(x): 몫, R(x): 나머지 (단, R(x)의 차수 < D(x)의 차수)
다항식의 나눗셈 — 계산 과정 (세로 나눗셈 예제)
📐 실제로 나눠보기 — x³ + 3x² − 2x − 1 ÷ (x − 1)
❓ 예제

정수 나눗셈을 세로로 적었던 것처럼, 다항식도 아래로 내려쓰면서 나눠요 (핀란드 lukio 교재에서도 이 "jakokulma"라는 세로 나눗셈 표기를 그대로 씁니다). 규칙은 매 단계 "몫 자리 채우기 → 곱해서 빼기 → 다음 항 내리기"의 반복이에요.

맨 위 줄(x²+4x+2)이 몫, 맨 아래 남은 1이 나머지예요. 각 단계는 "그 자리 몫을 정하고 → x−1에 곱해서 → 빼고 → 다음 항을 내려서 잇기"의 반복입니다.
몫: x² + 4x + 2, 나머지: 1
x³+3x²−2x−1 = (x−1)(x²+4x+2) + 1
다항식의 나눗셈 — 기본문제
기본 1 — 직접 나눠서 몫과 나머지 구하기
다항식 2x³ − 3x² + 4x − 1 을 x − 1 로 나눈 몫과 나머지를 구하세요.
💡 풀이
몫: 2x²−x+3, 나머지: 2
검산: 2x³−3x²+4x−1 = (x−1)(2x²−x+3) + 2
다항식의 나눗셈 — 기본문제 (이차식으로 나누기)
기본 1-2 — 나누는 식이 이차식일 때
다항식 2x³ + x² − 4x + 3 을 x² + x − 1 로 나눈 몫과 나머지를 구하세요.
💡 풀이
방법은 똑같아요 — 나누는 식이 두 항 이상이어도 "맨 앞끼리 나누기 → 곱해서 빼기 → 내리기"를 반복하면 돼요.

1단계: 2x³÷x²=2x → 2x(x²+x−1)=2x³+2x²−2x → (2x³+x²)−(2x³+2x²−2x) = −x²+2x, −4x 내려서 −x²−2x+3
2단계: −x²÷x²=−1 → −1(x²+x−1)=−x²−x+1 → (−x²−2x+3)−(−x²−x+1) = −x+2 → 더 내릴 항 없음, 끝(차수1 < 나누는 식의 차수2)

몫: 2x−1, 나머지: −x+2
검산: (x²+x−1)(2x−1) + (−x+2) = 2x³+x²−4x+3
📍 주제 2 — 나머지정리: 나눗셈 없이 나머지 구하기
나머지정리 — 개념 (핀란드식·질문에서 출발하는 발견)
🤔 나눗셈을 안 하고도 나머지를 알 수 있을까?
❓ 던지는 질문

P(x) = x³ − 2x² + 3x − 4 를 x−2로 나눈 나머지가 궁금해요. 세로 나눗셈을 끝까지 안 하고도 알아낼 방법이 있을까요?

잠깐 멈추고 직접 생각해보세요 — 힌트: P(x) = (x−2)Q(x) + R 이라는 건 이미 알고 있어요. 이 식에서 Q(x)를 통째로 없애버릴 수 있는 x값이 있을까요?
P(x) = (x−2) × Q(x) + R
1단계 — 관찰
이 식은 어떤 x를 넣어도 항상 성립해요 — 주제0에서 배운 항등식 그대로예요. 그래서 아무 x나(원하는 값을 우리가 골라서!) 대입해도 여전히 참인 식이 나와요.

2단계 — 시도
x−2 뒤에 곱해진 Q(x)를 통째로 사라지게 하려면, x−2 자체가 0이 되면 돼요. x−2=0이 되는 x는? → x=2

3단계 — 대입해서 확인
x=2를 대입하면:
P(2) = (2−2) × Q(2) + R = 0 × Q(2) + R = R

4단계 — 일반화
방금은 x−2에서만 확인했지만, 나누는 식이 x−a 어떤 형태든 같은 논리가 그대로 통해요. x=a를 넣으면 x−a가 0이 되니까요.
나머지정리
다항식 P(x)를 x−a로 나눈 나머지는 P(a)이다.
x−b로 나눈 나머지는 마찬가지로 bx−cb 형태 대신, bx−c=0 → x=c/b를 대입한 P(c/b)이다.
🦕 토로: 공식을 외운 게 아니라 "Q(x)를 사라지게 하려면?"이라는 질문 하나에서 직접 이끌어낸 결과예요. 이렇게 얻은 건 잊어버려도 같은 질문을 다시 던지면 언제든 재구성할 수 있어요.
나머지정리 — 기본문제
기본 2 — 나눗셈 없이 나머지 구하기
다항식 P(x) = x³ − 3x² + 2x + 5 를 x−2로 나눈 나머지를 나눗셈 없이 구하세요.
💡 풀이
나머지정리: x−2로 나눈 나머지는 P(2)
P(2) = 2³ − 3(2²) + 2(2) + 5 = 8 − 12 + 4 + 5 = 5
나머지정리 — 기본문제 (미정계수)
기본 2-2 — 나머지 조건으로 미지수 구하기
다항식 P(x) = x³ + ax + 3 을 x−1로 나눈 나머지가 7일 때, 상수 a의 값을 구하세요.
💡 풀이
나머지정리: x−1로 나눈 나머지는 P(1)
P(1) = 1 + a + 3 = a + 4
조건: a + 4 = 7 → a = 3
나머지정리 — 기본문제 (분수 근)
기본 2-3 — 나누는 식이 2x−1처럼 계수가 1이 아닐 때
다항식 P(x) = 2x³ + ax² − x + 3 을 2x−1로 나눈 나머지가 4일 때, 상수 a의 값을 구하세요.
💡 풀이
2x−1=0 → x=1/2 (나머지정리는 나누는 식이 0이 되는 x를 대입하는 게 핵심 — 계수가 1이 아니어도 원리는 같아요)
P(1/2) = 2(1/8) + a(1/4) − 1/2 + 3 = 1/4 + a/4 − 1/2 + 3 = a/4 + 11/4
조건: a/4 + 11/4 = 4 → a/4 = 5/4 → a = 5
📍 나머지정리 연습문제 7제
나머지정리 연습 — 직접 대입 (기본)
연습 1
P(x) = x³ − 2x² + x + 4 를 x−1로 나눈 나머지를 구하세요.
💡 풀이
P(1) = 1 − 2 + 1 + 4 = 4
나머지정리 연습 — 분수 근
연습 2
P(x) = x³ − 4x + 1 을 (2x − 1)로 나눈 나머지를 구하세요.
💡 풀이
2x−1=0 → x=1/2 대입
P(1/2) = 1/8 − 4×(1/2) + 1 = 1/8 − 2 + 1 = −7/8
나머지정리 연습 — 합성식의 나머지 (개념인식 훈련)
연습 3
P(x) = x³ + 2x² − x + 3 일 때, P(x−1)을 x로 나눈 나머지를 구하세요.
💡 풀이
g(x)=P(x−1)이라 하면, g(x)를 x(=x−0)로 나눈 나머지는 나머지정리에 의해 g(0)
g(0) = P(0−1) = P(−1) = −1+2+1+3 = 5
함정: P(x−1)을 전개해서 풀 필요 없이, "무엇으로 나누는가"만 알아채면 바로 대입 한 번으로 끝나요.
나머지정리 연습 — 몫과 나머지의 관계식 (개념인식 훈련)
연습 4
다항식 P(x)를 x−1로 나누면 나머지가 3이고, 그 몫을 Q(x)라 하면 Q(x)를 x−2로 나눈 나머지가 5이다. P(x)를 x−2로 나눈 나머지를 구하세요.
💡 풀이
조건을 그대로 식으로: P(x) = (x−1)Q(x) + 3
양변에 x=2 대입: P(2) = (2−1)Q(2) + 3 = Q(2) + 3
Q(2)는 나머지정리에 의해 Q(x)를 x−2로 나눈 나머지, 즉 5
P(2) = 5 + 3 = 8
나머지정리 연습 — 곱과 합의 나머지
연습 5
두 다항식 P(x), Q(x)에 대해 P(1)=3, Q(1)=−2일 때, 다항식 P(x)Q(x) + 2P(x)를 x−1로 나눈 나머지를 구하세요.
💡 풀이
R(x)=P(x)Q(x)+2P(x)라 하면 나머지는 R(1)
R(1) = P(1)Q(1) + 2P(1) = 3×(−2) + 2×3 = −6+6 = 0
나머지정리 연습 — 나머지가 같다는 조건
연습 6
P(x) = x³ + ax + b 를 x−1로 나눈 나머지와 x−2로 나눈 나머지가 서로 같다고 한다. 상수 a의 값을 구하세요.
💡 풀이
P(1)=1+a+b, P(2)=8+2a+b
1+a+b = 8+2a+b → 1+a = 8+2a → a=−7
(b는 조건에서 저절로 사라짐 — 양변에서 소거되니까요)
나머지정리 연습 — 이차식으로 나눈 나머지 (실전훈련 맛보기)
연습 7
다항식 P(x)를 x−1로 나누면 나머지가 3, x+2로 나누면 나머지가 −3이다. P(x)를 (x−1)(x+2)로 나눈 나머지를 구하세요.
💡 풀이
나누는 식이 이차식이므로 나머지는 일차식 이하: R(x)=ax+b로 놓는다.
P(1)=a+b=3
P(−2)=−2a+b=−3
빼면: 3a=6 → a=2, b=3−a=1
나머지: 2x+1
이 유형(이차식으로 나눈 나머지, 조건 2개 연립)이 다음 파일(실전훈련)에서 본격적으로 다뤄져요.
📍 주제 3 — 인수정리: 나머지가 0이 될 때
인수정리 — 개념
📐 나머지 0 = 나누어떨어짐 = 인수
방금 배운 그림에서, 만약 R = 0이라면 어떻게 될까요? 오른쪽의 작은 블록이 아예 없어지고, P(x) 전체가 (x−a)×Q(x) 하나로만 딱 맞아떨어져요.

이건 "P(x)가 x−a로 나누어떨어진다" = "x−a는 P(x)의 인수이다"라는 뜻이에요. 나머지정리에서 나머지가 P(a)였으니, 그대로 이어집니다.
인수정리
다항식 P(x)에 대해, P(a) = 0 ⟺ x−a는 P(x)의 인수
즉 인수정리는 나머지정리의 특수한 경우(나머지가 하필 0인 경우)일 뿐, 새로운 공식이 아니에요.
인수정리 — 기본문제 (인수분해까지 연결)
기본 3 — 인수 확인하고 완전히 인수분해하기
다항식 P(x) = x³ − 2x² − 5x + 6 이 x−1을 인수로 갖는지 확인하고, 갖는다면 P(x)를 완전히 인수분해하세요.
💡 풀이
1단계 — 인수정리로 확인
P(1) = 1 − 2 − 5 + 6 = 0 → x−1은 P(x)의 인수 맞음

2단계 — 몫 구하기(나눗셈)
P(x) ÷ (x−1) = x² − x − 6 (나머지 0)

3단계 — 남은 이차식 인수분해
x² − x − 6 = (x−3)(x+2)

→ P(x) = (x−1)(x−3)(x+2)
인수정리 — 기본문제 (미정계수+인수분해 결합)
기본 3-2 — 인수 조건으로 미지수부터 구하고 인수분해
다항식 P(x) = x³ + ax² − 4 가 x−1을 인수로 가질 때, 상수 a의 값을 구하고 P(x)를 완전히 인수분해하세요.
💡 풀이
1단계 — 인수정리로 a부터 구하기
x−1이 인수이므로 P(1)=0: 1 + a − 4 = a − 3 = 0 → a = 3

2단계 — 조립제법으로 몫 구하기
P(x) = x³ + 3x² − 4, 계수 1,3,0,−4를 조립제법(a=1)으로 나누면 몫의 계수 1,4,4 → x²+4x+4

3단계 — 남은 이차식 인수분해
x²+4x+4 = (x+2)²

→ P(x) = (x−1)(x+2)²
📍 주제 4 — 조립제법: 나눗셈을 빠르게
조립제법 — 계수만으로 빠르게 나누기
📐 세로 나눗셈을 표 하나로 압축하기
아까 세로 나눗셈으로 x³+3x²−2x−1 을 x−1로 나눠서 몫 x²+4x+2, 나머지 1을 구했어요. 이번엔 계수만 뽑아서 표로 훨씬 빠르게 같은 답을 구해볼게요.

조립제법 절차
① 계수를 순서대로 적고, 나누는 값 a를 왼쪽에 적는다.
② 맨 앞 계수를 그대로 내려쓴다.
③ 내려온 수 × a를 다음 계수 아래에 적고 더한다.
④ ③을 마지막 칸까지 반복한다 — 마지막 칸이 나머지, 그 앞까지가 몫의 계수.
계수 1, 3, −2, −1 을 놓고, a=1로 실제 해볼게요:
113−2−1
142
↓1421
결과: 몫의 계수 1, 4, 2 → x²+4x+2, 나머지 1.
세로 나눗셈에서 구했던 답과 정확히 똑같아요 — 계산이 짧아졌을 뿐, 답은 항상 세로 나눗셈과 일치해요.
🦕 토로: 왜 하필 이 절차가 세로 나눗셈과 같은 답을 주는지는 지금 안 파고들어도 돼요. 지금은 "절차대로 하면 항상 같은 답이 나온다"는 걸 믿고 빠르게 쓸 수 있으면 충분해요. (참고로 핀란드에서는 이 방법을 Hornerin menetelmä라고 불러요 — 실제로 검색해서 확인함.)

📍 나머지정리 문제 해결 서랍
나머지정리 — 문제 유형별 해결 서랍 (총정리)
🗄️ "이 문제는 어느 서랍에 넣지?"
지금까지 배운 걸 문제를 만났을 때 바로 꺼내 쓸 수 있는 서랍으로 정리해요. 복잡해 보이는 문제도 "이거 몇 번 서랍이지?"부터 떠올리면 길이 보여요.

🗄️ 서랍 0 — R(x)는 이름표일 뿐, 반드시 실제 다항식으로 바꾸기 꺼내 쓰는 순간: 검산식을 세우는 바로 그 순간, 항상
문제에 "나머지 R(x)를 구하라"고 적혀 있어도, R(x)라는 글자 자체로는 대입도 계수비교도 할 수 없어요. 나누는 식의 차수를 보고 바로 구체적인 식으로 바꿔야 풀이가 시작돼요.
・일차식으로 나눔 → 나머지는 상수 → R(x)=r
・이차식으로 나눔 → 나머지는 일차 이하 → R(x)=ax+b
・삼차식으로 나눔 → 나머지는 이차 이하 → R(x)=ax²+bx+c
(나머지의 차수가 나누는 식의 차수보다 항상 작아야 한다는, 주제1에서 배운 원칙 그대로예요.)
🗄️ 서랍 1 — 검산식부터 무조건 쓰고 시작 꺼내 쓰는 순간: 뭘 어떻게 시작해야 할지 막막할 때
P(x) = (나누는 식) × Q(x) + R(x) 형태부터 일단 적는다. (R(x)는 서랍 0의 규칙대로 즉시 구체화한다.)
🗄️ 서랍 2 — Q(x)를 지우는 값 대입 (나머지정리·인수정리) 꺼내 쓰는 순간: 미정계수를 구해야 하거나 Q(x)가 거추장스러울 때
나누는 식이 0이 되는 x를 대입해서 Q(x)를 통째로 없앤다. 그 결과가 0이면 인수정리로 인수분해까지 연결한다.
🗄️ 서랍 3 — 몫 Q(x)도 하나의 다항식, 다시 나머지정리를 걸 수 있다 꺼내 쓰는 순간: 검산식에 등장하는 몫 Q(x)에 대한 조건이 따로 하나 더 주어질 때 (연습 4가 이 유형이었죠)
Q(x)도 결국 다항식이니, 서랍1(검산식)·서랍2(값 대입)를 Q(x)에다 한 번 더 적용하면 된다.

예: P(x)를 x−1로 나누면 나머지가 3이고, 그 몫을 Q(x)라 하자. Q(x)를 x−2로 나누면 나머지가 5이다. P(x)를 x−2로 나눈 나머지는?
① 서랍1: P(x) = (x−1)Q(x) + 3
② 구하려는 건 P(2). 식에 x=2를 대입: P(2) = (2−1)Q(2) + 3 = Q(2) + 3
③ Q(2)는 "Q(x)를 x−2로 나눈 나머지" 그 자체 → 조건에서 5
→ P(2) = 5 + 3 = 8
🗄️ 서랍 4 — 합성식은 "무엇을 구하는 문제인지"부터 재정의 꺼내 쓰는 순간: P(2x−1), P(x+3)처럼 괄호 안이 변형된 식이 나올 때 (연습 3이 이 유형)
겉모습에 겁먹지 말고 "이 문제가 결국 P(무슨 값)을 구하는 문제인지"부터 정확히 정의한다. 괄호 안이 원하는 숫자가 되도록 x를 거꾸로 추적해서 대입한다.

예: P(x)를 x+2로 나눈 나머지가 9일 때, P(x−2)를 x로 나눈 나머지는?
① 목표 재정의: "x로 나눈 나머지"는 x=0을 대입한 값 → 구하는 건 P(0−2) = P(−2)
② 겉보기엔 새 계산 같지만, "x+2로 나눈 나머지"가 이미 P(−2)와 같은 것(나머지정리)이므로
→ 조건에서 P(−2) = 9
🗄️ 서랍 5 — 나머지가 같거나 규칙이 보이면 통째로 이항 꺼내 쓰는 순간: P(1)=P(2)=P(3)=k 처럼 나머지가 같을 때, 또는 P(1)=2, P(2)=3, P(3)=4처럼 규칙이 보일 때
규칙식을 좌변으로 이항해서 P(x) − (규칙식) = 0 꼴로 만든다. 이 식은 x=1,2,3에서 모두 0이 되니까 (x−1)(x−2)(x−3)을 인수로 갖는다 → P(x) = (x−1)(x−2)(x−3)Q(x) + (규칙식) 형태로 통째로 다시 쓴다.
🦕 토로: 실전 문제는 서랍 하나로 안 끝나고 두세 개가 섞여 나올 때가 많아요 — "서랍 1(검산식)로 시작했는데 알고 보니 서랍 4(합성식)"인 경우처럼요. 문제를 풀 때마다 "이건 몇 번 서랍이었지?"를 적어보는 연습이 다음 파일(실전훈련)에서 훨씬 도움이 될 거예요. 다음 파일에서는 "P(x)를 (x−1)(x−2)로 나눈 나머지" 같은 조건이 여러 개 동시에 걸리는 문제(연습 7 참고)를 조립제법과 함께 본격적으로 다룹니다.
