📍 주제 0 — 인수분해 유형 다섯 가지부터 확인하기
인수분해 유형 — 도입 (닻: 다항식 단원 복습)
🔙 고차방정식을 풀기 전에, 인수분해 도구부터 다시 꺼내볼게요
고차방정식 P(x)=0을 풀 때 가장 먼저 하는 일은 P(x)를 인수분해하는 것이에요. 다항식 단원에서 배운 인수분해 방법은 딱 다섯 가지 유형으로 정리돼요 — 새 방정식을 만날 때마다 "이 다섯 개 중 뭐가 보이지?"를 순서대로 점검하는 게 습관이 되어야 해요.

② 인수분해 공식 이용하기
③ 치환으로 낮추기
④ 복이차식(치환이 안 통할 때)
⑤ 내림차순 정리(문자가 여러 개일 때)
하나씩 예제로 확인해볼게요.
인수분해 유형① — 공통인수
📐 ① 공통인수로 묶기 — 항상 제일 먼저 확인
모든 항에 공통으로 곱해진 문자·숫자가 있으면 가장 먼저 밖으로 묶어낸다.
2x³−8x = 2x(x²−4) = 2x(x−2)(x+2)
🦕 토로: 공통인수를 먼저 안 묶고 바로 공식부터 찾으려 하면 계산이 쓸데없이 커져요. 제일 먼저 습관적으로 확인하는 유형이에요.
인수분해 유형② — 공식
📐 ② 인수분해 공식 이용하기 — 눈에 익은 패턴 찾기
a²−b², (a±b)², a³±b³ 같은 곱셈공식의 패턴이 보이면 그대로 거꾸로 적용한다.
x⁴−16 = (x²−4)(x²+4) = (x−2)(x+2)(x²+4)
→ x²−4를 한 번 더 a²−b²로 분해할 수 있는지까지 확인!
🔗 연결: 주제 1의 x³±1=0도 결국 이 유형(a³±b³ 공식)이에요.
인수분해 유형③ — 치환
📐 ③ 치환으로 낮추기 — 반복되는 덩어리를 문자 하나로
똑같은 식 덩어리가 반복해서 보이면, 그 덩어리를 통째로 한 문자(보통 t)로 바꿔서 차수를 낮춘다.
(x²+x)²−8(x²+x)+12
t=x²+x로 치환 → t²−8t+12 = (t−2)(t−6)
다시 되돌리면 (x²+x−2)(x²+x−6) = (x−1)(x+2)(x+3)(x−2)
🦕 토로: 치환은 "복잡한 식을 단순한 문자로 잠깐 가려두는" 기술이에요. 다 풀고 나면 반드시 원래 문자로 되돌리는 것을 잊지 마세요.
인수분해 유형④ — 복이차식
📐 ④ 복이차식 — 치환이 안 통할 때 쓰는 한 수
x⁴+ax²+b 꼴(복이차식)은 보통 t=x²로 치환해서 풀어요. 그런데 치환한 이차식이 깔끔하게 인수분해되지 않을 때가 있어요 — 그럴 때 쓰는 특별한 기술이 있어요.
x⁴+4 (t=x²로 치환하면 t²+4 → 인수분해 안 됨!)
→ 가운데 항을 더하고 빼서 완전제곱을 만든다
x⁴+4 = x⁴+4x²+4 −4x² = (x²+2)² − (2x)²
= (x²+2x+2)(x²−2x+2)
신호: t=x²로 치환했는데 이차식의 판별식이 완전제곱수가 아니다 → 가운데 항(4x²)을 더하고 빼서 (완전제곱)²−(완전제곱)² 형태로 강제로 만든다.
🦕 토로: 복이차식은 치환의 "특수하고 어려운 사례"예요. 치환해서 바로 풀리면 그냥 유형③이고, 안 풀릴 때만 이 더하고 빼는 기술(유형④)을 씁니다.
인수분해 유형⑤ — 내림차순 정리
📐 ⑤ 내림차순 정리 — 문자가 여러 개 섞여 있을 때
문자가 두 개 이상 섞인 식은, 차수가 낮은 문자 하나를 기준으로 내림차순 정리하면 인수분해가 보이기 시작해요.
x²+2x+1−y²
x에 대해 내림차순 정리(이미 x²+2x+1이 보임) → (x²+2x+1)−y²
= (x+1)² − y² = (x+1+y)(x+1−y)
🦕 토로: 내림차순 정리는 "인수분해를 새로 하는 방법"이 아니라 식을 다시 배열해서 앞의 네 유형(특히 ②공식)이 보이게 만드는 준비 작업이에요. 문자가 여럿이라 막막할 때 가장 먼저 시도해보세요.
📍 주제 0-보충 — 다섯 유형으로도 안 보이면 (인수정리+조립제법)
고차방정식 — 도입 (닻: 다항식 단원 복습)
🔙 기억나요? 인수정리로 인수 하나를 찾는 법
다항식 단원에서 배운 걸 다시 불러올게요.

인수정리: P(a)=0이면 (x−a)는 P(x)의 인수다.
조립제법: 인수 하나를 찾으면, 조립제법으로 나눠서 차수를 하나 낮출 수 있다.
삼차방정식 x³−2x²−x+2=0을 예로 들어볼게요. x=1을 넣으면 1−2−1+2=0 — 인수정리로 (x−1)이 인수라는 걸 알았어요. 조립제법으로 나누면: 몫은 x²−x−2 = (x−1)(x+2) — 그래서 원래 식은 (x−1)(x−1)(x+2) = (x−1)²(x+2)로 완전히 인수분해돼요.
고차방정식을 만나면 이 순서로 시도한다
① 공통인수가 있는지 먼저 본다 (x로 묶이거나 괄호가 겹치는지)
② 유리근 후보 (상수항의 약수)(최고차항 계수의 약수) 를 하나씩 대입해 인수정리로 인수를 찾는다
③ 인수를 찾았으면 조립제법으로 차수를 낮춘다 — 삼차 이하가 되면 근의 공식이나 인수분해로 마무리
🦕 토로: 이 세 단계는 사실 다항식 단원에서 이미 다 배운 도구예요. "고차방정식"이라는 이름 때문에 새로운 게 나올 것 같지만, 실제로는 인수정리·조립제법을 "몇 번 반복해서 쓰느냐"의 문제예요. 다만 이 방법이 안 통하는 특수한 형태들이 있는데, 그건 주제 1·2에서 따로 배울 거예요.
고차방정식 — 기본문제
기본 0 — 인수정리+조립제법으로 삼차방정식 풀기
삼차방정식 x³−3x−2=0을 푸세요.
💡 풀이
유리근 후보 ±1, ±2 중 x=−1을 대입: −1+3−2=0 → (x+1)이 인수
조립제법으로 나누면 몫 x²−x−2 = (x+1)(x−2)
원래 식 = (x+1)²(x−2) = 0 → x=−1(중근) 또는 x=2
고차방정식 — 유사문제
🔄 유사문제로 연습하기
유사문제1: 삼차방정식 x³+2x²−5x−6=0을 푸세요.
유사문제2: 사차방정식 x⁴−2x³−x²+2x=0을 푸세요. (공통인수부터!)
📍 주제 1 — x³=1, x³=−1: 합·차의 공식으로 인수분해
x³±1=0 — 도입 (닻: 곱셈공식 복습)
🔙 기억나요? 세제곱의 합·차 공식
다항식 단원 곱셈공식에서 이 두 개를 배웠어요.

a³+b³ = (a+b)(a²−ab+b²)
a³−b³ = (a−b)(a²+ab+b²)
이 공식은 a=x, b=1을 넣으면 그대로 삼차방정식 x³=∓1의 인수분해 공식이 돼요. 즉, 새로 외울 게 아니라 이미 아는 공식에 숫자 1을 넣은 것뿐이에요.
x³=1 — 풀이 과정
📐 x³−1=0의 세 근 — 실근 하나, 허근 두 개
❓ 예제

x³=1, 즉 x³−1=0을 풀어볼게요.

x³−1 = (x−1)(x²+x+1) = 0
(x−1)=0 이면 x=1.
(x²+x+1)=0 이면 근의 공식으로 x = −1±√3i2 (판별식 D=1−4=−3<0 이므로 허근)

세 근: 1, −1+√3i2, −1−√3i2
🔗 연결: 이 허근 두 개는 복소수 단원에서 배운(또는 배울) ω(오메가)예요 — x³=1의 허근을 ω라 하면 ω³=1, ω²+ω+1=0이라는 성질이 그대로 여기서 나온 거예요. 복소수 거듭제곱 정복(레벨3)에서 이 ω를 다시 만나게 됩니다.
x³=−1 — 풀이 과정
📐 x³+1=0의 세 근
같은 방식으로 x³+1=0을 풀면:
x³+1 = (x+1)(x²−x+1) = 0
(x+1)=0 이면 x=−1.
(x²−x+1)=0 이면 x = 1±√3i2

🦕 토로: x³=1이든 x³=−1이든 구조는 완전히 똑같아요 — "부호 하나만 다른 곱셈공식을 그대로 대입한다"는 같은 서랍을 씁니다. 실전에서는 x³=1, x³=8, x³=−27처럼 오른쪽 숫자가 세제곱수로 바뀌어 나올 수 있는데, 그때도 8=2³, −27=(−3)³으로 보면 a=x, b=2 또는 b=−3을 넣는 것과 똑같아요.
x³±1=0 — 기본문제
기본 1 — 세제곱 방정식 풀기
방정식 x³=8을 푸세요. (단, 허근도 모두 구하세요)
💡 풀이
x³−8=0 → x³−2³=0 → (x−2)(x²+2x+4)=0
(x−2)=0 → x=2
(x²+2x+4)=0 → x = −2±√12i2 = −1±√3i
x = 2, −1+√3i, −1−√3i
x³=1의 허근 ω — 성질 총정리 (기출 필수)
🌀 ω(오메가) — 이 단원의 기본핵심, 다양하게 물어봐요
x³=1의 두 허근 중 하나를 ω라 부를게요.
(복소수 거듭제곱 정복 레벨3에 이미 ω 카드가 있는데, 그 성질들이 사실 여기서 그대로 나온 거예요.)

성질 1. ω³=1
정의 그 자체예요.
성질 2. ω²+ω+1=0
ω가 x²+x+1=0의 근이니까요 (앞에서 (x−1)(x²+x+1)=0으로 인수분해했죠).
성질 3. 1/ω = ω²
ω³=1 이므로 ω·ω²=1.
🔗 연결: 주제4의 조작②(역수)를 그대로 쓴 결과예요.
성질 4. ω의 켤레복소수도 ω²
x²+x+1=0은 계수가 실수 → 켤레근 정리(주제5)로 ω의 켤레도 근.
근이 ω, ω² 딱 둘뿐이니 ω̄=ω².
🦕 토로: 이 네 성질은 따로따로가 아니라, 이미 배운 도구 세 개(인수분해·역수·켤레근)를 x²+x+1=0 하나에 전부 적용한 결과예요. 참고로 x²+x+1=0은 계수가 1,1,1로 좌우대칭 — 사실 가장 짧은 상반방정식(주제2)이기도 해요!
❓ 기출형 질문 두 개

Q1. ω2024의 값은?
2024=3×674+2 → ω2024=ω3×674·ω²=ω²

Q2. (1+ω)(1+ω²)의 값은?
전개: 1+ω²+ω+ω³ = (1+ω+ω²)+ω³ = 0+1 = 1
📍 주제 2 — 상반방정식: 계수가 대칭이면 보이는 지름길
상반방정식 — 도입
🤔 이 사차방정식, 계수가 뭔가 이상하지 않나요?
❓ 던지는 질문

x⁴−3x³+4x²−3x+1=0 의 계수를 순서대로 적어볼게요: 1, −3, 4, −3, 1.

앞에서 읽어도 뒤에서 읽어도 똑같은 순서가 되죠? 이렇게 계수가 좌우대칭인 방정식을 상반방정식이라고 불러요. 이 대칭성을 이용하면 유리근 후보를 하나씩 대입하는 것보다 훨씬 빠르게 풀 수 있어요. x=0을 넣으면 상수항 1≠0이니 x=0은 근이 아니에요 — 그래서 양변을 x²로 나눠도 안전합니다.
상반방정식 — 풀이 과정 (치환)
📐 x+1/x = t 로 치환해서 차수 낮추기
x⁴−3x³+4x²−3x+1=0 을 x²으로 나누면:
x² − 3x + 4 − 3x + 1x² = 0
→ (x² + 1x²) − 3(x + 1x) + 4 = 0
여기서 t = x + 1x 로 치환하면, t² = x² + 2 + 1x² 이므로 x² + 1x² = t²−2 예요. 대입하면:
(t²−2) − 3t + 4 = 0 → t²−3t+2=0 → (t−1)(t−2)=0 → t=1 또는 t=2
t=1: x + 1x = 1 → x²−x+1=0 (허근)
t=2: x + 1x = 2 → x²−2x+1=0 → (x−1)²=0 → x=1(중근)
🦕 토로: 상반방정식은 "새 공식"이 아니라 "대칭이 보이면 x²으로 나누고 x+1/x를 t로 바꾼다"는 하나의 전략이에요. 사차 상반방정식뿐 아니라 육차까지도 같은 방식(t=x+1/x로 낮추기)이 통해요 — 핵심은 "계수가 대칭이다 → x²으로 나눈다"는 판단력입니다.
상반방정식 — 기본문제
기본 2 — 치환으로 상반방정식 풀기
방정식 x⁴+x³−4x²+x+1=0을 푸세요. (실근만 구하세요)
💡 풀이
계수 1,1,−4,1,1 — 대칭 확인. x²으로 나누면 (x²+1/x²)+(x+1/x)−4=0
t=x+1/x 로 치환: t²−2+t−4=0 → t²+t−6=0 → (t+3)(t−2)=0 → t=−3 또는 t=2
t=2: x+1/x=2 → x²−2x+1=0 → x=1(중근)
t=−3: x+1/x=−3 → x²+3x+1=0 → x = −3±√52 (실근)
실근: x=1, −3+√52, −3−√52
상반방정식 — 유사문제
🔄 유사문제로 연습하기
유사문제1: 사차방정식 x⁴−5x³+6x²−5x+1=0을 푸세요. (계수 대칭 확인!)
📍 주제 3 — 근과 계수의 관계: 이차에서 삼차로
근과 계수의 관계 — 도입 (닻: 이차방정식 복습)
🔙 기억나요? 이차방정식의 두 근의 합과 곱
이차방정식 단원에서 배운 걸 다시 볼게요.

ax²+bx+c=0의 두 근을 α, β라 하면
α+β = −ba, αβ = ca
🔗 연결: 똑같은 원리가 삼차방정식에도 그대로 적용돼요. 계수와 근 사이의 이 관계는 "이차 전용"이 아니라 "차수에 상관없이 통하는 원리"이기 때문이에요.
근과 계수의 관계 — 삼차방정식 확장
📐 삼차방정식의 세 근의 합·곱·짝지은 곱의 합
ax³+bx²+cx+d=0 의 세 근을 α, β, γ 라 하면:
α+β+γ = −ba
αβ+βγ+γα = ca
αβγ = −da
이차 ax²+bx+c=0삼차 ax³+bx²+cx+d=0
근의 합−b/a−b/a
근의 곱 (전부)c/a−d/a
짝지은 곱의 합—c/a
이 표에서 보이는 규칙: 부호는 (−1)ⁿ으로 번갈아 붙고, 항상 (최고차항이 아닌 계수)/(최고차항 계수)예요. 실전에서는 이 공식으로 세 근의 합·곱을 구한 뒤, α²+β²+γ² = (α+β+γ)²−2(αβ+βγ+γα) 같은 대칭식 변형(다항식 단원 곱셈공식과 같은 변형)을 묶어서 쓰는 문제가 자주 나와요.
근과 계수의 관계 — 기본문제
기본 3 — 세 근으로 만드는 새 삼차방정식
삼차방정식 x³−2x²+3x−4=0의 세 근을 α, β, γ라 할 때, α+β+γ와 αβγ의 값을 구하세요.
💡 풀이
a=1, b=−2, c=3, d=−4
α+β+γ = −b/a = 2
αβγ = −d/a = 4
근과 계수의 관계 — 유사문제
🔄 유사문제로 연습하기
유사문제1: 삼차방정식 2x³+3x²−x+5=0의 세 근을 α, β, γ라 할 때, αβ+βγ+γα의 값은?
유사문제2: 삼차방정식의 세 근이 α, β, γ이고 α+β+γ=3, αβ+βγ+γα=−2, αβγ=4일 때, α²+β²+γ²의 값은?
근과 계수의 관계 — 실전형 응용문제
📐 세 근을 몇 배 한 값들을 근으로 하는 새 방정식 (실전 기출형)
❓ 예제 (기출 패턴)

삼차방정식의 세 근이 α, β, γ일 때, 2α, 2β, 2γ를 세 근으로 하고 최고차항의 계수가 1인 새 삼차방정식을 만드는 문제가 실제 기출에 자주 나와요. 예를 들어 원래 방정식이 x³+px²+qx+r=0 (세 근 α,β,γ) 라면, 새 방정식의 근과 계수의 관계를 2α+2β+2γ, (2α)(2β)+(2β)(2γ)+(2γ)(2α), (2α)(2β)(2γ) 순서로 하나씩 원래 값의 2배·4배·8배로 바꿔서 새 식을 세워요.
왜 2배, 4배, 8배일까?
근의 합(1개씩) → 2배가 그대로 곱해짐 → 2¹배
짝지은 곱의 합(2개씩 곱함) → 2배가 두 번 곱해짐 → 2²배
세 근의 곱(3개 곱함) → 2배가 세 번 곱해짐 → 2³배
🦕 토로: "새 근이 원래 근의 k배"라는 문제는 근과 계수의 관계 3개를 한 번에 스케일링하는 문제예요. 합은 k배, 짝지은 곱의 합은 k²배, 전체 곱은 k³배 — 곱하는 근의 개수만큼 k가 곱해진다는 규칙만 기억하면 됩니다.
📍 주제 4 — 부호·순서를 바꾼 방정식과 원래 방정식의 근 관계
부호를 바꾼 방정식 — 도입 (조작①)
🤔 ① f(x)=0의 근이 α라면, f(−x)=0의 근은?
❓ 던지는 질문

f(x) = x³−2x²+3x−4 이고, f(α)=0이라고 해볼게요 (α는 f(x)=0의 근). 그럼 f(−x)=0의 근은 α와 무슨 관계일까요?

f(−x)에 x=−α를 넣어보면 f(−(−α)) = f(α) = 0이 돼요. 즉, x=−α를 넣었더니 f(−x)=0이 성립해요.
조작① 부호를 바꾼 방정식의 근
f(x)=0의 근이 α이면, f(−x)=0의 근은 −α이다.
(f(x)의 계수 부호를 항 순서대로 +,−,+,−… 번갈아 바꾼 식이 바로 f(−x)와 같은 식이 되기 때문)
이걸 계수로 확인하면 더 명확해요. f(x)=x³−2x²+3x−4의 항을 x³, x², x, 상수 순서로 볼 때, x가 홀수제곱(x³, x¹)인 자리는 −x를 넣으면 부호가 바뀌고, 짝수제곱(x², x⁰)인 자리는 부호가 그대로예요. 그래서 f(−x) = −x³−2x²−3x−4 = −(x³+2x²+3x+4) — 홀수차항의 부호만 바뀐 식이 됩니다.
부호를 바꾼 방정식 — 기본문제
기본 4-1 — 부호 반대 방정식의 근 찾기
삼차방정식 x³+x²−2x+3=0의 세 근이 α, β, γ일 때, x³−x²−2x−3=0의 세 근을 α, β, γ로 나타내세요.
💡 풀이
g(x)=x³−x²−2x−3이 f(x)=x³+x²−2x+3의 f(−x)인지 확인: f(−x) = −x³+x²+2x+3 = −(x³−x²−2x−3)
g(x) = −f(−x) 이므로 g(x)=0 ⟺ f(−x)=0 ⟺ (−x)가 f의 근 ⟺ x는 f의 근에 −1을 곱한 값
세 근: −α, −β, −γ
계수 순서를 뒤집은 방정식 — 도입 (조작②)
🤔 ② 이번엔 계수의 순서를 뒤집으면 근은 어떻게 될까?
❓ 던지는 질문

f(x) = x²−3x+2 = 0 을 풀면 (x−1)(x−2)=0 → 근은 1, 2예요.

이번엔 f(x)의 계수 1, −3, 2를 거꾸로 나열해서 새 식을 만들어볼게요: g(x) = 2x²−3x+1 = 0. 이걸 풀면 (2x−1)(x−1)=0 → 근은 1/2, 1이에요.

원래 근 {1, 2}와 새 근 {1/2, 1}을 나란히 놓아볼까요? 1/2 = 1/2, 1 = 1/1 — 새 근은 원래 근의 역수예요!
조작② 계수 순서를 뒤집은 방정식의 근
f(x)=anxn+…+a0=0 (a0≠0)의 근이 α(≠0)이면, 계수를 거꾸로 나열한 방정식 a0xn+…+an=0의 근은 1/α이다.
📐 왜 그럴까? — 먼저 삼차식으로 확인

삼차방정식 a3x3+a2x2+a1x+a0=0 의 근이 α(≠0)라고 해볼게요.

1단계. α를 대입하면 0이에요.
a3α3+a2α2+a1α+a0 = 0
2단계. 양변을 α³으로 나눠요.
a3 + a2α + a1α2 + a0α3 = 0
3단계. 계수를 거꾸로 나열한 식을 만들어요.
g(x) = a0x3+a1x2+a2x+a3
4단계. g(x)에 x=1/α를 대입해요.
g(1α) = a0α3 + a1α2 + a2α + a3
5단계. 2단계 식과 비교해요.
더하는 순서만 다를 뿐, 같은 네 항이에요.
그러니 g(1/α) = 0.
1/α는 g(x)=0의 근!
🦕 토로: 핵심은 딱 하나예요 — "αn으로 나누기"가 계수 순서를 뒤집는 효과를 만들어요. 나눗셈 한 번이면 충분해요.
📐 이제 일반적인 n차식으로 확인

차수가 몇이든 완전히 같은 논리예요.

1단계. n차방정식의 근 α를 대입.
anαn+an−1αn−1+…+a1α+a0 = 0
2단계. 양변을 αn으로 나눔.
an + an−1α + … + a0αn = 0
3단계. 이 식을 앞에서부터 읽으면, 계수를 거꾸로 나열한 식에 x=1/α를 넣은 것과 똑같아요.
부호+순서를 함께 바꾼 방정식 — 도입 (조작①+②)
🤔 ③ 순서도 뒤집고 부호도 바꾸면?
❓ 던지는 질문

이미 배운 두 조작을 순서대로 두 번 적용하면 끝이에요 — 새로 배울 게 없어요.

아까 f(x)=x²−3x+2=0 (근 1, 2)에 조작②(순서 뒤집기)를 먼저 적용해서 g(x)=2x²−3x+1=0 (근 1/2, 1)을 만들었죠. 여기에 조작①(부호 뒤집기 — 홀수차항 부호 반전)을 한 번 더 적용해볼게요: x항의 부호만 바꾸면 2x²+3x+1=0. 인수분해하면 (2x+1)(x+1)=0 → 근은 −1/2, −1.

원래 근 {1, 2}와 비교하면: −1/2 = −(1/2), −1 = −(1/1) — 음의 역수예요!
조작①+② 순서를 뒤집고 부호도 바꾼 방정식의 근
f(x)=0의 근이 α(≠0)이면, 계수 순서를 뒤집고 홀수차항 부호까지 반전한 방정식의 근은 −1/α이다.
네 가지 변환 — 총정리 (도구의 동일성)
🔗 사실 이건 새 규칙 세 개가 아니라, 스위치 두 개예요
지금까지 배운 조작 세 가지(①②③)는 사실 "부호를 바꾸느냐"와 "순서를 뒤집느냐"라는 독립된 스위치 두 개를 켜고 끄는 것뿐이에요. 표로 정리하면:
순서 그대로순서 뒤집기
부호 그대로α (원래 방정식)1/α (조작②)
부호 뒤집기−α (조작①)−1/α (조작①+②)
🦕 토로: 스위치가 두 개면 조합은 2×2=4가지뿐이에요. 새로운 걸 네 개 외우는 게 아니라, 두 개의 조작을 조합하는 문제라고 생각하면 헷갈릴 일이 없어요. 이건 이 교재에서 계속 강조하는 "도구의 동일성"의 좋은 예시예요 — 겉보기엔 네 가지 다른 방정식 같지만, 사실 두 스위치의 on/off 조합일 뿐이에요.
계수 순서를 뒤집은 방정식 — 기본문제
기본 4-2 — 역수를 근으로 하는 방정식 만들기
이차방정식 x²+5x+6=0의 두 근을 α, β라 할 때, 1/α, 1/β를 근으로 하고 계수가 모두 정수인 이차방정식을 구하세요.
💡 풀이
계수 1, 5, 6을 거꾸로 나열: 6x²+5x+1=0
(직접 확인: x²+5x+6=(x+2)(x+3)=0 → α,β=−2,−3. 1/α,1/β=−1/2,−1/3. 6x²+5x+1=(3x+1)(2x+1)=0 → x=−1/3,−1/2 ✓)
6x²+5x+1=0
부호+순서를 함께 바꾼 방정식 — 기본문제
기본 4-3 — 음의 역수를 근으로 하는 방정식 만들기 (실전형: 근을 몰라도 풀린다)
삼차방정식 x³+2x²−3x+1=0의 세 근이 α, β, γ일 때, −1/α, −1/β, −1/γ를 세 근으로 하고 최고차항의 계수가 1인 삼차방정식을 구하세요.
💡 풀이
이 삼차방정식은 실제로 풀 필요가 없어요 — 조작①+②만 적용하면 끝이에요.
1단계(순서 뒤집기, 계수 1,2,−3,1 → 1,−3,2,1): x³−3x²+2x+1=0
2단계(부호 뒤집기, 홀수차항인 x³·x항 부호 반전): −x³−3x²−2x+1=0
최고차항 계수를 1로 맞추기 위해 양변에 −1을 곱하면
x³+3x²+2x−1=0
📍 주제 5 — 실계수·유리계수 다항식의 켤레근 정리
켤레근 정리 — 도입 (실제 기출 표현)
🤔 허근 하나를 찾았는데, 왜 다른 근도 자동으로 정해질까?
❓ 던지는 질문

"삼차방정식의 모든 계수가 실수이므로 허수인 근의 켤레근을 가진다" — 실제 기출 해설에 그대로 나오는 문장이에요. 왜 계수가 실수라는 사실 하나만으로 켤레근까지 자동으로 정해질까요?

복소수 단원에서 배운 켤레복소수의 성질을 떠올려보면: z̄ (z의 켤레)를 사칙연산에 넣어도 켤레는 그대로 유지돼요 (예: ‾z+w 표기 대신 말로 하면, z+w의 켤레 = z̄+w̄). 계수가 전부 실수인 다항식 f(x)에 z를 대입해서 f(z)=0이 나왔다면, 양변에 켤레를 취해도 등식은 유지돼요 — 실수 계수는 켤레를 취해도 그대로(자기 자신의 켤레는 자기 자신)이기 때문에, f(z̄)도 결국 0이 될 수밖에 없어요.
실계수 다항식의 켤레근 정리
계수가 모두 실수인 다항식 방정식이 허근 z를 가지면, 그 켤레복소수 z̄도 반드시 근이다.
유리계수 다항식의 켤레 무리근 정리
계수가 모두 유리수인 다항식 방정식이 무리수근 a+b√m (a,b는 유리수, √m은 무리수)을 가지면, a−b√m도 반드시 근이다.
🦕 토로: 두 정리는 형태가 닮았지만 조건이 달라요 — 실계수 → 허근의 켤레, 유리계수 → 무리근의 켤레. "계수의 범위가 좁아질수록(실수→유리수), 짝지어지는 근의 종류도 달라진다"는 감각으로 구분하면 헷갈리지 않아요.
켤레근 정리 — 기본문제
기본 5 — 켤레근으로 나머지 근 찾기
실계수 삼차방정식의 한 근이 2−i이고, 다른 한 근이 1일 때, 이 방정식의 나머지 한 근을 구하세요.
💡 풀이
계수가 실수이므로 2−i의 켤레복소수 2+i도 근이다.
세 근은 이미 1, 2−i, 2+i로 다 찾았으므로 나머지 한 근: 2+i
켤레근 정리 — 유사문제
🔄 유사문제로 연습하기
유사문제1: 유리계수 삼차방정식의 한 근이 1−√2이고 다른 한 근이 3일 때, 나머지 한 근을 구하세요.
유사문제2: 실계수 사차방정식의 네 근 중 세 근이 3+2i, −1, 2일 때, 나머지 한 근을 구하세요.

허근 조건 — 도입 (닻: 판별식 복습, 도구의 동일성)
🔙 기억나요? 판별식으로 근의 종류 구분하기
이차방정식 단원에서 배운 판별식을 다시 불러올게요.

ax²+bx+c=0 (a,b,c는 실수)의 판별식 D=b²−4ac 일 때
D>0: 서로 다른 두 실근 D=0: 중근(실근) D<0: 서로 다른 두 허근
🔗 연결: 이 도구는 "이차방정식 전용"이 아니에요. 고차방정식을 인수정리로 낮추고 남은 이차식에 그대로 재사용돼요 — 그래서 진짜 "여러가지방정식다운" 판별식 문제는 삼차·사차식을 먼저 인수분해하는 것부터 시작해요.
허근 조건 — 실전형 (삼차방정식 인수정리+판별식)
📐 삼차방정식을 인수정리로 낮추고 남은 이차식에 판별식 적용
❓ 예제 (기출 패턴)

삼차방정식 x³−x²+kx−k=0이 오직 하나의 실근만 갖도록 하는 실수 k의 범위를 구하세요.

x=1을 대입: 1−1+k−k=0 — k값과 무관하게 항상 0이에요! (x−1)은 항상 인수.
조립제법으로 나누면 몫은 x²+k.
x³−x²+kx−k = (x−1)(x²+k) = 0
실근이 x=1 하나뿐이려면, 남은 인수 x²+k=0이 허근을 가져야 해요 (실근을 가지면 실근이 2개 이상 됨).
x²+k=0의 판별식 D=−4k < 0 → k > 0
🦕 토로: "몇 개의 실근을 갖는가"라는 질문은 인수정리로 하나를 떼어내고, 남은 이차식의 판별식으로 나머지를 센다는 이 조합이 핵심이에요. 이차식 하나만 보고 판별식을 쓴 게 아니라, 삼차식 전체를 먼저 쪼갠 뒤 쓴 거예요.
허근 조건 — 실전형 (사차방정식·복이차식+판별식)
📐 사차방정식은 복이차식(주제0 유형③④)으로 낮춘 뒤 판별식
❓ 예제 (기출 패턴)

사차방정식 x⁴+(k−1)x²−k=0이 서로 다른 두 실근과 두 허근을 갖도록 하는 실수 k의 범위를 구하세요.

짝수차항만 있으니 t=x²로 치환.
t²+(k−1)t−k = (t−1)(t+k) = 0 → t=1 또는 t=−k
t=1 → x²=1 → x=±1 (실근 두 개, k값과 무관하게 항상 나옴)
t=−k → x²=−k — 이게 허근이어야 나머지 두 근이 실근이 안 돼요.
x²=−k 가 허근 ⟺ −k<0 ⟺ k > 0
🦕 토로: 사차식이라고 겁먹을 필요 없어요 — 짝수차항만 있으면 치환(주제0 유형③)으로 이차식이 되고, 거기부터는 삼차방정식 예제와 완전히 같은 판별식 논리예요. "차수가 올라갈수록 도구가 늘어나는 게 아니라, 낮추는 방법이 늘어날 뿐"이라는 게 이 단원 전체의 결론이에요.
📍 총정리
고차방정식 — 문제 해결 서랍 총정리
🗄️ 고차방정식을 만나면 이 순서로 서랍을 열어보세요
🗄️ 서랍 0 — 기본 전략 (인수정리+조립제법) 공통인수 확인 → 유리근 후보 대입 → 조립제법으로 차수 낮추기. 특수한 형태가 안 보이면 항상 이 서랍부터 연다.
🗄️ 서랍 1 — x³=±(세제곱수) 꼴이 보이면 a³±b³ 공식을 그대로 대입. 오른쪽이 8, 27, −64처럼 세제곱수면 이 서랍.
🗄️ 서랍 2 — 계수가 좌우대칭이면(상반방정식) x=0이 근이 아님을 확인 → x²으로 나누기 → t=x+1/x로 치환.
🗄️ 서랍 3 — "세 근을 몇 배/몇 제곱 한 값" 문제가 보이면 직접 풀지 말고 근과 계수의 관계(합·짝지은곱의합·전체곱)를 스케일링해서 새 방정식을 세운다.
🗄️ 서랍 4 — "−α, 1/α, −1/α를 근으로 하는 새 방정식" 문제가 보이면 직접 풀지 말고 부호 스위치(홀수차항 부호 반전)와 순서 스위치(계수 나열 뒤집기)를 조합한다. 부호만=−α, 순서만=1/α, 둘 다=−1/α.
🗄️ 서랍 5 — 근 하나가 허수 또는 무리수로 주어지면 계수가 실수 → 켤레복소수도 근. 계수가 유리수이고 무리근이면 켤레 무리수도 근. 나머지 근을 바로 채워 넣을 수 있다.
🗄️ 서랍 6 — "실근이 몇 개인가" 같은 조건이 보이면 인수정리(또는 복이차식 치환)로 먼저 낮추고, 남은 이차식에 판별식을 적용한다. 이차식 자체는 중3 수준 도구지만, 그 앞에 "먼저 낮추기"가 이 단원의 핵심.
🦕 토로: 이 단원 전체를 한 줄로 요약하면 — "고차방정식은 새로운 산이 아니라, 다항식·이차방정식·복소수 단원에서 이미 등반해 본 길들을 이어 붙인 산길"이에요. 다음 파일에서는 이차연립방정식(두 이차식을 동시에 만족하는 해)과 부정방정식(정수 조건이 걸린 방정식)을 이어서 다룹니다.
