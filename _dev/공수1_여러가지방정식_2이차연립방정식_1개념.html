📍 주제 0 — 연립방정식 복습: 대입법이 왜 만능인지
연립방정식 — 도입 (닻: 중학교 복습)
🔙 기억나요? 미지수를 하나로 줄이는 두 가지 방법
중학교에서 배운 연립방정식 풀이법은 두 가지였어요.
가감법: 두 식을 더하거나 빼서 문자 하나를 없앤다.
대입법: 한 식을 "y=…" 꼴로 정리해서 다른 식에 그대로 밀어넣는다.
가감법은 두 식이 전부 일차식일 때만 깔끔해요 (계수를 맞춰 더하면 문자가 사라지니까). 그런데 이차식이 하나라도 섞이면 가감법으로는 문자가 안 사라져요.
🦕 토로: 그래서 이 단원에서는 대입법 하나만 있으면 충분해요. "한 문자를 다른 문자로 표현해서 밀어넣는다"는 원리 자체는 그대로고, 밀어넣는 대상이 이차식으로 바뀔 뿐이에요.
📍 주제 1 — 일차식+이차식의 연립방정식
일차+이차 연립 — 풀이 과정
📐 일차식을 이차식에 밀어넣기
❓ 예제

연립방정식 x+y=3, x²+y²=5 를 풀어볼게요.

일차식에서 y를 x로 표현: y=3−x
이걸 이차식에 대입:
x²+(3−x)² = 5
x²+9−6x+x² = 5
2x²−6x+4 = 0 → x²−3x+2 = 0 → (x−1)(x−2)=0
x=1 또는 x=2. 각각 y=3−x에 다시 넣으면:
(x,y) = (1,2) 또는 (2,1)
🦕 토로: 일차식은 항상 "한 문자를 다른 문자에 대한 식으로 정리하기 가장 쉬운 식"이에요. 그래서 연립방정식에 일차식이 하나라도 있으면, 그걸 먼저 정리해서 대입하는 게 순서예요.
일차+이차 연립 — 기본문제
기본 1 — 대입법으로 일차+이차 연립방정식 풀기
연립방정식 x−y=1, x²+y²=13 을 푸세요.
💡 풀이
x=y+1을 x²+y²=13에 대입: (y+1)²+y²=13 → 2y²+2y−12=0 → y²+y−6=0 → (y+3)(y−2)=0
y=−3 → x=−2, y=2 → x=3
(x,y) = (−2,−3) 또는 (3,2)
일차+이차 연립 — 유사문제
🔄 유사문제로 연습하기
유사문제1: 연립방정식 x+2y=5, x²−y²=5 를 푸세요.
📍 주제 2 — 이차식+이차식의 연립방정식: 인수분해형
이차+이차 연립 — 도입
🤔 이차식 두 개인데 어떻게 문자를 줄이지?
❓ 던지는 질문

연립방정식 x²−y²=0, x+2y=6 을 볼게요. 두 식 다 대입하기엔 애매해요 — 그런데 첫 번째 식을 자세히 보면?

x²−y²=(x−y)(x+y)=0 — 인수분해가 돼요! 곱이 0이라는 건 둘 중 하나가 0이라는 뜻이니까:
x−y=0 (즉 x=y) 또는 x+y=0 (즉 x=−y)
🔗 연결: 이건 고차방정식 단원(주제0 유형②)에서 배운 "곱이 0이면 케이스를 나눈다"는 원리를 연립방정식에 그대로 적용한 거예요. 이차식 하나가 인수분해되면, 연립방정식 하나가 두 개의 서로 다른 연립방정식으로 쪼개져요.
이차+이차 연립 — 풀이 과정
📐 두 갈래로 쪼개서 각각 풀기
방금 쪼갠 두 경우를 각각 x+2y=6과 연립해볼게요.
경우1) x=y 를 x+2y=6에 대입 → y+2y=6 → y=2, x=2
경우2) x=−y 를 x+2y=6에 대입 → −y+2y=6 → y=6, x=−6
(x,y) = (2,2) 또는 (−6,6)
🦕 토로: 인수분해형은 "연립방정식 1개 풀기"가 아니라 "간단한 연립방정식 2개를 따로 풀기"예요. 케이스를 나누는 순간 나머지는 전부 주제1(일차+이차)과 똑같습니다.
이차+이차 연립 — 기본문제
기본 2 — 인수분해로 케이스를 나눠 풀기
연립방정식 x²−xy−2y²=0, x−y=3 을 푸세요.
💡 풀이
x²−xy−2y² = (x−2y)(x+y) = 0 → x=2y 또는 x=−y
경우1) x=2y를 x−y=3에 대입: 2y−y=3 → y=3, x=6
경우2) x=−y를 x−y=3에 대입: −y−y=3 → y=−3/2, x=3/2
(x,y) = (6,3) 또는 (3/2,−3/2)
📍 주제 3 — 대칭연립방정식: 근과 계수의 관계 재사용
대칭연립방정식 — 도입 (닻: 근과 계수의 관계)
🔙 기억나요? 두 수의 합과 곱을 알면 이차방정식이 된다
고차방정식 단원(주제3)에서 배운 걸 거꾸로 써볼게요.

이차방정식 t²−(합)t+(곱)=0의 두 근이 바로 합과 곱이 그 값인 두 수다.
그러니까 연립방정식이 x+y=(어떤 수), xy=(어떤 수) 꼴로 정리되면, x와 y는 사실 하나의 이차방정식의 두 근이에요. 연립방정식을 푸는 게 아니라, 이차방정식 하나를 푸는 문제로 바뀌는 것이죠.
대칭연립방정식 — 풀이 과정
📐 합과 곱 → t²−(합)t+(곱)=0
❓ 예제

연립방정식 x+y=5, xy=6 을 풀어볼게요. (대입법으로 풀어도 되지만, 더 빠른 길이 있어요)
x, y는 t²−5t+6=0의 두 근
(t−2)(t−3)=0 → t=2 또는 t=3
(x,y) = (2,3) 또는 (3,2)
❓ 응용 — 합과 곱이 바로 안 보이면?

연립방정식 x+y=5, x²+y²=13 이라면, 두 번째 식이 곱(xy) 형태가 아니죠. 그런데 곱셈공식을 뒤집으면:
x²+y² = (x+y)²−2xy → 13 = 25−2xy → xy = 6
이제 x+y=5, xy=6이 됐으니 위와 똑같이 t²−5t+6=0으로 풀면 (x,y)=(2,3) 또는 (3,2).
🦕 토로: x²+y²을 (x+y)²−2xy로 바꾸는 이 변형은 고차방정식 단원(주제3)에서 이미 연습한 대칭식 변형이에요 — 같은 도구가 여기서도 그대로 쓰입니다.
대칭연립방정식 — 기본문제
기본 3 — 합과 곱으로 바꿔서 풀기
연립방정식 x+y=4, x²+y²=10 을 푸세요.
💡 풀이
x²+y²=(x+y)²−2xy → 10=16−2xy → xy=3
x,y는 t²−4t+3=0의 두 근 → (t−1)(t−3)=0 → t=1 또는 3
(x,y) = (1,3) 또는 (3,1)
대칭연립방정식 — 유사문제
🔄 유사문제로 연습하기
유사문제1: 연립방정식 x+y=6, xy=8 을 푸세요.
유사문제2: 연립방정식 x−y=2, xy=8 을 푸세요. (힌트: x+(−y)의 합·곱 형태로 바꿔보세요)
대칭연립방정식 — 심화 (치환 후 다시 연립방정식)
🔥 심화 — 치환했더니 s, p가 다시 연립방정식이 되는 경우
❓ 심화 예제

연립방정식 x+y+xy=7, x²y+xy²=12 를 만족시키는 실수 x, y를 구하세요.

두 번째 식을 인수분해하면 x²y+xy²=xy(x+y). s=x+y, p=xy로 치환하면:
s+p = 7
sp = 12
어? s와 p 자체가 합과 곱으로 주어진 연립방정식이 됐어요. 그러니 s, p는 다시 u²−7u+12=0의 두 근이에요 (같은 트릭을 한 번 더!).
u²−7u+12=0 → (u−3)(u−4)=0 → u=3 또는 4
(s,p) = (3,4) 또는 (4,3)
이제 각 (s,p)를 각각 t²−st+p=0에 넣어서 x, y를 구해요.
경우1) (s,p)=(3,4): t²−3t+4=0, D=9−16=−7<0 → 실근 없음 (버림)
경우2) (s,p)=(4,3): t²−4t+3=0 → (t−1)(t−3)=0 → t=1 또는 3
(x,y) = (1,3) 또는 (3,1)
🦕 토로: "합과 곱 → 이차방정식" 트릭을 두 번 쓰는 문제예요 — 한 번은 s,p를 구하려고, 한 번은 x,y를 구하려고. 그리고 (s,p)=(3,4) 쪽처럼 판별식이 음수가 나오면 그 경우는 버려야 한다는 걸 꼭 확인하세요 — 후보가 나왔다고 전부 답은 아니에요.
대칭연립방정식 — 심화 유사문제
🔄 유사문제로 연습하기
유사문제1: 연립방정식 x+y+xy=5, x²y+xy²=6 을 만족시키는 실수 x, y를 구하세요.
📍 주제 4 — 실전형: 매개변수+판별식 결합 (기출 확인)
실전형 — 도입 (닻: 판별식, 도구의 동일성)
🔗 실수해가 "존재하는가"도 결국 판별식
실제 기출에는 "연립방정식을 만족시키는 실수 x, y가 존재하도록 하는 자연수 k의 개수(또는 범위)를 구하라" 같은 문제가 나와요. (한영외고 기출 확인: "치환한 뒤 이차방정식이 실근을 가질 조건"을 그대로 쓰는 구조)

연립방정식이 대칭형(주제3)으로 정리되면, x,y는 t²−(합)t+(곱)=0의 두 근이에요. 이 t의 방정식이 실근을 가져야 x,y도 실수가 될 수 있겠죠 — 그래서 판별식이 다시 등장해요.
실전형 — 예제 (기출 패턴)
📐 대칭형으로 정리 → 판별식으로 k의 범위 찾기
❓ 예제 (기출 패턴)

연립방정식 x+y=k, xy=3 을 만족시키는 실수 x, y가 존재하도록 하는 자연수 k의 최솟값을 구하세요.

x, y는 t²−kt+3=0의 두 근. 실수 x,y가 존재 ⟺ 이 t의 방정식이 실근을 가져야 해요.
D = k²−4·3 = k²−12 ≥ 0 → k² ≥ 12 → k ≤ −2√3 또는 k ≥ 2√3
2√3 ≈ 3.46 이므로, 이를 만족하는 자연수 k 중 가장 작은 값은:
k = 4
🦕 토로: "실수해가 존재하도록 하는 k"라는 문구를 보면 반사적으로 대칭형(주제3)으로 바꾸고 판별식(D≥0)을 건다는 두 단계가 떠올라야 해요. 새 계산이 아니라, 이미 배운 두 도구를 순서대로 쓰는 것뿐이에요.
실전형 — 유사문제
🔄 유사문제로 연습하기
유사문제1: 연립방정식 x+y=k, xy=k+2 를 만족시키는 실수 x, y가 존재하도록 하는 정수 k의 최댓값을 구하세요.
📍 총정리
이차연립방정식 — 문제 해결 서랍 총정리
🗄️ 이차연립방정식을 만나면 이 순서로 서랍을 열어보세요
🗄️ 서랍 0 — 일차식이 하나라도 있으면 그 식을 "y=…" 꼴로 정리해서 다른 식에 그대로 대입한다.
🗄️ 서랍 1 — 이차식이 인수분해되면 곱이 0인 형태로 만들어 두 갈래로 쪼갠 뒤, 각 갈래를 남은 식과 따로 연립한다.
🗄️ 서랍 2 — x+y, xy 형태(또는 변형 가능)로 보이면 t²−(합)t+(곱)=0의 두 근으로 바꿔 푼다. x²+y², x²−y² 등은 곱셈공식으로 합·곱 형태로 바꿀 수 있는지 먼저 확인.
🗄️ 서랍 3 — "실수해가 존재하도록 하는 k" 조건이 보이면 대칭형(x+y, xy 형태)으로 바꾼 뒤 그 이차방정식의 판별식 D≥0을 건다. s,p 자체가 다시 연립방정식으로 나오면, 서랍2를 한 번 더 적용해서 s,p부터 구한다.
🦕 토로: 이 단원은 사실 새 도구가 하나도 없어요 — 대입법(서랍0), 인수분해(서랍1), 근과 계수의 관계(서랍2), 판별식(서랍3) 전부 앞에서 배운 것들이에요. "이차연립방정식"이라는 이름이 주는 위압감과 달리, 실제로는 이미 가진 도구를 조합하는 문제일 뿐이에요. 다음 파일에서는 정수 조건이 걸린 부정방정식을 다룹니다.
