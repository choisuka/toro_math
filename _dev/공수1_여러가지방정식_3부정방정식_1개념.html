📍 주제 0 — 부정방정식이란? 식보다 미지수가 많을 때
부정방정식 — 도입
🤔 x+y=5, 이 식 하나로 x,y를 다 구할 수 있을까?
❓ 던지는 질문

x+y=5 라는 식 하나만 있어요. x=1,y=4도 되고, x=2.5,y=2.5도 되고, x=100,y=−95도 돼요 — 해가 무수히 많아요.

보통 미지수가 2개면 식도 2개 있어야 해가 딱 하나(또는 몇 개)로 정해지는데, 식이 부족하면 이렇게 해가 정해지지 않아요(부정, 不定). 그런데 여기에 "x, y는 정수다" 같은 조건을 하나 걸면 어떻게 될까요? 무수히 많던 해가 갑자기 몇 개로 확 줄어들 수 있어요.
부정방정식: 식의 개수보다 미지수가 많아 해가 무수히 많은 방정식에, 정수·자연수·실수 같은 범위 조건을 걸어 유한 개(또는 하나)의 해만 골라내는 방정식.
🦕 토로: 이 단원은 딱 두 가지 조건만 다뤄요 — "정수(자연수)"일 때와 "실수"일 때. 조건에 따라 쓰는 도구가 완전히 다르니, 문제를 보자마자 어떤 조건인지부터 확인하는 습관이 제일 중요해요.
📍 주제 1 — 정수 조건: AB=k 꼴 만들기
정수 조건 — 도입 (닻: 인수분해, 내림차순 정리)
🔙 곱해서 특정 수가 되는 정수 쌍은 몇 개 없다
정수 A, B에 대해 A×B=5라면, A와 B는 5의 약수 쌍뿐이에요: (1,5),(5,1),(−1,−5),(−5,−1). 무한하지 않고 딱 4쌍이죠.

이 아이디어를 이용해요 — xy가 섞인 식을 (x+b)(y+a)=상수 꼴로 인수분해할 수 있으면, 약수 쌍을 나열해서 정수해를 전부 찾을 수 있어요.
정수 조건 — 풀이 과정 (그룹핑)
📐 xy+ax+by+c=0을 (x+b)(y+a)=상수로 바꾸기
❓ 예제

xy−2x−3y+1=0 을 만족하는 정수 x, y를 모두 구하세요.

x가 있는 항끼리 묶어요:
x(y−2) − 3y + 1 = 0
x(y−2) − 3(y−2) − 6 + 1 = 0
(x−3)(y−2) = 5
5의 약수 쌍을 전부 나열하면:
(x−3,y−2) = (1,5),(5,1),(−1,−5),(−5,−1)
→ (x,y) = (4,7), (8,3), (2,−3), (−2,1)
🔗 연결: "x가 있는 항끼리 묶는다"는 이 과정은 고차방정식 단원(유형⑤ 내림차순 정리)에서 배운 "한 문자를 기준으로 정리한다"는 원리와 같아요.

매번 이렇게 묶기 번거로우니, 일반형으로 외워두면 편해요:
xy+ax+by+c=0 → (x+b)(y+a) = ab−c
🦕 토로: 확인해볼게요 — 위 예제는 a=−2, b=−3, c=1 이니까 ab−c = 6−1 = 5. 맞아요!
정수 조건 — 기본문제
기본 1 — 그룹핑으로 AB=k 꼴 만들어 정수해 찾기
xy−x−2y−1=0 을 만족하는 정수 x, y의 순서쌍의 개수를 구하세요.
💡 풀이
x(y−1) − 2y − 1 = 0 → x(y−1) − 2(y−1) − 2 − 1 = 0 → (x−2)(y−1) = 3
3의 약수 쌍: (1,3),(3,1),(−1,−3),(−3,−1) → 4개
정수 조건 — 유사문제
🔄 유사문제로 연습하기
유사문제1: xy+2x−y−7=0 을 만족하는 정수 x, y의 순서쌍의 개수를 구하세요.
정수 조건 — 심화 (그룹핑이 안 통할 때)
🔥 심화 — x², y²이 섞여 그룹핑이 안 통하면: 내림차순+판별식
❓ 던지는 질문

지금까지 본 식은 전부 xy 하나만 있고 x², y²은 없었어요. 그런데 x²이나 y²이 함께 있으면 (x+b)(y+a)=k 꼴로 그룹핑이 안 통할 때가 있어요. 이럴 땐 어떻게 할까요?

❓ 예제

x²+xy+y²−x−y−1=0 을 만족하는 정수 x, y를 모두 구하세요.

x²+xy+y²는 정수 계수로 인수분해가 안 돼요 — 그룹핑이 막혔으니, x에 대한 이차방정식으로 보고 내림차순 정리합니다.
x² + (y−1)x + (y²−y−1) = 0
x가 실수이려면 판별식 D≥0.
D = (y−1)² − 4(y²−y−1) = −3y²+2y+5 ≥ 0
이 부등식을 풀면 −1≤y≤5/3 — 정수 y는 −1, 0, 1 셋뿐으로 좁혀져요. 이제 하나씩 대입해서 D가 완전제곱수인지(=x가 정수인지) 확인합니다.
y=−1: D=0 (완전제곱) → x=1
y=0: D=5 (완전제곱 아님) → 정수 x 없음
y=1: D=4 (완전제곱) → x=1 또는 −1
정수해: (1,−1), (1,1), (−1,1) — 3개
🦕 토로: 여기엔 두 단계 필터가 있어요 — ①D≥0은 "x가 실수로 존재할 조건"이고, ②D가 완전제곱수는 "그 x가 정수일 조건"이에요. ①로 y의 후보를 확 줄이고, ②로 진짜 정수해만 골라내는 순서예요. 🔗 연결: D≥0으로 범위를 좁히는 이 과정은 이차연립방정식 단원(서랍3)의 판별식 활용과 완전히 같은 도구예요.
정수 조건 — 심화 유사문제
🔄 유사문제로 연습하기
유사문제1: x²+xy+y²−2x−y−2=0 을 만족하는 정수 x, y를 모두 구하세요.
📍 주제 2 — 실수 조건: 완전제곱의 합=0
실수 조건 — 도입 (닻: 다항식 단원 완전제곱식)
🔙 제곱은 절대 음수가 되지 않는다
실수를 제곱하면 항상 0 이상이에요 — 이 당연한 사실이 이번 도구의 전부예요.
A, B가 실수일 때, A²+B²=0 ⟺ A=0 이고 B=0
(둘 다 0 이상인데 합이 0이려면, 각각 0일 수밖에 없다)
그래서 실수 조건의 부정방정식은 주어진 식을 (완전제곱)+(완전제곱)=0 꼴로 만드는 것이 목표예요. 다항식 단원 곱셈공식(완전제곱식 x²±2ax+a²=(x±a)²)을 그대로 씁니다.
실수 조건 — 풀이 과정
📐 완전제곱 두 개로 쪼개기
❓ 예제

x²+y²−4x+6y+13=0 을 만족하는 실수 x, y를 구하세요.

x끼리, y끼리 모아서 완전제곱을 만들어요.
(x²−4x+4) + (y²+6y+9) = 13−4−9
(x−2)² + (y+3)² = 0
x−2=0 이고 y+3=0 → x=2, y=−3
🦕 토로: 상수항을 나눠 넣는 계산(13−4−9)이 헷갈리면, 완전제곱 만들 때 더한 만큼 반대쪽에서 빼준다고 생각하세요 — x²−4x에 +4를 더했으니, 등호를 맞추려면 우변에도 +4를 더해야 해요.
실수 조건 — 기본문제
기본 2 — 완전제곱의 합으로 실수해 찾기
x²+4y²−2x+16y+17=0 을 만족하는 실수 x, y를 구하세요.
💡 풀이
(x²−2x+1) + (4y²+16y+16) = 17−1−16 → (x−1)² + 4(y+2)² = 0
x−1=0 이고 y+2=0 → x=1, y=−2
실수 조건 — 유사문제
🔄 유사문제로 연습하기
유사문제1: x²+y²+6x−4y+13=0 을 만족하는 실수 x, y를 구하세요.
📍 주제 3 — 판별 훈련: "정수"냐 "실수"냐로 풀이가 완전히 갈린다
판별 훈련 — 대비쌍
🔍 겉모습은 비슷한데, 조건 단어 하나가 풀이를 바꾼다
아래 두 문제를 나란히 비교해보세요. 식의 생김새는 비슷해 보이지만, 조건 단어 하나가 완전히 다른 도구를 요구해요.
A. 정수 조건 xy−x−y−5=0을 만족하는 정수 x, y의 순서쌍의 개수는?
B. 실수 조건 x²+y²−2x+2y+2=0을 만족하는 실수 x, y의 순서쌍의 개수는?
A 풀이: x(y−1) −(y−1) −6=0 → (x−1)(y−1)=6 → 6의 약수 쌍 8개 → 8개
B 풀이: (x−1)²+(y+1)²=0 → x=1,y=−1 하나뿐 → 1개
🦕 토로: A는 "곱해서 6이 되는 정수 쌍이 몇 개나 있지?"를 묻는 문제라 답이 여러 개고, B는 "제곱의 합이 0이 되려면?"을 묻는 문제라 답이 정확히 하나예요. 문제를 읽을 때 "정수"·"실수"라는 단어에 반드시 형광펜을 긋는 연습을 하세요 — 이 단어 하나가 전체 풀이 방향을 결정합니다.
판별 훈련 — 세 번째 함정 (판별식이 필요한 경우)
🔍 "정수" 조건인데 그룹핑도 안 통하면?
A, B는 각각 그룹핑(서랍0)과 완전제곱(서랍1)으로 바로 풀렸죠. 그런데 "정수" 조건인데 x², y²이 섞여 그룹핑도 안 통하는 경우가 있어요 — 이땐 주제1 심화에서 배운 내림차순+판별식(서랍2)까지 가야 해요.
판별식 사용한 문제 x²−xy+y²−3x+3=0 을 만족하는 정수 x, y를 구하세요.
x²−xy+y²는 정수 계수로 인수분해가 안 되니 서랍0(그룹핑) 실패 → x에 대해 내림차순: x²+(−y−3)x+(y²+3)=0
D=(y+3)²−4(y²+3) = −3y²+6y−3 = −3(y−1)² ≥ 0 은 y=1일 때만 성립(D=0)
x=(y+3)/2=(1+3)/2=2
정수해: (x,y)=(2,1) — 유일하다
🦕 토로: "정수"라는 단어만 보고 반사적으로 그룹핑부터 시도하면 안 돼요 — 먼저 xy만 있는지(그룹핑 가능), x²·y²까지 섞여 있는지(판별식 필요)를 식의 모양으로 먼저 확인하세요. 조건 단어(정수·실수) 하나, 식의 모양(xy만 vs x²·y²도) 하나 — 이 두 가지를 같이 봐야 서랍을 제대로 고를 수 있어요.
📍 주제 4 — 실전형: 자연수 조건 (정수 조건 위에 필터 하나 더)
실전형 — 도입
🔗 "자연수"는 "정수"보다 한 단계 더 좁은 조건
실전 문제에서는 "정수"보다 "자연수" 조건이 더 자주 나와요. 자연수는 1 이상의 정수니까, 정수 조건으로 구한 해들 중에서 x≥1, y≥1인 것만 다시 골라내면 돼요 — 새 도구가 아니라 주제1 위에 필터 하나를 더 얹는 것뿐이에요.
실전형 — 예제 (표준 패턴, 참고자료에 이 정확한 형태의 기출은 없어 직접 설계)
📐 정수해를 다 구한 뒤, 자연수 조건으로 한 번 더 거르기
❓ 예제

xy−3x−2y=0 을 만족하는 자연수 x, y의 순서쌍의 개수를 구하세요.

먼저 정수 조건처럼 그룹핑: x(y−3) −2y=0 → x(y−3) −2(y−3) −6=0 → (x−2)(y−3)=6
6의 약수 쌍(정수 전체): (1,6)(2,3)(3,2)(6,1)(−1,−6)(−2,−3)(−3,−2)(−6,−1)
→ (x,y): (3,9)(4,6)(5,5)(8,4)(1,−3)(0,0)(−1,1)(−4,2)
이제 x≥1, y≥1(자연수) 조건으로 걸러내면:
(3,9), (4,6), (5,5), (8,4) → 4개
(나머지 4개는 x 또는 y가 1보다 작아서 탈락)
🦕 토로: "정수"로 물으면 8개, "자연수"로 물으면 4개 — 같은 방정식인데 조건 하나로 답이 반토막이 나요. 약수 쌍을 다 나열한 다음, 마지막에 범위 조건으로 한 번 더 체크하는 습관을 들이세요.
실전형 — 유사문제
🔄 유사문제로 연습하기
유사문제1: xy−4x−3y=0 을 만족하는 자연수 x, y의 순서쌍의 개수를 구하세요.
📍 총정리
부정방정식 — 문제 해결 서랍 총정리
🗄️ 부정방정식을 만나면 이 순서로 서랍을 열어보세요
🗄️ 서랍 0 — "정수" 또는 "자연수" 조건이면 xy+ax+by+c=0 꼴로 그룹핑해서 (x+b)(y+a)=ab−c 를 만들고, 약수 쌍을 전부 나열한다. "자연수"면 x≥1,y≥1 필터를 마지막에 한 번 더 건다.
🗄️ 서랍 1 — "실수" 조건이면 x끼리, y끼리 모아 완전제곱의 합=0 꼴로 만든다. A²+B²=0 ⟺ A=0이고 B=0.
🗄️ 서랍 2 — 그룹핑·완전제곱이 바로 안 보이면 한 문자(보통 x)에 대해 내림차순으로 정리부터 한다(고차방정식 유형⑤). 정리하고 나면 서랍0·1의 형태가 드러나는 경우가 많다. 그래도 서랍0(AB=k)을 못 쓰면(x²·y²이 섞여 인수분해가 안 되면), x에 대한 이차방정식으로 보고 판별식을 쓴다 — D≥0으로 y의 범위를 좁히고, D가 완전제곱수인 y만 골라 정수 x를 구한다.
🦕 토로: 부정방정식은 사실 "조건 단어를 읽고 서랍0을 열지, 서랍1을 열지 판단하는 것"이 유일한 새 기술이에요. 그룹핑(인수분해)도, 완전제곱식도, 전부 이미 배운 도구고요. 이걸로 "여러 가지 방정식" 3부작(고차방정식 → 이차연립방정식 → 부정방정식)이 끝났어요 — 세 파일 전부 같은 도구 상자(인수분해·근과 계수의 관계·판별식·완전제곱)를 여러 각도에서 다시 쓴 것이라는 감각을 꼭 챙겨 가세요.
