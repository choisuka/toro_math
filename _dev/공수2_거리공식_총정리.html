📍 평면좌표 단원 — 두 점 사이의 거리
평면좌표 단원 — 거리 공식 개념 1
수직선 위, 두 점 사이의 거리
가장 단순한 경우부터: 수직선(1차원) 위에 두 점 A(a), B(b)가 있으면, 거리는 그냥 두 좌표의 차의 절댓값이에요.

AB = |b − a|
예: A(2), B(7) → AB = |7−2| = 5. A(−3), B(4) → AB = |4−(−3)| = 7.

순서를 바꿔 |a−b|로 써도 결과는 같아요 — 절댓값이 부호를 없애주니까요.
평면좌표 단원 — 거리 공식 개념 2 (1의 확장)
평면 위, 두 점 사이의 거리
이제 2차원(평면)으로 넘어가면? x축 방향 차이와 y축 방향 차이를 각각 수직선 거리(개념 1)로 구한 다음, 피타고라스 정리로 합쳐요.

AB = √{(x₂−x₁)² + (y₂−y₁)²}
예: A(1,2), B(4,6) → AB = √{(4−1)²+(6−2)²} = √(9+16) = √25 = 5

🦕 토로: 사실 (x₂−x₁)과 (y₂−y₁) 자체가 각각 "x축 방향 수직선 거리", "y축 방향 수직선 거리"예요 — 개념 1을 두 번 쓰고 피타고라스로 묶은 것뿐, 완전히 새로운 공식이 아니에요.
📏 직선의 방정식 단원 — 직선과 관련된 거리
직선의 방정식 단원 — 거리 공식 개념 3 (2의 응용)
점과 직선 사이의 거리
점에서 직선까지의 거리는, 점에서 직선에 수선을 내려 만나는 점까지의 거리예요 — 결국 "두 점 사이의 거리"(개념 2)인데, 그 발까지의 좌표를 직접 구하는 대신 훨씬 빠른 공식을 써요.

점 P(x₀, y₀)와 직선 ax+by+c=0 사이의 거리:
d = |ax₀+by₀+c|√(a²+b²)
예: 점 (1,2)와 직선 3x+4y−6=0 사이의 거리 = |3(1)+4(2)−6|√(9+16) = |5|5 = 1
직선의 방정식 단원 — 거리 공식 개념 4 (3의 확장)
직선과 직선 사이의 거리 (평행할 때)
두 직선이 평행할 때만 "직선 사이의 거리"가 의미 있어요(만나는 두 직선은 거리가 0이니까). 방법은 간단 — 한 직선 위에서 점 하나를 아무거나 잡아서, 개념 3(점과 직선 거리)을 그대로 쓰면 돼요.

두 평행선 ax+by+c₁=0, ax+by+c₂=0 사이의 거리:
d = |c₁−c₂|√(a²+b²)
예: 3x+4y−2=0과 3x+4y+8=0 사이의 거리 = |−2−8|5 = 105 = 2

이 공식이 성립하는 이유: 한 직선 위의 아무 점이나 잡아 개념 3에 대입하면, 항상 |c₁−c₂|/√(a²+b²)로 정리돼요 — 어느 점을 잡아도 같은 값이 나오는 게 "평행"의 성질이에요.
🔵 원의 방정식 단원 — 원과 관련된 거리
원의 방정식 단원 — 거리 공식 개념 5 (2의 응용)
원과 점 사이의 거리
원 밖의 한 점 P에서 원 위의 점까지 거리는 어디를 재느냐에 따라 달라져요 — 그래서 "최단 거리"와 "최장 거리"를 따로 구해요. 핵심은 먼저 중심 C와 점 P 사이의 거리(개념 2)부터 구하는 거예요.

점 P가 원 밖에 있고, 중심 C, 반지름 r, CP = d 일 때
최단 거리 = d − r    최장 거리 = d + r
예: 원 (x−2)²+(y−1)²=9(중심(2,1), r=3), 점 P(2,9)일 때
CP = √{(2−2)²+(9−1)²} = √64 = 8 (개념 2 그대로 사용) → 최단거리 = 8−3=5, 최장거리 = 8+3=11

만약 점이 원 안에 있으면(d<r)? 최단거리는 r−d, 최장거리는 d+r로 바뀌어요 — 그림을 그려보면 부호가 왜 바뀌는지 바로 보여요.

🔗 바로 다음 개념 6(원과 직선)에서, 재는 대상이 "점"에서 "직선"으로 바뀌어도 이 d−r, d+r 공식이 글자 그대로 다시 나와요 — 미리 기억해두세요.
원의 방정식 단원 — 개념 5 예제
최단·최장거리로 "자연수인 점의 개수" 세기
원 x²+y²=4(중심 O, r=2) 위를 움직이는 점 P와 고정점 A(5,0)이 있어요. 선분 AP의 길이가 자연수가 되는 점 P는 몇 개일까요?

OA=5(개념 2) → 최단거리=5−2=3, 최장거리=5+2=7(개념 5)
P가 원을 한 바퀴 돌 때 AP는 3→7→3으로 연속 변화하므로 [3,7]의 모든 값을 지나가요.
양 끝(3, 7)은 직선 OA 위의 점에서 각 1개씩, 중간값(4,5,6)은 직선 OA 기준 대칭인 두 점에서 각 2개씩.
개수 = 1+1+2+2+2 = 8개
최단·최장거리가 자연수일 때 vs 아닐 때
Case A(자연수): 원 (x−3)²+(y−4)²=4, 점 (0,0) → 중심거리=√(9+16)=5 → 최단=5−2=3, 최장=5+2=7 (둘 다 자연수)
Case B(자연수 아님): 원 x²+y²=9, 점 (4,4) → 중심거리=√(16+16)=4√2≈5.66 → 최단=4√2−3≈2.66, 최장=4√2+3≈8.66 (둘 다 자연수 아님)
최단·최장거리가 자연수가 되려면, 먼저 중심과 점 사이의 거리(개념 2) 자체가 자연수여야 해요 — 3-4-5 같은 "피타고라스 세 쌍"이 되는지부터 확인하는 습관을 들이세요.
원의 방정식 단원 — 거리 공식 개념 6 (3,5의 응용)
원과 직선 사이의 거리
"원과 직선 사이의 거리"는 사실 원과 점(개념 5)과 똑같은 아이디어예요 — 다만 재는 대상이 점 P 대신 중심에서 직선까지의 거리로 바뀔 뿐이에요.

중심 C(a,b), 반지름 r, 직선 px+qy+s=0까지의 거리 d = |pa+qb+s|√(p²+q²) (개념 3의 점과 직선 사이 거리 공식) 을 구한 뒤:

d < r → 서로 다른 두 점에서 만남
d = r → 한 점에서 만남(접함)
d > r → 만나지 않음
예: 원 x²+y²=4(중심(0,0), r=2), 직선 x+y−4=0일 때
d = |0+0−4|√2 = 4√2 = 2√2 ≈ 2.83 > 2 → 만나지 않음

🦕 토로: 여기서 쓰는 "점과 직선 사이의 거리 공식"은 바로 위 개념 3에서 배운 걸 그대로 가져오는 거예요 — 새로 외울 건 "d와 r을 비교한다"는 판정 규칙뿐이에요.

🔗 개념 5(원과 점)와 완전히 똑같은 도구
원 위를 움직이는 점 X에서 직선까지의 최단·최장 거리도 구할 수 있어요 — 방법은 개념 5에서 "점 P" 대신 "직선"으로 재는 대상만 바꾼 것뿐:

최단 거리 = d − r    최장 거리 = d + r

예: 위와 같은 원(중심(0,0), r=2), 직선 x+y−4=0(d=2√2)일 때, 원 위의 점에서 이 직선까지
최단 거리 = 2√2−2, 최장 거리 = 2√2+2
개념 5의 "d−r, d+r"과 여기 "d−r, d+r"이 글자 그대로 똑같죠 — d를 구하는 방법(두 점 사이 거리 vs 점과 직선 사이 거리)만 다를 뿐, 원 관련 최단·최장 거리는 결국 하나의 도구예요.
원의 방정식 단원 — 개념 6 예제
최단·최장거리를 삼각형 넓이 최대·최소로 확장하기
두 점 A(0,0), B(6,0)이 있고, 원 (x−3)²+(y−5)²=4 위를 점 P가 움직여요. 삼각형 PAB의 넓이의 최댓값과 최솟값은?

밑변 AB=6(고정)이므로 넓이 = 12×6×(P에서 직선 AB까지의 거리) — 결국 필요한 건 P에서 직선 AB(x축)까지의 최단·최장거리(개념 6)예요.

중심(3,5)에서 x축까지 거리 d=5, r=2 → 최단거리=5−2=3, 최장거리=5+2=7

최소 넓이 = 12×6×3 = 9    최대 넓이 = 12×6×7 = 21
"넓이의 최대·최소"라고 물어봐도 결국 밑변은 고정이니, 높이의 최대·최소(=개념 6의 최단·최장거리)로 바꿔 생각하면 끝이에요.
원의 방정식 단원 — 거리 공식 개념 7 (2와 6의 결합)
원과 원 사이의 거리 (두 원의 위치 관계)
두 원의 위치 관계는 두 중심 사이의 거리(개념 2)와 두 반지름을 비교해서 판정해요. 중심거리를 d, 반지름을 r₁, r₂(r₁≥r₂)라 하면 다섯 가지 경우가 있어요.

d > r₁+r₂ → 서로 밖에 (안 만남)
d = r₁+r₂ → 외접 (한 점, 밖에서 접함)
r₁−r₂ < d < r₁+r₂ → 서로 다른 두 점에서 만남
d = r₁−r₂ → 내접 (한 점, 안에서 접함)
d < r₁−r₂ → 한 원이 다른 원 안에 (안 만남)
예: 중심 (0,0), r₁=5인 원과 중심 (8,0), r₂=2인 원 → d=8, r₁+r₂=7, r₁−r₂=3. d(8) > r₁+r₂(7)이므로 서로 밖에 있고 만나지 않음

외접·내접의 "접한다"는 두 원이 딱 한 점만 공유한다는 뜻이에요 — 경계값(=)일 때만 일어나는 특수한 경우.
🦕 토로: 일곱 개념이 전부 따로따로가 아니에요 — 개념1(수직선 거리) → 개념2(피타고라스로 확장) → 개념3,4(점·직선 사이의 거리로 응용) → 개념5,6,7(전부 "중심에서 뭔가까지의 거리를 구한 다음 반지름과 비교") 순서로, 매번 앞 개념 위에 한 겹씩 쌓아올린 것뿐이에요. 막히면 "지금 재는 게 결국 개념 몇 번이지?"부터 확인하세요.
