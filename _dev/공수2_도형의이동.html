📍 주제 0 — 평행이동
평행이동 — 기본설명
모양은 그대로, 위치만 슬라이드
평행이동은 도형을 돌리거나 뒤집지 않고, 모양·크기 그대로 밀기만 하는 거예요.

A(2,3)을 x축 방향으로 3, y축 방향으로 −1만큼 밀면 A′(2+3, 3−1) = A′(5, 2)가 돼요.

점의 평행이동
점 (x, y)를 x축 방향으로 a, y축 방향으로 b만큼 평행이동한 점:
(x + a, y + b)
평행이동 — 기본문제
기본 1 — 점의 평행이동
점 (−3, 5)를 x축 방향으로 4, y축 방향으로 −2만큼 평행이동한 점의 좌표를 구하세요.
💡 풀이
(x+a, y+b) = (−3+4, 5−2) = (1, 3)
평행이동 — 개념 (도형의 평행이동)
방정식은 "거꾸로" 대입 — x 대신 (x−a)
도형(직선, 원 등)을 평행이동할 땐, 방정식에서 x 대신 (x−a), y 대신 (y−b)를 대입해요. 더하기가 아니라 빼기라는 게 헷갈리기 쉬운 포인트예요 — 왜 그런지는 바로 다음 두 장(칸아카데미·하브루타)에서 한 단계도 빠짐없이 확인해요.

예: 직선 y=2x+1을 x축 방향 3, y축 방향 −1만큼 평행이동하면?
y 대신 (y+1), x 대신 (x−3) 대입 (b=−1이니까 y−b = y+1):
(y+1) = 2(x−3)+1 → y+1 = 2x−6+1 → y = 2x−6

검산: 원래 직선 위의 점 (0,1)을 직접 이동하면 (3,0). 새 직선 y=2x−6에 x=3 대입 → y=0 ✓ 맞아요.
🔵 원은 특히 쉬워요 — 반지름은 절대 안 바뀌니까, 중심만 (a,b)만큼 이동시키면 끝이에요. 원 (x−p)²+(y−q)²=r²을 x축 방향 a, y축 방향 b만큼 이동 → 중심만 (p+a, q+b)로 바뀐 (x−p−a)²+(y−q−b)²=r².
평행이동 — 왜 (x−a)일까? (칸아카데미)
🧠 한 단계도 빠짐없는 증명
비유 없이, 순수 논리로만 가볼게요.

전제(정의): 점 (p,q)를 x축 방향 a만큼 평행이동한 점은 정확히 (p+a, q)다.
① 새 도형 C′ 위의 점 (X,Y)가 있다고 하자. C′은 C를 이동시켜 만든 도형이므로, 이 점은 반드시 C 위의 어떤 점 (p,q)가 이동해서 나온 결과다: (X,Y)=(p+a, q)
② p+a=X. 양변에서 a를 빼면 p = X−a. (p=X+a가 나올 방법은 없음 — 산수 오류.)
③ (p,q)는 C 위의 점이므로 C의 방정식을 만족: f(p,q)=0
④ ②의 p=X−a, q=Y를 대입: f(X−a, Y) = 0
⑤ 이게 C′의 방정식. X,Y를 x,y로 다시 쓰면: f(x−a, y) = 0

①은 정의, ②는 등식 풀이, ③은 C의 정의, ④는 대입 — 어디에도 "선택"이 없어요. f(x+a,y)=0이 나오려면 ②에서 산수를 틀려야만 합니다.
평행이동 — 왜 (x−a)일까? (하브루타)
✡️ 질문으로 스스로 도달하기
학생A: 이동은 +a인데 왜 식은 −a야? 논리적으로 이해가 안 돼.
학생B: 새 그래프 위에 점 (X,Y)가 있다고 하자. 이 점, 어디서 왔을까?
A: C를 이동시켜 만든 거니까... C 위의 어떤 점이 이동해서 왔겠지.
B: 그 원래 점을 (p,q)라 하면, 이동 정의상 (p,q)랑 (X,Y)는 무슨 관계야?
A: p+a=X, 그리고 q=Y.
B: 그럼 p는 얼마야?
A: ...p+a=X니까, p=X−a네. 이거 말고 다른 답이 없잖아.
B: 맞아. 근데 (p,q)는 원래 C 위의 점이었으니까 뭘 만족해야 해?
A: f(p,q)=0.
B: 방금 구한 p=X−a를 넣으면?
A: f(X−a, Y)=0... 어 이게 새 방정식이네. p+a=X를 푼 거니까 −a 말고는 답이 나올 수가 없구나.

+a로 이동했다는 사실이랑, 새 점의 "원래 자리"를 구하는 계산은 서로 반대 연산이라서 그런 거예요.
도형의 이동 — 표현 방식 1/3
y=f(x) 꼴에서는?
y=f(x)는 x값 하나에 y값이 딱 하나씩 대응하는 함수 그래프의 표준형이에요 — 포물선(y=x²), 직선(y=2x+1) 같은 게 이 꼴이죠.

새 도형 위의 점 (X,Y)는 원래 점 (p,q)=(X−a, Y−b)가 이동해서 온 거예요. (p,q)가 원래 곡선 위에 있으므로 q=f(p), 즉:
Y−b = f(X−a) → x,y로 다시 쓰면 y−b = f(x−a), 즉 y = f(x−a) + b

예: y=x²을 x축 방향 2, y축 방향 3만큼 평행이동 → y−3=(x−2)² → y=(x−2)²+3
검산: 꼭짓점 (0,0)→(2,3). 새 식에 x=2 대입 → y=(2−2)²+3=3 ✓

주의: x만 (x−a)로 바꾸고 끝내면 안 돼요 — y도 반드시 (y−b)로 이항해서 b를 더해줘야 해요.
도형의 이동 — 표현 방식 2/3
f(x,y)=0 꼴에서는?
f(x,y)=0은 x와 y 사이의 관계 전체를 하나의 식으로 담은 일반형이에요 — 원(x²+y²=9)처럼 x값 하나에 y값이 여러 개 대응해서 함수가 아닌 도형도 표현할 수 있어요.

새 도형 위의 점 (X,Y)는 원래 점 (p,q)=(X−a,Y−b)에서 온 거고, (p,q)가 원래 도형 위에 있으므로 f(p,q)=0. 그대로 대입하면:
f(X−a, Y−b) = 0 → x,y로 다시 쓰면 f(x−a, y−b) = 0

예: 원 x²+y²=9를 x축 방향 2, y축 방향 −3만큼 평행이동 → (x−2)²+(y+3)²=9
검산: 중심 (0,0)→(2,−3). 새 식의 중심이 정확히 (2,−3) ✓

x와 y를 동시에, 대칭적으로 (x−a),(y−b)로 바꿔 넣기만 하면 끝 — 따로 챙길 게 없어요.
도형의 이동 — 표현 방식 3/3
두 꼴, 같은 원리 다른 표현
y=f(x) f(x,y)=0
표현 대상 함수만
(수직선 검사 통과)		 함수 아닌 도형도 가능
(원 등)
치환 규칙 x→x−a 대입 +
y를 (y−b)로 이항		 x→x−a, y→y−b
동시에 대입, 끝
자주 하는 실수 y 이동을 깜빡함 대칭적이라 실수 적음
사실 y=f(x)도 f(x,y)=0의 특수한 경우예요 — g(x,y) = y−f(x)라고 두면 y=f(x)는 정확히 g(x,y)=0. 일반 규칙 g(x−a,y−b)=0을 그대로 적용하면 (y−b)−f(x−a)=0, 즉 y−b=f(x−a) — 1/3 카드에서 얻은 결과와 완전히 같아요!

기본 2 — 도형의 평행이동
원 x²+y²=9를 x축 방향으로 2, y축 방향으로 −3만큼 평행이동한 도형의 방정식을 구하세요.
💡 풀이
x 대신 (x−2), y 대신 (y+3) 대입:
(x−2)² + (y+3)² = 9
📍 주제 1 — 대칭이동
대칭이동 — 개념
네 방향 거울
대칭이동은 점을 거울에 비추듯 뒤집는 거예요. 거울을 어디에 두느냐(x축, y축, 원점, 직선 y=x)에 따라 4가지가 있어요.

점 (x, y)를 대칭이동하면:
x축 대칭 → (x, −y)   (y만 부호 반대)
y축 대칭 → (−x, y)   (x만 부호 반대)
원점 대칭 → (−x, −y)   (둘 다 부호 반대)
직선 y=x 대칭 → (y, x)   (x와 y 자리 바꿈)
대칭이동 — 기본문제
기본 3 — 점의 대칭이동
점 (−2, 5)를 ① x축 ② y축 ③ 원점 ④ 직선 y=x에 대하여 각각 대칭이동한 점의 좌표를 구하세요.
💡 풀이
① x축: (−2, −5)   ② y축: (2, 5)   ③ 원점: (2, −5)   ④ y=x: (5, −2)
대칭이동 — 개념 (도형의 대칭이동)
도형도 같은 규칙으로 치환
도형의 방정식도 점과 똑같은 규칙으로 x, y를 바꿔치기하면 돼요.

x축 대칭 → y 대신 −y    y축 대칭 → x 대신 −x
원점 대칭 → x 대신 −x, y 대신 −y    y=x 대칭 → x와 y를 통째로 교환
예: 원 (x−2)²+(y−3)²=4를 x축에 대칭이동하면?
y 대신 −y 대입: (x−2)²+(−y−3)²=4 → (x−2)²+(y+3)²=4
중심이 (2,3)→(2,−3)으로 옮겨갔을 뿐, 반지름은 그대로예요 — 대칭이동은 모양과 크기를 안 바꾸니까요.
대칭이동 — 기본문제
기본 4 — 도형의 대칭이동
직선 y = 3x − 2를 원점에 대하여 대칭이동한 직선의 방정식을 구하세요.
💡 풀이
x 대신 −x, y 대신 −y 대입:
−y = 3(−x) − 2 → −y = −3x − 2 → y = 3x + 2
🗺️ 심화문제 들어가기 전에
지도
대칭이동한 직선이 원의 중심을 지난다
문제에 "직선을 대칭이동했더니 원의 넓이를 이등분했다"는 표현이 나오면?

조건: 대칭이동한 직선이 원의 넓이를 이등분
필요한 도구: "넓이를 이등분" = "그 직선이 원의 중심을 지난다"는 사실
공식: 대칭이동한 직선의 식에 원의 중심 좌표를 대입해서 미지수를 구함
원을 정확히 반으로 나누는 직선은 무조건 중심을 지나야 해요. "넓이 이등분"이라는 말을 보면 자동으로 "중심을 대입하자"고 떠올리면 됩니다 — 원의 방정식 단원과 이 단원이 만나는 대표적인 지점이에요.

예: 직선 y=kx−3을 x축에 대칭이동한 직선이 원 (x−2)²+(y+1)²=9(중심(2,−1))의 넓이를 이등분할 때, k를 구하세요.
x축 대칭: y=kx−3 → −y=kx−3 → y=−kx+3. 이 직선이 중심(2,−1)을 지나야 하므로: −1=−2k+3 → k=2
검산: k=2일 때 대칭이동한 직선은 y=−2x+3, x=2 대입 → y=−1 ✓ 중심을 정확히 지나요.
→ 원의 방정식(중심) + 대칭이동 결합
지도
대칭을 두 번 하면?
x축 대칭 → y축 대칭(순서 바꿔도 동일)을 연달아 하면 결과는 항상 원점 대칭과 같아요 — x축 대칭은 y부호만, y축 대칭은 x부호만 바꾸니 둘을 합치면 결국 (x,y)→(−x,−y).

🪞 거울과 빛의 반사 — 대칭이동으로 광학 문제 풀기
빛이 거울에 부딪히면 "입사각 = 반사각"으로 튕겨 나가요(반사 법칙). 그런데 이 반사 경로를 직접 계산하려면 각도를 재야 해서 꽤 번거로워요.

광학에서 실제로 쓰는 방법: 도착점을 거울 면에 대해 대칭이동시켜서 거울 반대편에 옮겨놓으면, 출발점과 그 대칭점을 직선으로 잇기만 해도 실제 빛의 경로(광로)가 나옵니다.
반사각을 하나하나 계산하는 대신, 오늘 배운 "대칭이동해서 직선 긋기"로 바꿔버리는 거예요 — 망원경, 카메라, 레이저 장치가 전부 이 원리를 씁니다.

🎱 당구공의 최단 경로 — 벽에 두 번 튕기기
당구대 벽에 두 번 튕기는 경우도 똑같은 방법(대칭이동)으로 풀 수 있어요 — 벽마다 한 번씩 대칭이동을 반복하면 됩니다. 이번엔 출발점 A와 도착점 B도 당구대 벽 위에 있는 경우예요.

꼭짓점이 (0,0)~(6,8)인 직사각형 당구대예요. 공이 왼쪽 벽의 A(0,4) 지점에서 출발해 아래쪽 벽 → 오른쪽 벽 순서로 차례로 튕긴 뒤, 위쪽 벽의 B(3,8) 지점에 도착하려 해요. 최단 경로의 길이는?
1단계: B(3,8)를 오른쪽 벽(x=6)에 대칭이동 → B′(9,8)
2단계: B′을 아래쪽 벽(y=0)에 대칭이동 → B″(9,−8)
3단계: A(0,4)와 B″(9,−8)을 직선으로 잇는다 — 이 직선이 두 벽을 차례로 지나가는 자리가 실제로 튕기는 지점.
최단 거리 = AB″ = √{(9−0)²+(−8−4)²} = √(81+144) = √225 = 15

튕기는 지점까지 확인: 직선 AB″은 아래쪽 벽을 P₁(3,0)에서, 오른쪽 벽을 P₂(6,4)에서 지나요. 검산: AP₁=√(3²+4²)=5, P₁P₂=√(3²+4²)=5, P₂B=√(3²+4²)=5. 세 구간 전부 5로 똑같아요! 합=5+5+5=15 ✓

벽이 하나 늘어도 원리는 같아요 — 튕기는 순서의 반대로, 벽마다 한 번씩 대칭이동해서 목표점을 계속 옮긴 다음, 출발점과 일직선으로 이으면 끝이에요.

대칭이동과 최단거리 1/4
🎒 초등학교 — 대칭축
곧 나올 "거리의 합의 최소" 문제들, 사실 완전히 새로운 게 아니에요 — 여러분이 훨씬 오래전부터 배워온 개념이 좌표평면 위에서 다시 나타난 거예요. 그 출발점부터 하나씩 짚어볼게요.

선대칭도형의 대칭축: "반으로 접으면 완전히 겹치는 선"이에요. 대칭축 위의 어떤 점 M에서 재도, 접히는 두 점까지의 거리 MP와 MP′는 항상 같아요 — 손으로 접어보면 바로 확인되는, 아주 직관적인 사실이었죠.
대칭이동과 최단거리 2/4
📐 중1-2 (기본 도형) — 작도
이제 이 성질을 도구로 직접 그려봐요. 두 점 A, B에서 같은 길이만큼 컴퍼스를 벌려 호를 그리면(양쪽에서), 두 호가 만나는 두 점을 지나는 선이 바로 선분 AB의 수직이등분선이에요. 같은 방식으로 각의 이등분선도 작도할 수 있어요.

단, 이 단계에서는 "이렇게 그리면 된다"는 방법만 배워요 — "왜 이 선 위의 점들이 A, B로부터 같은 거리인지"는 아직 증명하지 않습니다.
대칭이동과 최단거리 3/4
📏 중2-2 (삼각형의 성질) — 드디어 증명
"접으면 겹친다"는 직관을 이제 삼각형의 합동으로 증명해요: 수직이등분선 위의 점 P는 △PMA ≡ △PMB(SAS 합동)이므로 반드시 PA = PB. 각의 이등분선 위의 점도 같은 방식(RHA 합동)으로 두 변까지의 거리가 같음을 증명해요.

초등학교 땐 "접어보니 그렇더라"였다면, 이제는 "논리적으로 반드시 그렇다"로 업그레이드된 거예요.
대칭이동과 최단거리 4/4
📊 고1 2학기 공통수학2 — 좌표평면 위에서 다시 만나다
이 성질들이 좌표평면 + 방정식으로 다시 등장해요. 특히 지금 이 단원(도형의 이동)에서는: 직선 위를 움직이는 점 P와 다른 두 점 A, B를 잇는 거리의 합 AP+PB의 최솟값을 구할 때 씁니다. 점 A를 거울선에 대칭이동해서 A′을 만들면, 거울선 위의 어떤 점 M에서도 MA=MA′ — 1/4에서 접어 확인하고 3/4에서 증명까지 마친 바로 그 성질이에요. 숫자로 직접 확인해볼게요.

A(1,4), B(7,2)가 있고, 직선(거울선)이 x축이에요. x축 위의 점 P에 대하여 AP+PB의 최솟값은?
1단계: A를 x축에 대칭이동 → A′(1,−4)
2단계: A′과 B를 직선으로 잇는다. 기울기 = (2−(−4))/(7−1) = 1, 식 y−2=1(x−7) → y=x−5. y=0 대입 → P(5, 0)
3단계: 최솟값 = A′B = √{(7−1)²+(2−(−4))²} = √72 = 6√2

검산: AP=√{(5−1)²+(0−4)²}=√32=4√2, PB=√{(7−5)²+(2−0)²}=√8=2√2. 합=4√2+2√2=6√2 ✓

🦕 토로: 새로운 기술을 배운 게 아니에요 — 초등학교 때부터 알던 "대칭=같은 거리"라는 사실 하나를, 좌표평면이라는 새로운 도구 위에서 다시 쓰는 것뿐입니다. 다음 문제들에서 직접 확인해보세요.

연습문제 7 — 풀이
💡 정답 5√5 − 1
1단계 — x축 대칭으로 꺾인 경로 펴기: A를 x축에 대칭이동한 점 A′(6,−2)를 만들면, x축 위의 어떤 Q에서도 AQ = A′Q가 성립해요(대칭이동은 거리를 보존하니까). 그래서 AQ+QP = A′Q+QP가 돼요.

2단계 — 직선으로 최단 거리 만들기: A′Q+QP의 최솟값은, A′과 P를 잇는 경로가 일직선이 될 때예요(삼각부등식). P가 원 위를 움직이니, A′에서 원의 중심 C(1,8)까지 거리에서 반지름만 빼면 됩니다.

A′C = √((6−1)²+(−2−8)²) = √(25+100) = √125 = 5√5
최솟값 = A′C − r = 5√5 − 1

이 문제는 심화 카드 "거울과 빛의 반사"에서 배운 반사 원리(대칭이동으로 꺾인 경로를 직선으로 펴기)와 원의 방정식(중심까지 거리−반지름=최단거리)을 그대로 결합한 거예요.
🕵️ 사건 해결 — 최단 경로를 찾아라
💡 정답 3√2
단서 1 — 꺾인 경로는 계산이 어렵다
A→P→B처럼 꺾인 길은 거리를 한 번에 재기 어려워요. 곧게 펴는 방법이 필요합니다.

단서 2 — 거울의 법칙(대칭이동)
직선 y=x를 거울이라고 생각하면, A(1,5)를 이 거울에 비춘 점 A′(5,1)(y=x 대칭은 x,y를 맞바꾸면 돼요)에 대해 AP = A′P가 항상 성립해요(거울선 위의 어떤 점에서 재도 원래 점까지의 거리와 거울상까지의 거리는 같으니까요). 그래서 AP+PB = A′P+PB가 됩니다.

단서 3 — 곧은 길이 최短(최단)
A′P+PB의 최솟값은 A′, P, B가 일직선일 때예요(삼각부등식). A′(5,1)과 B(2,4)를 그대로 이으면 됩니다.

사건 해결:
A′B = √((2−5)²+(4−1)²) = √(9+9) = √18 = 3√2

검산: A′와 B를 잇는 직선과 y=x의 교점은 P(3,3). AP=√((3−1)²+(3−5)²)=√8=2√2, PB=√((2−3)²+(4−3)²)=√2. 합=2√2+√2=3√2 ✓ — 꺾어서 재도 결국 곧게 편 거리와 똑같이 나와요.

🦕 토로: 이 문제는 A, B가 거울선의 같은 쪽에 있을 때만 이 방법이 통해요 — 만약 둘이 이미 반대쪽에 있다면 대칭이동 없이 그냥 AB를 직선으로 이으면 답이 나옵니다. 먼저 어느 쪽에 있는지부터 확인하는 습관을 들이세요.
대칭이동 — 심화문제 풀이
💡 정답 A′(−1, 1)
지금까지 배운 x축·y축·원점·y=x 대칭은 전부 "거울선이 축이거나 45°"인 특수한 경우였어요. 거울선이 일반적인 직선이면, 공식을 외우는 대신 대칭이동의 정의 그 자체(중점 조건 + 수직 조건)를 직접 세워야 해요.

절차 (반드시 세트로)
① 중점 조건: A와 A′의 중점은 반드시 거울선 위에 있다
② 수직 조건: 직선 AA′과 거울선은 서로 수직이다(기울기의 곱=−1)
A′(a,b)라 하면
① 중점 조건: 중점 a+22, b+42이 y=−x+3 위에 있음
b+42 = −a+22+3 → a+b=0 ⋯(가)

② 수직 조건: 직선 AA′의 기울기 b−4a−2와 거울선 기울기(−1)의 곱이 −1
b−4a−2×(−1)=−1 → b−4=a−2 → a−b=−2 ⋯(나)

(가)+(나): 2a=−2 → a=−1, b=1
A′(−1, 1)

검산: 중점=((2−1)/2,(4+1)/2)=(0.5,2.5). y=−x+3에 대입 → −0.5+3=2.5 ✓. 기울기 (1−4)/(−1−2)=(−3)/(−3)=1, 거울선 기울기(−1)와 곱하면 −1 ✓.
평행이동 — 실전 결합 (확률) 풀이
💡 정답 5
평행이동은 순서를 바꿔도 결과가 같아요(더하기는 교환법칙이 성립하니까) — 앞면·뒷면이 어떤 순서로 나왔는지는 몰라도, 앞면이 3번이면 x축 방향으로 총 3만큼, 뒷면이 4번이면 y축 방향으로 총 4만큼 이동한 것만 알면 충분합니다.

이동량: x축 방향 +3, y축 방향 +4 → P = P₀ + (3, 4)
P₀P의 길이는 이동한 거리 그 자체이므로:
P₀P = √(3² + 4²) = √25 = 5

P₀의 실제 좌표(2,−1)는 사실 이 문제에서 중요하지 않아요 — 어디서 출발하든 이동량(3,4)만큼 움직인 거리는 항상 5거든요.
평행이동 — 실전 결합 (원과 직선) 풀이
💡 정답 15개
1단계 — 평행이동한 직선 구하기: y=x를 x축 방향 k만큼 이동 → x 대신 (x−k) 대입: y=x−k, 즉 x−y−k=0

2단계 — 원과 직선의 위치 관계(주제0+원의 방정식 단원 결합): "서로 다른 두 점에서 만난다"는 지도 신호는 중심에서 직선까지 거리 < 반지름이에요.
중심(0,0)에서 직선까지 거리: d = |−k|√2 = |k|√2
조건: |k|√2 < 5 → |k| < 5√2 ≈ 7.07

3단계 — 정수 개수 세기: −7.07 < k < 7.07을 만족하는 정수는 −7, −6, …, 6, 7 → 총 15개

검산: k=7일 때 d=7/√2≈4.95<5 ✓(만남). k=8일 때 d=8/√2≈5.66>5 ✗(안 만남) — 경계가 정확히 7과 8 사이임을 확인.
평행이동 — 실전 스토리 풀이
💡 정답 16
다리의 폭(=강폭 3)은 어디에 놓든 고정된 값이라는 게 핵심이에요. 그래서 다리를 지나는 구간의 길이 3은 항상 답에 그대로 더해지고, 나머지 "다리 입구까지"+"다리 출구부터 B까지"의 합만 최소화하면 됩니다.

아이디어: 지점 A를 강물이 흐르는 방향(기슭에 수직)으로 강폭만큼(3) 미리 평행이동시켜 강 건너편으로 옮겨놓으면, "다리를 거쳐가는 거리"가 자동으로 "곧은 직선 거리"로 바뀝니다 — 다리 길이만큼 미리 이동해뒀으니까요.
좌표를 놓아볼게요. 가까운 기슭을 y=0, 먼 기슭을 y=−3(강폭 3)이라 하면:
A(0, 4), B(12, −4) [먼 기슭에서 1만큼 더 떨어진 위치: −3−1=−4]

1단계 — B를 강폭 3만큼 거슬러 평행이동: B(12,−4) → B′(12, −4+3) = B′(12,−1)
2단계 — A에서 B′까지 직선 거리: AB′ = √{(12−0)²+(−1−4)²} = √(144+25) = √169 = 13
3단계 — 다리 길이(3)를 더하기: 최단 거리 = AB′ + 3 = 13+3 = 16

검산: 직선 A-B′과 가까운 기슭(y=0)의 교점 P≈(9.6,0), 다리 출구 Q=(9.6,−3). AP=√(9.6²+4²)=10.4, QB=√(2.4²+1²)=2.6. AP+QB=13, 여기에 다리 3을 더하면 정확히 16 ✓.
