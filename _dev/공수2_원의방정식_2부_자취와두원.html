📍 주제 3 — 원이 되는 자취
원이 되는 자취 — 개념
📐 자취, 다시 보기 — 조건에 따라 직선도 되고 원도 된다
자취란 어떤 조건을 만족하는 점을 전부 모은 도형이에요. 구하는 방법은 항상 똑같아요 — 그 점을 P(x,y)라고 이름 붙이고, 조건을 식으로 세운 뒤 정리하면 됩니다. 직선의 방정식 단원에서 이미 배운 방법이에요.

직선의 방정식 단원에서 봤던 예: 두 점 A(1,2), B(5,−2)로부터 같은 거리에 있는 점 P의 자취 → 정리하면 x−y−3=0 (선분 AB의 수직이등분선, 즉 직선)
그때는 조건이 "같은 거리"였어서 결과가 직선이었어요. 그런데 조건이 조금만 바뀌면 결과가 완전히 달라질 수 있어요 — 같은 거리 대신 거리의 "비"가 일정하다는 조건으로 바꾸면 어떻게 될까요? 다음 카드에서 직접 계산해봐요.
원이 되는 자취 — 예제로 먼저 확인
📐 이번엔 어떤 도형이 나올까?
예: 두 점 A(−4,0), B(2,0)로부터 거리의 비가 2:1(PA:PB=2:1)인 점 P(x,y)의 자취는?
PA=2PB → PA²=4PB²
(x+4)²+y² = 4[(x−2)²+y²]
전개·정리하면 → (x−4)² + y² = 16 (중심(4,0), 반지름4)
결과를 보세요 — 직선일 때와 달리 이번엔 x², y² 항이 사라지지 않고 그대로 남아서, 정리하니 원의 방정식이 나왔어요! 방법(제곱해서 근호 없애고 정리하기)은 직선 때와 완전히 똑같은데, "거리의 비"라는 조건 때문에 결과가 원으로 바뀐 거예요.

이렇게 두 점으로부터 거리의 비가 일정한 점들의 자취가 그리는 원을, 특별히 아폴로니오스 원이라고 불러요. (참고로 "한 정점으로부터 일정한 거리"라는 조건도 원이 되는데, 그건 원의 정의 그 자체죠 — 원이 되는 자취가 아폴로니오스 원 하나만 있는 건 아니에요.)
아폴로니오스 원 — 기본문제
기본 7 — 거리의 비로 원의 방정식 구하기
두 점 A(0,0), B(9,0)로부터 거리의 비가 1:2(PA:PB=1:2)인 점 P의 자취의 방정식을 구하세요.
💡 풀이
PB=2PA → PB²=4PA²
(x−9)²+y² = 4(x²+y²)
x²−18x+81+y² = 4x²+4y²
0 = 3x²+18x−81+3y² → x²+6x−27+y²=0
(x+3)² + y² = 36 (중심(−3,0), 반지름6)
접선 + 자취 — 결합 문제
기본 8 — 수직인 두 접선을 그을 수 있는 점의 자취
점 P(a,b)에서 원 x²+y²=9에 그은 두 접선이 서로 수직일 때, 점 P가 만족하는 자취의 방정식을 구하세요.
💡 풀이
원의 중심 O, 두 접점 T₁·T₂, 점 P를 이으면: OT₁⊥PT₁, OT₂⊥PT₂(반지름은 항상 접선과 수직), 그리고 문제에서 ∠T₁PT₂=90°까지 주어졌으니 사각형 O-T₁-P-T₂는 세 각이 이미 90°인 도형이에요. 네 번째 각도 자동으로 90°가 되므로 이건 직사각형이고, OT₁=OT₂=r(반지름)이므로 사실은 정사각형입니다.

정사각형의 대각선 OP = 변×√2 = 3√2(반지름이 3이니까)
따라서 원점에서 P까지의 거리가 항상 3√2 → a² + b² = 18
📍 주제 4 — 두 원의 관계
두 원의 위치 관계 — 개념
📐 중심 사이 거리로 다섯 가지를 구분
두 원이 서로 어떻게 놓여있는지는 두 중심 사이의 거리 d와 두 반지름(r₁, r₂)을 비교하면 알 수 있어요. 주제1(원과 직선의 위치 관계)과 완전히 같은 방식이에요 — 거리 하나만 비교하면 끝. 다섯 가지 경우를 그림으로 하나씩 볼게요 — 중심을 잇는 선(점선, 길이 d)이 두 반지름(r₁, r₂)과 어떤 관계인지 보면 공식이 저절로 나와요.
두 원의 위치 관계 — ①
d > r₁+r₂
① d > r₁+r₂ → 서로 만나지 않음
r₁ 구간과 r₂ 구간을 다 써도 상대방 중심에 못 닿아요 — 그 사이에 여백이 남는다는 게 바로 "안 만남"의 그림 증거예요.
두 원의 위치 관계 — ②
d = r₁+r₂
② d = r₁+r₂ → 외접 (한 점에서 접함)
r₁ 구간이 끝나는 지점이 정확히 r₂ 구간이 시작하는 지점이에요 — 여백도 겹침도 없이 딱 맞닿으니 d = r₁+r₂.
두 원의 위치 관계 — ③
|r₁−r₂| < d < r₁+r₂
③ |r₁−r₂| < d < r₁+r₂ → 두 점에서 만남 (교차)
r₁ 구간과 r₂ 구간이 겹치는 구간이 생겨요(56~72 부분) — 이 겹침이 바로 두 원이 두 점에서 교차한다는 뜻이에요.
두 원의 위치 관계 — ④
d = |r₁−r₂|
④ d = |r₁−r₂| → 내접 (작은 원이 안쪽에서 닿음)
중심에서 d만큼, 그리고 이어서 r₂만큼 더 간 지점이 큰 원의 경계(r₁ 끝지점)와 정확히 같아요 → d+r₂=r₁, 즉 d=r₁−r₂.
두 원의 위치 관계 — ⑤
d < |r₁−r₂|
⑤ d < |r₁−r₂| → 한 원이 다른 원 안에 완전히 들어있음
d+r₂를 다 더해도 큰 원의 반지름 r₁에 못 미쳐요(여백이 남음) → 작은 원이 큰 원 경계에 닿지도 않고 안에 쏙 들어있는 거예요.

예: 원 x²+y²=9(중심(0,0), r=3)와 (x−1)²+y²=1(중심(1,0), r=1) → d=1, |r₁−r₂|=2 → d<|r₁−r₂| → 내부포함 (작은 원이 큰 원 안에 쏙 들어가 있고, 서로 닿지 않아요)
두 원의 위치 관계 — 기본문제
기본 9 — 두 원의 위치 관계 판별
두 원 x²+y²=4와 (x−1)²+(y−1)²=9의 위치 관계를 판별하세요.
💡 풀이
중심(0,0), r₁=2 / 중심(1,1), r₂=3
d = √(1²+1²) = √2 ≈ 1.41
|r₁−r₂| = 1, r₁+r₂ = 5 → 1 < √2 < 5
두 점에서 만난다 (교차)
📍 주제 5 — 항등식: 두 원의 교점을 지나는 직선과 원의 방정식
두 원을 조합하면? — 개념
📐 빼면 직선, k를 곱해서 더하면 원
두 원이 두 점에서 만나면, 이 둘을 조합해서 새로운 도형을 만들 수 있어요. 직선의 방정식 단원에서 "두 직선의 교점을 지나는 직선"을 k·l₁+l₂=0 꼴로 만들 수 있다고 배웠죠? 원도 똑같은 원리가 통해요 — 방법은 딱 하나, 두 원의 일반형 C₁, C₂를 C₁ + k·C₂ = 0 꼴로 묶는 거예요.

📎 직선의 방정식 단원에서 배운 것과 나란히 보기 (실제 숫자로)

[직선] 두 직선 l₁: x−y−1=0, l₂: 2x+y−5=0의 교점을 지나고, 점(1,4)도 지나는 직선은?
k·l₁+l₂=0 → k(x−y−1)+(2x+y−5)=0에 (1,4) 대입 → k=14
→ 3x+y−7=0

[원] 두 원 C₁: x²+y²=10, C₂: x²+y²−4x−2y+4=0의 교점을 지나는 도형은?
C₁+k·C₂=0 꼴로 묶는데, k=−1을 넣으면(=C₁−C₂) → 2x+y−7=0 (직선, 공통현)

두 식 모두 형태가 똑같죠? "l₁, l₂를 k로 묶기"와 "C₁, C₂를 k로 묶기"가 완전히 같은 방법이에요. 왜 이게 항상 통할까요 — 두 식이 동시에 0이 되는 교점에서는, 어떤 비율(k)로 묶어서 더해도 그 결과 역시 0이 되기 때문이에요. 그래서 결합식이 나타내는 도형은 원래의 교점을 항상 그대로 지나갑니다.
두 원을 조합하면? — 그림으로 보기
📐 k가 바뀌어도 두 교점은 항상 그대로
↑ 두 원의 크기가 많이 다른 특수한 예 하나였어요. 아래는 비슷한 크기의 원 두 개로 본, 좀 더 일반적인 그림이에요:
C₁, C₂ 크기가 비슷해도 원리는 똑같아요 — k값을 바꾸면(점선 원처럼) 크기와 위치가 계속 달라지는 원이 나오지만, 두 교점만은 항상 그대로 지나요.
두 원을 조합하면? — k값에 따른 결과 + 예제
📐 k=−1 → 직선, k≠−1 → 원
k = −1 이면 → x², y² 항이 서로 사라져서 직선이 나와요. 이 직선을 두 원의 교점을 잇는 공통현이라고 불러요.

k ≠ −1 이면 → x², y² 항이 안 사라지고 또 다른 원이 나와요. 이 원도 똑같이 두 원의 교점을 지나요.
"빼기"(k=−1)와 "k배해서 더하기"(k≠−1)는 사실 같은 조작의 두 가지 결과일 뿐이에요.

예1 (k=−1, 직선이 나오는 경우): 두 원 C₁: x²+y²=10, C₂: x²+y²−4x−2y+4=0의 공통현은?
C₁−C₂: 4x+2y−14=0 → 2x+y−7=0
검산: 실제 교점 (3,1), (2.6,1.8) 둘 다 대입하면 성립해요.

예2 (k≠−1, 원이 나오는 경우): 두 원 x²+y²−4=0, x²+y²−2x−2y=0 의 교점과 점 (1,−1)을 지나는 원은?
C₁(1,−1)=−2, C₂(1,−1)=2 → k=1 → C₁+C₂=0 → x²+y²−x−y−2=0
두 원을 조합하면? — 기본문제 (직선이 나오는 경우)
기본 10 — 공통현의 길이로 미지수 구하기
두 원 x²+y²=20과 (x−a)²+y²=20의 공통현의 길이가 8일 때, 양수 a의 값을 구하세요.
💡 풀이
두 식을 빼면 공통현: x²+y²−[(x−a)²+y²]=0 → 2ax−a²=0 → x = a/2
중심(0,0)에서 이 공통현까지의 거리 = a/2, 반지름 √20, 반현(半弦)의 길이 = 4(현의 길이 8의 절반)
피타고라스: (a/2)² + 4² = 20 → (a/2)² = 4 → a/2 = 2 → a = 4
두 원을 조합하면? — 기본문제 (원이 나오는 경우)
기본 11 — 교점을 지나는 원 구하기
두 원 x²+y²−4=0, x²+y²−2x−2y=0 의 교점과 점 (−2, 2)를 지나는 원의 방정식을 구하세요.
💡 풀이
C₁(−2,2)=4+4−4=4, C₂(−2,2)=4+4+4−4=8
C₁+k·C₂=0 → 4+8k=0 → k=−12
2C₁−C₂=0 → 2(x²+y²−4)−(x²+y²−2x−2y)=0
→ x²+y²+2x+2y−8=0
