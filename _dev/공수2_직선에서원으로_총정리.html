🚧 빌드 중 — 직선에서 배운 게 원에서 어떻게 다시 나올까? (깜짝 연결 카드)
거리 공식 연결(점과직선거리↔원과직선거리)은 공수2_거리공식_총정리.html에서 이미 다룸 — 이 파일은 나머지 3가지: 자취→원의 방정식, 정점→두 원의 교점, 평행·수직→접선

🦕 토로의 수학왕국 · 직선에서 배운 게, 원에서 다시 나온다?!

이 카드 시리즈 전체를 관통하는 질문
원의 방정식은 정말 "새 단원"일까?
🦕 토로: 원의 방정식을 배우기 시작하면 다들 "또 새로운 걸 외워야 하나" 하고 긴장해요. 그런데 사실은 아니에요!

직선의 방정식 단원에서 만든 도구들 — 자취를 세우는 법, 정점을 항등식으로 찾는 법, 평행·수직을 판정하는 법 — 이 그대로, 심지어 글자 하나 안 바뀌고 원의 방정식에서 다시 등장해요. 아래 3장의 카드에서 각각 확인해봐요.

🦕 토로: "원의 방정식 = 새 단원"이 아니라 "직선의 방정식에서 배운 도구로, 원이라는 새 대상을 다루는 것"이라고 생각하면 훨씬 쉬워져요. 도구가 늘어난 게 아니라, 같은 도구를 다른 곳에 다시 쓰는 것뿐이에요.
🔍 연결 1 — 자취의 방정식
직선의 방정식 단원 — 주제6 자취의 방정식
"같은 거리"의 자취 → 직선
직선의 방정식 단원에서 배운 자취 기법을 다시 떠올려봐요: 조건을 만족하는 점을 P(x,y)라 놓고, 그 조건을 그대로 식으로 세운 뒤 정리하면 자취의 방정식이 나와요.

① AB를 수직으로 이등분하는 선
② 이 선 위 어떤 점 P든 PA=PB
두 점 A, B로부터 같은 거리에 있는 점 P(x,y)의 자취 → 수직이등분선(직선)
예: A(0,0), B(4,0)로부터 같은 거리인 점의 자취 → PA=PB → x²+y² = (x−4)²+y² → 정리하면 x=2(직선)
원의 방정식 단원 — 개념 예고 (자취 기법의 재사용)
"일정한" 거리의 자취 → 원
조건 딱 하나만 바꿔볼게요: "같은 거리"(두 점으로부터 똑같은 거리) 대신, "일정한 거리"(한 점으로부터 항상 같은 값 r)로 바꾸면 어떻게 될까요?

쓰는 절차는 완전히 똑같아요 — 점 P(x,y)를 놓고, "중심 C(a,b)로부터 거리가 항상 r"이라는 조건을 두 점 사이의 거리 공식으로 그대로 식을 세워요.

CP = r  →  √{(x−a)²+(y−b)²} = r  →  양변 제곱
(x−a)² + (y−b)² = r²
🔗 원의 방정식(표준형) 자체가, 사실 자취의 방정식이에요
직선의 방정식 단원의 자취 절차(①조건 세우기 ②P(x,y)로 놓기 ③거리공식으로 식 세우기 ④정리)를 단 한 단계도 안 바꾸고 그대로 따라간 결과가 원의 표준형 공식이에요. "조건이 달라지면 결과 도형도 달라진다"는 걸 직접 보여주는 예시예요.
"자취를 구하라"는 문제를 만나면, "이게 직선이 되는 조건일까, 원이 되는 조건일까"부터 먼저 판단하는 습관을 들이세요 — 판단 기준은 "거리 조건이 두 대상 사이의 같음인가, 한 대상으로부터의 일정함인가"예요.
🔍 연결 2 — 정점을 지나는 도형 (항등식)
직선의 방정식 단원 — 주제4 정점을 지나는 직선
k(l₁)+l₂=0 — k값과 상관없이 항상 지나는 점
두 직선 l₁: a₁x+b₁y+c₁=0, l₂: a₂x+b₂y+c₂=0의 교점을 P라 하면, k(l₁)+l₂=0 꼴의 식은 k값이 뭐든 항상 그 교점 P를 지나요 — k에 대한 항등식이기 때문이에요.

k(a₁x+b₁y+c₁) + (a₂x+b₂y+c₂) = 0 → k값에 상관없이 항상 l₁, l₂의 교점 P를 지남
k가 어떤 값이든 이 식이 지나는 점은 딱 하나(교점 P)로 고정돼 있다는 게 핵심이에요.
원의 방정식 단원 — 개념 예고 (항등식 논리의 재사용)
C₁+k·C₂=0 — 두 원의 교점을 지나는 도형
이번엔 l₁, l₂ 자리에 두 원의 방정식을 넣어볼게요. 두 원 C₁: x²+y²+D₁x+E₁y+F₁=0, C₂: x²+y²+D₂x+E₂y+F₂=0이 두 점에서 만난다고 하면?

C₁ + k·C₂ = 0 (k≠−1) → k값에 상관없이 두 원의 교점 2개를 항상 지나는 원
🔗 정점 논리와 완전히 똑같은 항등식 아이디어
"교점을 지나는 도형이, k값과 무관하게 항상 나온다"는 원리가 직선(정점 1개)에서 원(교점 2개)으로 그대로 옮겨왔어요. 딱 하나 특별한 경우가 있는데, k=−1이면 x², y² 항이 서로 상쇄돼서 원이 아니라 직선이 돼요 — 이 직선을 "공통현"(두 원이 만나는 현을 포함하는 직선)이라고 불러요.
정점 문제에서 "k에 대한 항등식"을 알아채야 했던 것처럼, 여기서도 "이 식이 k값과 무관하게 항상 성립하려면?"이라고 스스로 묻는 습관이 그대로 이어져요.
🔍 연결 3 — 평행·수직 조건
직선의 방정식 단원 — 주제3 두 직선의 위치관계
기울기의 곱이 −1이면 수직
두 직선이 수직이라는 걸 판정하는 도구, 기억하죠? 기울기를 각각 m₁, m₂라 하면:

m₁ × m₂ = −1 ⟺ 두 직선은 수직
이 도구는 "두 직선"뿐 아니라, 직선과 반지름 사이에도 그대로 적용돼요.
원의 방정식 단원 — 개념 예고 (수직 조건의 재사용)
접선은 반지름과 항상 수직
원 위의 한 점 T에서 그은 접선은, 중심 C와 T를 잇는 반지름 CT와 항상 수직이에요. "접한다"는 새로운 성질이 아니라, 이미 아는 수직 조건이 그대로 적용된 경우예요.

반지름 CT의 기울기를 m₁, 접선의 기울기를 m₂라 하면
m₁ × m₂ = −1 (T가 원점이 아닐 때)
🔗 두 직선의 수직 조건과 완전히 똑같은 도구
"어떤 두 직선이 수직이려면 기울기의 곱이 −1"이라는 판정법을, 대상만 "임의의 두 직선"에서 "반지름과 접선"으로 좁힌 것뿐이에요. 예: 원 x²+y²=25 위의 점 T(3,4)에서 그은 접선 → 반지름 CT의 기울기 = 4/3 → 접선의 기울기 = −3/4 (곱이 −1) → 접선의 방정식은 y−4=−34(x−3)
접선의 방정식을 구하는 문제를 만나면, "반지름의 기울기부터 구하고, 수직조건으로 접선의 기울기를 뒤집는다"는 순서가 여기서 나와요 — 직선 단원에서 이미 수백 번 써본 순서예요.
🦕 토로: 세 가지 연결 모두 같은 패턴이에요 — 조건을 살짝 바꾸면(같은 거리→일정한 거리, 정점 1개→교점 2개, 임의의 두 직선→반지름과 접선), 도구는 그대로인데 결과 도형만 달라져요. 원의 방정식 단원에서 "이거 처음 보는 건데?" 싶은 게 나오면, 먼저 "직선의 방정식에서 이거랑 닮은 도구가 있었나?"부터 떠올려보세요.
