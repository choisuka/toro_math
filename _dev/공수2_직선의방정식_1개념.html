📍 주제 1 — 기울기가 뭐지?
기울기 — 기본설명 (정의 + 시각화)
📐 기울기가 뭐지?
직선의 기울기(m)는 x가 변한 양에 대해 y가 얼마나 변했는지를 나타내는 비율이에요. 세 가지 방식으로 표현할 수 있어요.

1비율 정의
m = y의 변화량x의 변화량
오른쪽으로 Δx칸 갈 때 위로 Δy칸 움직이면, m = ΔyΔx
📐 기울기 계단으로 보면
숫자로만 보면 헷갈리니 계단으로 직접 그려볼게요.

계단 한 칸: 오른쪽으로 1칸 갈 때마다 위로 2칸. 이 계단이 몇 번 반복되든 비율은 항상 똑같아요.
계단 하나의 높이너비 = 21 = 2 → 이게 기울기예요
기울기가 음수면, 계단이 오른쪽으로 갈수록 아래로 내려가는 모양이 돼요.
2두 점으로 구하기
두 점 A(x₁,y₁), B(x₂,y₂)를 지나는 직선이라면
m = (y₂ − y₁)(x₂ − x₁)
3각도로 구하기 (중3 삼각비 연결)
직선이 x축의 양의 방향과 이루는 각을 θ라 하면
m = tan θ
중3 때 배운 삼각비 기억나나요? 직각삼각형에서 tan = 높이밑변이었죠 — 여기서도 똑같이 "세로 변화가로 변화"라 사실 같은 개념이에요.
정리: 셋 다 결국 "세로로 움직인 양가로로 움직인 양"이라는 같은 이야기를 다른 방식으로 표현한 것뿐이에요.
📍 주제 2 — 직선의 방정식 구하기 (3가지 유형)
직선의 방정식 — 유형1: 한 점과 기울기
📐 점과 기울기로 방정식 세우기
점 (x₁, y₁)을 지나고 기울기가 m인 직선 위의 임의의 점을 (x, y)라 하면, 기울기의 정의 그대로 (y − y₁)(x − x₁) = m 이 성립해요. 양변에 (x−x₁)을 곱하면 바로 공식이 나와요.
y − y₁ = m(x − x₁)
직선의 방정식 — 기본문제
기본 1 — 한 점과 기울기로 직선의 방정식 세우기
❓ 문제

기울기가 −3이고 점 (2, 5)를 지나는 직선의 방정식을 구하세요.
💡 풀이
y − y₁ = m(x − x₁)에 m=−3, (x₁,y₁)=(2,5)를 대입하면
y − 5 = −3(x − 2) → y − 5 = −3x + 6 → y = −3x + 11
직선의 방정식 — 유형2: 두 점
📐 두 점으로 방정식 세우기
두 점 (x₁,y₁), (x₂,y₂) (단, x₁≠x₂)가 주어지면, 새 공식이 필요한 게 아니라 유형1을 그대로 재사용해요.

① 먼저 두 점으로 기울기부터 구하고: m = (y₂−y₁)(x₂−x₁)
② 이 m과 점 하나를 유형1의 공식에 대입: y − y₁ = m(x − x₁)
직선의 방정식 — 기본문제
기본 2 — 두 점을 지나는 직선의 방정식
두 점 (1, 4), (3, 10)을 지나는 직선의 방정식을 구하세요.
💡 풀이
m = (10−4)(3−1) = 62 = 3
y − 4 = 3(x − 1) → y − 4 = 3x − 3 → y = 3x + 1
▾ 유형3 — 절편으로 방정식 세우기
절편 — 개념 (시각화)
📐 직선이 축을 가로지르는 지점
직선이 y축과 만나는 점의 y좌표를 y절편, x축과 만나는 점의 x좌표를 x절편이라고 해요.
절편 — x절편·y절편이 주어졌을 때 방정식 세우기
📐 절편형 공식: x/a + y/b = 1
x절편이 a, y절편이 b로 주어지면(단, a≠0, b≠0), 새 공식이 아니라 유형2(두 점)를 그대로 재사용해요 — 이 직선은 결국 두 점 (a,0), (0,b)를 지나는 직선이니까요.

① 기울기: m = (b−0)(0−a) = −ba
② 점 (a,0)과 대입: y − 0 = −ba(x − a) → y = −bax + b
③ 양변을 b로 나누면: yb = −xa + 1 → 정리하면:
xa + yb = 1
(x절편 a, y절편 b인 직선의 방정식 — 유형2에서 유도된 것일 뿐, 외울 공식이 하나 더 늘어난 게 아니에요)
절편 — 기본문제 (절편으로 방정식 세우기)
기본 3 — 절편형 공식으로 직선의 방정식 세우기
x절편이 4, y절편이 −2인 직선의 방정식을 구하세요.
💡 풀이
x4 + y−2 = 1 → 양변에 4를 곱하면
x − 2y = 4 → x − 2y − 4 = 0
절편 — 기본문제 (반대 방향: 방정식에서 절편 구하기)
기본 3-2 — x절편·y절편 구하기
직선 y = 3x − 9의 x절편과 y절편을 각각 구하세요.
💡 풀이
y절편: x=0 대입 → y = −9
x절편: y=0 대입 → 0 = 3x−9 → x = 3
y절편 −9, x절편 3
📍 주제 3 — 두 직선의 위치관계
평행·수직 — 기울기 조건 (요약)
📐 기울기로 보면 이렇게 간단해요
평행 조건: m₁ = m₂ (기울기가 같으면 절대 안 만나요)
수직 조건: m₁ × m₂ = −1 (자세한 그림은 이 주제 마지막에 있어요)
평행·수직 — 기본문제
기본 4 — 평행·수직 조건으로 직선 구하기
점 (2, 1)을 지나고, 직선 y = 4x + 3에 평행한 직선과 수직인 직선의 방정식을 각각 구하세요.
💡 풀이
평행 (m=4 그대로): y − 1 = 4(x − 2) → y = 4x − 7
수직 (m×4=−1 → m=−14): y − 1 = −14(x − 2) → y = −14x + 32
평행·수직 — 기본문제 (수직 전용 예제 추가)
기본 4-2 — 수직 조건만 따로 연습
직선 y = −2x + 5에 수직이고 점 (4, −1)을 지나는 직선의 방정식을 구하세요.
💡 풀이
기존 직선의 기울기 m₁=−2이므로, 수직 조건 m₁×m₂=−1에서
−2 × m₂ = −1 → m₂ = 12
점 (4,−1)과 m=1/2를 y−y₁=m(x−x₁)에 대입:
y − (−1) = 12(x − 4) → y + 1 = 12x − 2 → y = 12x − 3
▾ 같은 주제, 다른 도구로 — 일반형(ax+by+c=0) 계수만으로 판정하기
일반형과 위치관계 — 개념
📐 계수만 보고 판정하기
직선의 일반형 ax+by+c=0 꼴을 사용하면, 두 직선의 위치 관계(만나는지, 평행한지, 일치하는지, 수직인지)를 계수(a,b,c)만 비교해서 아주 빠르고 명쾌하게 파악할 수 있어요.

두 직선 l₁: a₁x+b₁y+c₁=0 과 l₂: a₂x+b₂y+c₂=0 이 있을 때, 일반형을 기울기 형태(y = −abx − cb)로 바꾸어 생각하면 다음과 같은 깔끔한 비율 공식이 나와요.
한 점에서 만난다 (기울기가 다를 때)
조건: a₁a₂ ≠ b₁b₂
의미: 두 직선이 한 점에서 교차합니다. (연립방정식의 해가 오직 1개)

평행하다 (기울기는 같고 y절편은 다를 때)
조건: a₁a₂ = b₁b₂ ≠ c₁c₂
의미: 만나지 않고 나란히 갑니다. (연립방정식의 해가 없음)

일치한다 (기울기와 y절편이 모두 같을 때)
조건: a₁a₂ = b₁b₂ = c₁c₂
의미: 두 직선이 완전히 겹칩니다. (연립방정식의 해가 무수히 많음)
예: 두 직선 2x−y−1=0 과 4x−2y−6=0 은?
a₁a₂ = 24 = 12 b₁b₂ = −1−2 = 12 c₁c₂ = −1−6 = 16
a₁a₂ = b₁b₂(=1/2) 인데 c₁c₂(=1/6)는 다르니까 → 평행
일반형과 위치관계 — 수직 조건
📐 수직 조건 — 가장 많이 쓰임!
두 직선이 서로 수직으로 만날 때는 계수 사이에 아주 간단한 성질이 성립해요. (기울기의 곱이 −1임을 일반형으로 유도한 결과예요.)

수직 조건: a₁a₂ + b₁b₂ = 0
x의 계수끼리 곱한 값과 y의 계수끼리 곱한 값을 더했을 때 0이 되면 두 직선은 직교해요.
예: 두 직선 2x+3y−6=0 과 3x−2y+4=0 은?
a₁a₂+b₁b₂ = 2×3 + 3×(−2) = 6−6 = 0 → 수직
검산(기울기 방법으로): l₁ 기울기 = −2/3, l₂ 기울기 = 3/2, 곱 = −2/3×3/2 = −1 ✓ 같은 결론이에요 — 도구만 다를 뿐 같은 사실을 보고 있는 거예요.
🦕 토로: 이 "교차 조건"이 다음 주제(정점을 지나는 직선)에서 어떻게 실전 무기가 되는지 계속 이어져요 — 끝까지 보면 연결이 보일 거예요.
일반형과 위치관계 — 기본문제
기본 7 — 계수만으로 판정하기
① 두 직선 4x−2y+3=0 과 2x−y−5=0 은 어떤 위치 관계인가요?
② 두 직선 3x+y−2=0 과 x−3y+7=0 은 서로 수직인가요?
💡 풀이
① a₁a₂ = 42 = 2, b₁b₂ = −2−1 = 2, c₁c₂ = 3−5 = −35
a₁a₂ = b₁b₂(=2) 인데 c₁c₂는 다르니까 → 평행

② a₁a₂+b₁b₂ = 3×1 + 1×(−3) = 3−3 = 0 → 수직 맞음
일반형과 위치관계 — 기본문제 (구성하기)
기본 7-2 — 교점을 지나는 직선 만들기
두 직선 x−y−1=0, 2x+y−5=0 의 교점을 지나고, 점 (1, 4)도 함께 지나는 직선의 방정식을 구하세요.
💡 풀이
k(x−y−1)+(2x+y−5)=0 꼴로 놓고, 점 (1,4)를 대입해요.
k(1−4−1)+(2×1+4−5)=0 → k(−4)+(1)=0 → −4k+1=0 → k=14

대입해서 정리: 14(x−y−1)+(2x+y−5)=0 → 양변에 4를 곱하면
(x−y−1)+4(2x+y−5)=0 → x−y−1+8x+4y−20=0 → 9x+3y−21=0

→ 3x+y−7=0

검산: 교점(2,1) 대입 → 6+1−7=0 ✓ / (1,4) 대입 → 3+4−7=0 ✓
평행·수직 — 수직 조건을 그림으로 정확히 확인
📐 왜 곱이 −1이 되면 직각일까
아래는 실제 격자에 정확한 비율로 그린 두 직선이에요 — 눈금 하나하나를 세어보면 기울기와 직각을 직접 확인할 수 있어요.

직선①은 오른쪽 2칸마다 위로 4칸 (m₁ = 4/2 = 2), 직선②는 오른쪽 4칸마다 아래로 2칸 (m₂ = −2/4 = −1/2)이에요. 격자가 정사각형이라 그림에서도 두 직선이 정확히 직각으로 만나는 걸 볼 수 있어요.
m₁ × m₂ = 2 × (−12) = −1
한 직선의 "오른쪽·위" 방향이 다른 직선에서는 "위·왼쪽" 방향으로 90° 회전한 모양이라, 가로·세로가 서로 자리를 바꾸고 부호 하나가 뒤집혀요 — 그래서 곱이 항상 −1이 돼요.
📍 주제 4 — 정점을 지나는 직선
정점을 지나는 직선 — 개념
📐 교점을 몰라도 지나가는 직선
두 직선 l₁: x−y−1=0 과 l₂: 2x+y−5=0 이 있어요. 이 둘의 교점을 지나는 또 다른 직선을 만들고 싶다면 어떻게 할까요?

가장 단순한 방법은 교점을 직접 구한 다음(연립방정식을 풀어서), 그 점을 지나는 직선을 다시 세우는 거예요. 그런데 교점을 몰라도 되는 더 빠른 방법이 있어요.

k·l₁ + l₂ = 0, 즉 k(x−y−1) + (2x+y−5) = 0 은 k가 어떤 값이든 항상 두 직선의 교점을 지나요! (l₂ 자기 자신만 빼고요.)
왜 그럴까요? 교점 (x₀, y₀)는 l₁=0 과 l₂=0 을 동시에 만족하는 점이에요. 그러니까
k·l₁(x₀,y₀) + l₂(x₀,y₀) = k×0 + 0 = 0
— k를 아무리 바꿔도 이 점에서는 항상 0이 되니까, 이 점을 절대 벗어나지 않아요.
정점을 지나는 직선 — 개념 풀이
📐 거꾸로 뒤집으면 — 항등식으로 찾기
이제 거꾸로 생각해볼까요? 처음부터 k(x−y−1) + (2x+y−5) = 0 이라는 식이 주어졌다면, 방금 배운 대로 이건 k값에 관계없이 항상 두 직선 x−y−1=0 과 2x+y−5=0 의 교점을 지나요.

그러니까 "이 직선이 k값에 관계없이 항상 지나는 점(정점)을 구하라"는 문제는, 사실 두 부분을 각각 0으로 놓고 연립하라는 뜻이에요.

여기서 방정식 단원에서 배운 항등식 개념이 그대로 쓰여요 — k(x−y−1)+(2x+y−5)=0을 k에 대한 식으로 보면, k가 무엇이든(=항등식으로) 항상 성립해야 하니까 k의 계수 부분과 상수 부분이 각각 0이어야 해요. (ax+b=0이 모든 x에 대해 성립하려면 a=0, b=0이어야 하는 것과 완전히 같은 원리!)

→ x−y−1=0 이고 2x+y−5=0 → 연립해서 풀면 정점 (2, 1)

일반형
k(a₁x+b₁y+c₁) + (a₂x+b₂y+c₂) = 0 꼴의 직선은, k값과 관계없이 항상 두 직선 a₁x+b₁y+c₁=0 과 a₂x+b₂y+c₂=0의 교점을 지난다.
🔗 방금 배운 것과 연결: 주제3에서 배운 교차 조건(a₁/a₂ ≠ b₁/b₂)으로 다시 확인해볼까요? l₁: x−y−1=0 (a=1, b=−1), l₂: 2x+y−5=0 (a=2, b=1) → 1/2 ≠ −1/1 이므로 교차 조건을 만족해요. 즉 이 두 직선은 반드시 한 점에서 만나고, 그 점이 바로 우리가 방금 구한 정점 (2, 1)이에요. "정점을 지나는 직선"은 결국 "두 직선의 교점을 지나는 직선 묶음"이라는 걸 계수로도 확인한 셈이죠.
정점을 지나는 직선 — 기본문제
기본 8 — 고정점 찾기
직선 k(2x−y+1) + (x+y−4) = 0 이 실수 k의 값에 관계없이 항상 지나는 점을 구하세요.
💡 풀이
k값과 관계없이 항상 성립하려면 두 괄호가 각각 0이어야 해요.
2x−y+1=0 … ①
x+y−4=0 … ②
①+②: 3x−3=0 → x=1, ②에 대입: y=3
정점 (1, 3)
정점을 지나는 직선 — 심화 1 (기출 패턴: 정점+거리 결합)

점과 직선 사이의 거리 — 개념
📐 점에서 직선까지 가장 가까운 거리
점에서 직선까지 거리 중 가장 짧은 건, 점에서 직선에 수직으로 내린 선분의 길이예요. 수직이 아닌 다른 점들과 비교해서 직접 확인해볼게요.

그림에서 P에서 직선 위 여러 점(Q₁, Q₂)까지 재보면 전부 F까지의 거리보다 더 깁니다 — 직각으로 만나는 F 지점이 항상 가장 가깝습니다.

점과 직선 사이의 거리 공식

점과 직선 사이의 거리 — 심화에서 쓰는 보충 도구
📐 산술기하평균 — "양수 + 그 역수" 꼴의 최솟값
넓이나 길이의 최솟값을 구하는 문제에서, 식을 정리했더니 "어떤 양수 + 그 양수의 역수" 꼴(예: m + 1/m)이 나오는 경우가 있어요. 이럴 때 쓰는 부등식이에요 — 원래는 부등식 단원 도구지만, 미리 알아두면 여기서도 바로 쓸 수 있어요.

a>0, b>0일 때: a + b ≥ 2√(ab), 등호는 a = b일 때 성립
("산술평균≥기하평균" — 줄여서 산술기하평균)
예: m>0일 때 m + 1m의 최솟값은?
a=m, b=1m로 놓으면 ab=1이므로 m + 1m ≥ 2√1 = 2, 등호는 m=1m → m=1일 때

m<0이면 부호가 반대로 뒤집혀서 최댓값 문제가 돼요(m=−1일 때 최댓값 −2) — 직선 단원 문제는 보통 m>0인 경우만 다룹니다.
📍 주제 6 — 자취의 방정식
자취의 방정식 — 개념
📐 조건을 만족하는 점을 전부 모으면?
자취란 어떤 조건을 만족하는 점을 전부 모은 도형이에요. 구하는 방법은 항상 똑같아요 — 그 점을 P(x,y)라고 이름 붙이고, 조건을 식으로 세운 뒤 정리하면 됩니다.

예: 두 점 A(1,2), B(5,−2)로부터 같은 거리에 있는 점 P(x,y)의 자취는?
PA = PB → PA² = PB² (제곱해서 근호를 없애는 게 핵심 요령)
(x−1)²+(y−2)² = (x−5)²+(y+2)²
전개해서 정리하면 → x − y − 3 = 0, 즉 y = x−3
검산: 이 결과는 사실 여러분이 이미 배운 선분 AB의 수직이등분선과 정확히 같아요! AB의 중점(3,0)을 지나고, AB의 기울기(−1)와 수직인 기울기(1)를 가지니까요. "자취"라는 새 이름이 붙었을 뿐, 방법은 항상 조건 → 식 세우기 → 정리로 똑같습니다.
자취의 방정식 — 기본문제
기본 6 — 자취의 방정식 구하기
두 점 A(0,0), B(6,2)로부터 같은 거리에 있는 점 P의 자취의 방정식을 구하세요.
💡 풀이
PA²=PB²: x²+y² = (x−6)²+(y−2)²
x²+y² = x²−12x+36+y²−4y+4
0 = −12x−4y+40 → 12x+4y−40=0 → 3x+y−10=0
🦕 토로: 지금은 "같은 거리" 조건이라 결과가 직선(수직이등분선)이 됐지만, 조건이 달라지면(예: 한 정점으로부터 일정한 거리) 결과가 원이 되기도 해요 — 원의 방정식 단원에서 이 자취 기법을 그대로 다시 쓰게 됩니다.

두 평행선 l₁: y = 2x + 1, l₂: y = 2x − 9가 있어요. (기울기가 둘 다 2니까 평행이 맞죠?) 이 두 직선 사이의 거리를 구하고 싶은데, 아직 "평행선 사이의 거리" 공식은 배운 적이 없어요. 두 학생의 대화를 들어볼까요:

민준: 새 공식이 없어도, 우리가 이미 배운 "점과 직선 사이의 거리" 공식을 쓸 수 있지 않을까? l₁ 위에서 점을 하나 골라서, l₂까지의 거리를 재면?
유나: 근데 어느 점을 고르느냐에 따라 답이 달라지지 않을까? l₁ 위에도 점이 무한히 많은데?
민준: 어... 그럴 수도 있겠다. 확인은 해볼 수 있잖아. 점 두 개로 각각 재보자.
l₁ 위의 점 A(0, 1)에서 l₂(2x−y−9=0)까지: d = |2(0)−1(1)−9|√(2²+1²) = 10√5 = 2√5
l₁ 위의 다른 점 B(3, 7)에서 l₂까지: d = |2(3)−1(7)−9|√5 = 10√5 = 2√5

유나: 어? 진짜 똑같이 나왔어! 우연일까?
민준: 평행선이니까 두 직선이 어디서든 절대 안 만나고, 벌어진 간격도 어디서나 똑같은 거 아닐까? 그러니까 어느 점을 골라도 같은 답이 나오는 거지.
유나: 그럼 우리가 새 공식을 외울 필요가 없네 — 그냥 아무 점이나 골라서 기존 공식에 넣으면 되는 거였어.

직선의 방정식 — 이 단원 한눈에 보기
🗂️ 전체 흐름 정리 (+ 공식)
이 단원은 이렇게 흘러가요:

① 기울기가 뭐지? — 기울기(m)는 x가 변한 양에 대해 y가 얼마나 변했는지를 나타내는 비율이에요. 이 비율을 두 점으로 구하거나 각도(tanθ)로 구하거나, 방법은 다양해도 결국 하나의 같은 값이에요.
m = 세로 변화량가로 변화량 = y₂−y₁x₂−x₁ = tanθ

② 직선의 방정식 구하기 — 한 점+기울기 공식이 기본이고, 두 점 유형과 절편형은 전부 이 공식을 재사용해서 유도돼요. 새 공식이 아니라 "이미 아는 도구의 재사용"이라는 게 핵심이에요.
y−y₁=m(x−x₁)    xa+yb=1

③ 두 직선의 위치관계 — 기울기로 보는 방법과 일반형 계수로 보는 방법, 두 도구가 사실 같은 사실을 다르게 표현한 것뿐이에요.
평행 m₁=m₂   수직 m₁×m₂=−1    일반형 수직: a₁a₂+b₁b₂=0

④ 정점을 지나는 직선 — k(a₁x+b₁y+c₁)+(a₂x+b₂y+c₂)=0 형태가 k값에 관계없이 항상 두 직선(a₁x+b₁y+c₁=0 과 a₂x+b₂y+c₂=0)의 교점을 지난다는 걸, 방정식 단원에서 배운 항등식 원리로 설명해요.

⑤ 점과 직선 사이의 거리 — 공식 하나로 넓이, 최댓값 등 다양한 곳에 활용돼요.
d = |ax₀+by₀+c|√(a²+b²)

⑥ 자취의 방정식 — 자취에서 가장 중요한 건 표현이에요. 조건을 만족하는 ①동점(움직이는 점) ②점들의 집합 ③도형을 전부 점 P 하나로 이름 붙이고, 그 점을 ④P(x,y)로 놓는 것 — 이건 중1 방정식 활용에서 미지수를 x로 놓는 것, 함수에서 점을 (x,y)로 놓는 것과 똑같은 원리예요.
두 점 사이의 거리 공식: PA = √((x−x₁)²+(y−y₁)²) → 조건 PA=PB에 대입 → PA²=PB² → 전개해서 정리

이 여섯 가지 주제 다음에는 "지도"(실전에서 이 표현이 나오면 어떤 도구를 쓸지 미리 보는 유형 정리, 4가지)와 서랍문제·판별 드릴이 이어집니다.
