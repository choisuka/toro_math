미술관 입장료와
방정식 활용
미지수 선택 · 조건 번역 · 요금 구조 분석
문제
① 평일 입장료: 어른은 청소년의 2배
② 주말 입장료: 평일보다 어른은 1,200원↑, 청소년은 800원↑
③ 어느 주말, 어른 3명 + 청소년 5명 = 총 56,000원
🎯 같은 날 어른 5명 + 청소년 2명의 입장료 합계는?
🇸🇬 싱가포르 바 모델 구조 시각화 ▼
청소년 평일 = x원 어른 평일 = 2x원 청소년 주말 = x + 800 어른 주말 = 2x + 1,200
구분평일주말
청소년xx + 800
어른2x2x + 1,200
주말 합계: 3(2x+1200) + 5(x+800) = 56,000
🇫🇮 핀란드 단계별 풀이 논리 서술 ▼
1
미지수 설정 — 가장 기본 단위를 x로
모든 요금이 청소년 평일 요금을 기준으로 파생되므로
x = 청소년 평일 입장료 (원)
💡 어른 = 2x로 바로 표현 가능. x를 어른으로 잡으면 청소년이 x/2가 되어 분수 계수 등장.
2
주말 요금 표현 — 평일 기준에서 더하기
어른 주말 = 2x + 1,200
청소년 주말 = x + 800
⚠️ 어른 주말 = 2x + 1,200 (평일 어른 기준). x + 1,200으로 혼동 주의!
3
방정식 세우기 — 조건 번역
3(2x + 1,200) + 5(x + 800) = 56,000
4
풀기
6x + 3,600 + 5x + 4,000 = 56,000 11x + 7,600 = 56,000 11x = 48,400 x = 4,400
5
요금 확인
구분평일주말
청소년4,400원5,200원
어른8,800원10,000원
6
구하는 값 — 어른 5명 + 청소년 2명
5 × 10,000 + 2 × 5,200 = 50,000 + 10,400 = 60,400원
최종 정답
60,400원
